## v8 で直してほしい所

### 1. 立ち姿の首を短くする（いちばん大事）
持ち主の指摘は「首が長すぎ」（2026-10-24）だった。ところが v7 は首の付け根を太くしただけで、首の上の線は v6 より長くなった。
- **いまの数**：立ち姿の首の上の線（き甲からうなじ）は 0.715m（v6 は 0.629m）。Codex 側の測り方でも 0.693m → 0.739m。頭の長さは 0.561m。
- **目標**：立ち姿で、首の上の線を頭の長さの 1.0〜1.1 倍、つまり **0.56〜0.62m** にする（頭の長さ 0.561m のまま）。頭 ÷ 首で言うと 0.90〜1.0。
  - v7 の首の上の線は頭の 1.27 倍（0.715m）で、これでも長すぎに見えた。v7 の依頼文に書いた「首の上の線は頭の約1.5倍」は、本の上の体形の目安だった。今回は、持ち主が見せた手本の連続絵と動画（首は頭とほぼ同じか、少し長いくらい）の見え方を優先する。
  - 測り方は v7 と同じ。うなじ（耳の後ろの骨の点）・き甲・上唇の3点を、立ち姿の横から測る。
- 首を短くしても、v7 の首の形（付け根が太く喉へ細い三角形）と、首の下の線の長さとの比（上の線：下の線 ≒ 2:1）は保つ。
- 走り（RaceGallop）でも同じ形で首が短くなるようにする。走りの首の上の線は、v7 の 0.638m より短くする。

### 2. 走りの頭の位置を下げる
v7 は走りの頭の位置が v6 より 13cm 高い（うなじの平均 1.83m。v6 は 1.70m、いまの馬は 1.66m）。首が上に立って長く見える一因になっている。
- うなじの平均の高さを **1.66〜1.72m** に下げる（倍率 2.6・速さ 16m/秒）。
- 首の傾き（水平から 30〜45°）と、頭が前下を向くことは保つ。首を短くすれば、傾きを保ったまま頭は下がるはず。
- うなじの上下の幅は 0.25〜0.30m のまま。頭の中心の上下（v7 は 0.256m）は、胴のしなりを保ったまま、もう少し小さくてよい（頭がなるべく止まる）。

### 3. レース画面の距離で違いが分かること
レース画面の中継の距離では、v6 と v7 の見分けがほとんど付かなかった。v8 では、中継の視点（`race_compare_mid_tv.jpg` と同じ距離）で見ても、首が短く太く、頭が前下にあることが分かる形にする。

## 取り込みの約束（ゲーム側で決まっていること）
- 向き：前は −X・Y が上。ゲーム側で親を Y 軸で +90° 回す。`Saddle` の向きも GLB の軸のまま。
- UV2 は自動のライトマップ UV で上書きしない。法線の絵は GLB の中に入れたまま（ゲーム側の import は embedded_image_handling を GLB の中に残す設定）。
- 首の補正は名前で2つ（RaceNeckCorrective・WalkNeckCorrective）。値はクリップが持つ。名前を変えるなら書く。
- COLOR_0 は頭の座標を入れたまま（ゲーム側のシェーダが鼻の穴と口を描くのに使う）。
- ゲームの本体のコードとデータには触らない。ゲーム側で試作の場面（`godot/proto/tripo_horse/`）に取り込み、v7・いまの馬と同じレース・同じ時刻の絵で並べてから、採るかどうかを決める。
- 商用で使える形で作る（Tripo の Pro プラン）。手本の写真は、権利の問題が無いもの（パブリックドメインなど）だけを使い、出典を書く。
