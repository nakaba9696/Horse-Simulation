## v4 で良くなった所（変えないでほしい所）
- **約束：** 倍率 2.6 で1完歩 7.00m、周期 0.45 秒、その場走行。完歩の式 L＝7×S÷2.6 と、再生倍率 v×0.45÷L はゲーム側でそのまま使っている。
- **接地：** 蹄が地面に沈まない（最も低い点 −0.3cm）。接地中の蹄の滑りが小さい（蹄の重心で 0.64m/秒）。
- **取付点：** `Saddle`・`Stirrup_L/R`・`Bit_L/R`・`Withers` と `saddle-track.json`。ゲーム側で、いまの騎手を `Saddle` に乗せる試作が動いた。
  - `Saddle` の向きは GLB の軸（前が −X）のままで、ゲーム側で −90° 回している。向きの決まりは変えないこと。変えるならそう書く。
- **クリップ：** `Stand`（3 秒）と `Walk`（1.2 秒）。首の補正の値は、走りが 1、立ち姿と常歩が 0。
- **頭絡：** 別の材質になっている。
- **体の長さ：** 立ち姿で 2.45m。
- **UV2 の毛色の領域の決まり**（region＝floor(UV2.x×8)、leg＝floor(UV2.y×8)）。
- **重さ：** 19,358 三角形・骨 54 本。これより大きく増やさないこと。

## v5 で直してほしい所（大事な順）

### 1. 首が曲がって見える（いちばん大事。持ち主の指摘 2026-10-23「首曲がってるように見える」）
横から見ると、首の上の線（たてがみの線）が、き甲から頭へまっすぐ伸びていない。首の真ん中で下へへこみ、頭が首の先でかぎのように下へ折れて、胸の方を向いている（`neck_v4_02.jpg`・`neck_sheet.jpg` の2段目）。いまの馬（3段目）は、首がまっすぐ前へ伸び、頭は首の先で前を向いている。

走る全部のコマで、次を満たしてほしい。
- 首の上の線は、き甲から耳の後ろ（うなじ）まで、まっすぐか、ゆるく上へふくらむ形にする。真ん中でへこまない。
- 首の傾きは、き甲とうなじを結ぶ線で、水平から 20〜35° 上（走る馬らしく前へ伸ばす）。
- 頭と首の角度（うなじで、首の線と、額から鼻先の線がなす角）は 90〜110°。鼻先がうなじより前にあり、胸の方へ巻き込まない。v4 は頭が巻き込んで、この角が小さく見える。
- 首の下の線（喉から胸）も折れずにつながる（v4 で良くなった所は保つ）。
- 正面と後ろから見て、首と頭が体のまん中の線に乗り、左右へ曲がったりねじれたりしない（`trio4_front.jpg`）。
- **確かめ方：**
  - 28時点の横の絵で、首の上の線に折れやへこみが無いことを見る。
  - 正面・後ろの絵でねじれが無いことを見る。
  - き甲・首の真ん中・うなじ・鼻先の4点の座標を、1周期ぶん JSON に書き出す（`neck-line.json`）。そこから上の2つの角度の幅を出して、記録に書く。

### 2. 首の穴と、肩の出っ張り・黒い切れ目
- 首の真ん中、たてがみの下にメッシュの穴があり、向こうの空が見える（`neck_hole_zoom.jpg`）。Codex の Blender の絵（neck-closeup.jpg）にも黒い三角で写っている。ふさぐこと。
- 肩の前に、袋のような出っ張りが出るコマがある。肩と胸に黒い切れ目のような線がある。裏面が見えているか、割れ目に見える。なくすこと。
- **確かめ方：** 穴（境界の辺）が0であること。法線が裏返った面が無いこと。肩の寄りの絵で、28時点ともなめらかであること。

### 3. たてがみ
- 領域は耳の後ろまで届いた（良い）。ただ、房ではなく首から立つ黒いとげのように見える。房に見える形にする。首に沿って片側へ寝かせ、先を少しまとめる。
- たてがみと胴の色の境がぎざぎざで、たてがみの中に胴の色が島のように残っている。境をなめらかにし、島をなくす。

### 4. 体の上下と頭の高さ
- き甲の上下は、v3 の 0.072m から v4 で 0.118m になった（良い）。もう少し大きく、0.15m 前後にしてほしい（いまの馬は 0.33m）。
- 4本とも浮く時間は1周期の19%で、今の割合を保つ。
- 走るとき、頭をもう少し上げる。うなじの平均の高さを、v4 の 1.62m から 1.66m 前後へ（倍率 2.6 で）。上の1の角度に収まる範囲でよい。

### 5. 鼻先の色の境
鼻先（region 4）と顔の色の境が角張っている。なめらかにする。

### 6. あれば：速歩・駈歩のクリップ
2〜5m/秒では常歩を速く回すしかないので、`Trot_Loop`（速歩）と `Canter_Loop`（駈歩）があると助かる。返し馬とゴール後の流しで使う。無理なら書いて飛ばしてよい。

## 取り込みの約束（ゲーム側で決まっていること）
- 前は −X・Y が上。ゲーム側で親を Y 軸で +90° 回す。
- UV2 は自動のライトマップ UV で上書きしない。法線の絵は GLB の中に入れたまま。
- ゲームの本体のコードとデータには触らない。ゲーム側で試作の場面（`godot/proto/tripo_horse/`）に取り込み、v4・いまの馬と同じレース・同じ時刻の絵で並べてから、採るかどうかを決める。
- 素材は商用で使える形で作る（Tripo の Pro プラン）。
