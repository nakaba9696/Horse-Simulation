# 馬モデル v4 の依頼（Codex へ）

v3（`horse-claude-handoff-v3.zip`）をゲームの試作の場面とレース画面に取り込み、いまの馬と並べて比べた。v2 よりはっきり良くなったが、本採用にはまだ足りない所がある。v3 を元に v4 を作ってほしい。

## v3 で良くなった所（変えないでほしい所）
- 完歩と速さの約束：倍率 2.6 で1完歩 7.00m、周期 0.45 秒、クリップ名 `RaceGallop_Loop`（Godot では `RaceGallop`・LOOP_LINEAR）、その場走行（ルートは前へ進まない）。完歩の式 L＝7×S÷2.6、再生倍率 v×0.45÷L もそのまま使っている。
- 首の高さと前への伸び：うなじの高さ 1.63m（いまの馬 1.66m）。
- 脚の伸び：前後の蹄の開き 2.61m、接地中の蹄の滑りが小さい（骨の点で測った目安 1.3m/秒）。
- 毛色の領域（UV2）：region＝floor(UV2.x×8)、leg＝floor(UV2.y×8) の決まり。ゲーム側の毛色シェーダはこれを読んでいる。**UV2 の決まりは変えないこと。** 変えるなら coat-region-schema.json の版を上げて、変えた所を書く。
- 54本の骨・RaceNeckCorrective（走るときは 1）。
- 重さ：18,320 三角形・LOD あり。1コマの CPU は 1.3〜1.7ms で、いまの馬（5.6〜5.9ms）より軽い。三角形の数はこれより大きく増やさない。

## v4 で直してほしい所（大事な順）

### 1. 体の上下と、4本とも浮く時間（いちばん大事）
- v3 は体がほとんど上下・前後に揺れず、4本とも地面から離れている時間が短い。いまの馬より「跳ねる」感じが弱い（比べの絵 `trio_run_sheet.jpg`）。
- 1周期の中に、4本とも浮く時間をはっきり入れる。目安は周期の 15〜25%。
- き甲（肩の上）を、実寸でおよそ 0.10〜0.15m 上下させる。いちばん低いのは前脚で体を受けたあと、いちばん高いのは浮いている時間。いまの馬は、うなじの高さが 1.45〜1.84m の幅で動いている（v3 は 1.57〜1.69m）。
- 首と頭は体の上下に合わせて少し遅れて振る（首の振り子）。鼻先が地面を向きすぎないこと。
- 完歩 7m・周期 0.45 秒・接地中に蹄が滑らないことは保つ。

### 2. 首の付け根から喉の皺と折れ
- 首の付け根から喉にかけて皺と折れが見え、頭が胸へ押し込まれて見えるコマがある。肩の皺も残っている。
- 走る全部のコマで、首の下の線（喉から胸）がなめらかにつながるようにする。補正形状でも、骨の重みの付け直しでもよい。
- 確かめ方：v3 と同じ28時点の側面の絵で、首の下の線に折れが無いこと。

### 3. たてがみの領域と形
- たてがみの領域（region 1）が首の後ろ半分にしかなく、頭側は胴の色になっている。うなじ（耳の後ろ）までたてがみにする。前髪もあれば入れる。
- たてがみと尾は面になっている。房に見えるように、縁を割るか、少し厚みを付ける（三角形は増やしすぎない）。

### 4. 立ち姿と常歩のクリップ
- ゲートの中など、速さが 0 のときに立ち姿が無く、走る形のまま止まってしまう。
- 足してほしいクリップ：
  - `Stand_Loop`：立ち姿（耳と尾が少し動く程度。2〜4 秒のループ）
  - `Walk_Loop`：常歩（パドック・返し馬・ゴール後の流し）
- 走るクリップとのつなぎを考え、首の補正をどう扱うか（0 に戻すか）を書く。

### 5. 騎手を乗せるための点（本採用に必須）
- いまの馬は騎手が乗っている。v3 は騎手を乗せる場所が分からないので、レース画面では騎手を消して比べた。
- 背の上の鞍の位置に、骨か空のノード `Saddle` を置き、背の骨に付けて動かす（向きは馬の前を -X のまま）。
- あぶみの位置（左右）にも `Stirrup_L`・`Stirrup_R` を置く。
- `Saddle` の位置と傾きを、1周期ぶん（240fps のベイクから 60fps で十分）JSON に書き出す（`saddle-track.json`）。ゲームはこれで騎手の上下を合わせる。

### 6. 頭絡と、体の長さ
- 頭絡（はみ・手綱をつける所・額帯）が無い。手綱の付く点 `Bit_L`・`Bit_R` と、簡単な頭絡の形を足す。毛色の領域とは別の領域（例：region 7 を使わず、別の材質）にする。
- 鼻先から尾までが約 2.55m（倍率 2.6）で、いまの馬（2.43m）より少し長い。体高はいまのままで、体の長さを 2.45m 前後に寄せられるなら寄せる（無理なら倍率で合わせるので、その旨を書く）。

## 渡してほしいもの（v3 と同じ形）
- `horse-gallop.glb`（最終）・`horse-gallop.blend`・`source-rigged.glb`
- `preview/`（Godot 4.6 の独立した場面。立ち姿・常歩・走りを切り替えられる）
- `tools/`（作り直しと確かめの道具）、`SHA256SUMS`
- 確かめの記録（JSON）：完歩の実測・接地・ループ端の差・浮く時間の割合・き甲の上下の幅・`saddle-track.json`
- 1600×1000 の側面の絵（1周期の8コマ並べ）と、正面・背面
- `CLAUDE_HANDOFF.md`（v3 からの変更・約束・限界）

## 取り込みの約束（ゲーム側で決まっていること）
- 前は -X・Y が上（ゲーム側で親の Y 回転 +90 度）。
- UV2 は自動のライトマップ UV で上書きしない。法線の絵は GLB の中に入れたまま。
- ゲームの本体のコードとデータには触らない。ゲーム側で試作の場面（`godot/proto/tripo_horse/`）に取り込み、いまの馬と同じレース・同じ時刻の絵で並べてから、採るかどうかを決める。
- 素材は商用で使える形で作る（Tripo の Pro プラン）。出典はゲーム側の `assets/CREDITS.md` に書く。
