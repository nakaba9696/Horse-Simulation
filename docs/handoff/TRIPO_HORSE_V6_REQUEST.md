## v6 で直してほしい所（大事な順）

### 1. 首が短く太く、頭が大きい（いちばん大事）
v5 は首が短く太くなり、頭が大きく見える。全体がずんぐりして、ポニーのような体形に見える（`trio5_side.jpg`・`trio5_front_zoom.jpg`）。v4 といまの馬は、首が長く細い。
- き甲からうなじまでの首の長さを、v4 並みに戻す。水平に測って v5 の約 1.25 倍が目安。
- 首を細くする。とくに喉から胸にかけての太さ。首の付け根（肩の前）から喉へ、すっと細くなる形にする。
- 頭を、体に対して1割ほど小さくする。顔を細長くし、額から鼻先までの長さに対して頬を張らせすぎない。
- v5 で直った首の線（傾き 20〜35°・頭と首の角度 90〜110°・へこみ無し・ねじれ無し）は保つ。`neck-line.json` も出す。

### 2. 走るとき首と頭が動かず、硬い
v5 は走っても首と頭がほとんど動かない。うなじの高さの幅は 0.17m で、いまの馬は 0.40m。
- 完歩に合わせて、首と頭を上下に振る。前脚が着くときに頭が下がり、浮くときに上がる、首の振り子にする。
- うなじの高さの幅は 0.25〜0.35m が目安。
- 振っても、首の線の角度（上の1）の範囲からはみ出さない。

### 3. たてがみが櫛のように見える
とげではなくなったが、等間隔の黒い板が櫛のように並んで見える。房の根元に胴の色が少し島のように残る。
- 房の間隔・長さ・向きをばらし、首に沿って片側へ寝かせる。
- 根元の胴の色の島を無くす。

### 4. 目のまわりと鼻先の黒
- 目のまわりに黒い角張った形がある（目の領域か頭絡の金具）。小さく、なめらかにする。
- 正面から見ると、鼻先の黒い所が大きな2つの塊になって、ゴーグルのように見える（`trio5_front_zoom.jpg`）。鼻先の暗い所は、鼻の穴と口のまわりだけの小さな範囲にし、顔の色へなめらかにつなぐ。

## 取り込みの約束（ゲーム側で決まっていること）
- 向き：前は −X・Y が上。ゲーム側で親を Y 軸で +90° 回す。`Saddle` の向きも GLB の軸のまま（ゲーム側で −90° 回す）。
- UV2：自動のライトマップ UV で上書きしない。法線の絵は GLB の中に入れたまま。
- 取り込みの手順：ゲームの本体のコードとデータには触らない。ゲーム側で試作の場面（`godot/proto/tripo_horse/`）に取り込み、v5・いまの馬と同じレース・同じ時刻の絵で並べてから、採るかどうかを決める。
- 素材の権利：商用で使える形で作る（Tripo の Pro プラン）。
