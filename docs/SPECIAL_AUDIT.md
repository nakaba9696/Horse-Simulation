# スペシャルホースと隠し馬の総点検

`node tools/special_audit.js` で作る（手で直さない）。持ち主が採否を付けるのは `docs/SPECIAL_AUDIT.json`（adopt）。採った案は `node tools/special_audit_apply.js` で `data/horse_fix.js` に入る。

調べた馬 322頭（スペシャルホース 322頭・トロフィーの隠し馬 79頭。重なりあり）。問題のある馬 90頭、問題 乱れ 21・能力 49・同格 26・帯 20・馬場 3・脚質 5。案 78頭（持ち主の名指し 13頭）。当てた直し 8頭。

総合力の目安（docs/SPEC.md）：46〜50 OP・51〜55 G3・56〜60 G2・61〜65 G1・66〜80 G1 を何度も勝った名馬・81〜85 神話の名馬級（伝説級）・86〜99 オリジナルホースだけ。総合力（スピードとスタミナ）は実績の格に合わせ、個性と逆転の余地はほかの能力（根性・気性・切れ・坂など）と特殊能力で出す（持ち主 2026-10-20）。案は G1 を何度も勝った名馬を 66〜80、伝説級だけを 81〜85 に置いた

総合力は「いちばん良いとき」の芝・ダート（`HS.Season.fhPeak`）。素の値＝能力の乱れ（名前ごとの運）が無いときの値。

## 全体の片寄り（式・決まりの側の原因）

### 能力の乱れが総合力を ±3 ほど動かす

史実馬の能力は rating に名前ごとの運（スピード・スタミナに 標準偏差2、芝とダートを分けるときにさらに 1.5）を足して作る（js/core/horse.js の H.fromHistoric・H.splitSurface）。総合力はスピードとスタミナだけで決まるので、同じ rating でも総合力が上下する。この一覧の 322頭で、素の値との差の標準偏差は 1.46、3 以上低いのが 9頭・3 以上高いのが 12頭（プリティーポリー −5・バックパサー −3・トウショウボーイ −3 など）。

案1（いまの案の作り方）：馬ごとの案で、目標の総合力に届く rating を探す（運はそのまま）。案2（式を直す）：スペシャルホース（と史実馬）のスピード・スタミナの運を小さく（標準偏差 2 → 0.7 など）。史実馬4771頭の総合力が動くので、目印の馬とテストを合わせ直す。

### 芝ダの馬はいつもダートが上になる

芝ダの馬は芝 85・ダート 90 の向きで作る（H.fromHistoric の apt）ので、ダートの総合力が芝より 1〜2 高くなる。この一覧の芝ダ 23頭のうち 20頭がダートが上。芝が本筋の馬（エクセラー・ハイセイコーなど）は向きが逆になる。

案：芝ダの向きを勝ち鞍の馬場の数で決める（芝が多ければ芝 90・ダート 85）。いまは目立つ馬だけデータに turf/dirt を書いて直した。

### 昔の米国のダートの名馬と、地方・豪州の名馬の rating が低め

rating はデータのファイルごとに手で付けた値（自動で作った馬は勝ち鞍の格から）。いまの暦の G1 に当たる大レースを3勝以上した馬の総合力のまん中は 北米 77（14頭）・欧州 71（51頭）・日本 71（21頭）・香港 70（4頭）・豪州 67（4頭）・日本（地方） 65（1頭） で、三冠馬のような馬は低くない。低いのは、勝った大競走（昔のハンデキャップの大競走・南関東の三冠など）がいまの暦の G1 に当たらない馬で、年度代表馬クラスでも rating が 83〜91 に置かれている（トムフール 86・ギャロレット 86・ネイティヴダンサー 90・コリン 91・ハツシバオー 83・サンオーイ 80）。

案：馬ごとの案で上げる（式は変えない）。

### 伝説級でも 81 に届かない馬がいる

伝説級は能力を 1.035 倍するだけなので、rating が 100 でないと 81 に届かない（グラディアトゥール 96 → 75・ザテトラーク 86 → 67）。

案1（いまの案）：その馬の rating を上げる。案2（式）：伝説級は総合力が 81 を下回らないように能力の下限を置く。

### 昔の名馬に「大舞台」が付かない

「大舞台」は暦で G1 になっているレースの勝ち数（3勝、または2勝で rating 95 以上）で付く（H.histSkills）。1984年より前の JRA の大レースや、昔の海外の大レースは暦で G1 になっていないので、三冠馬や無敗の名馬にも付かない。

案：名鑑のある名馬（手で決めた表の無い馬）で、大レースを3勝以上・伝説級・8戦以上無敗のどれかなら「大舞台」を足す（馬ごとの案に入れた）。

### 無敗の名馬に運で弱みが付く

勝ち鞍から見えない癖は、名前ごとの運で 6% の馬に出遅れ・掛かり・ソラのどれかを付ける（H.histSkills）。ネアルコ（14戦無敗）に掛かり癖、オーモンド（16戦無敗）に出遅れ癖が付いている。

案：大レースを何度も勝った名馬・無敗の名馬からは、史実の裏付けのない弱みを外す（馬ごとの案に入れた）。史実に合うもの（クリフジの出遅れ）は残す。

### マイル〜中距離の馬が少し損

能力を作るとき、短距離馬（距離の上限 1400m 以下）はスピード +3、長距離馬（上限 2400m 以上）はスタミナ +3 だが、その間の馬には何も無い。総合力にして 1 ほど低い。

小さいので式はそのまま（知らせだけ）。
