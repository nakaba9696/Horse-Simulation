## おしゃれにするために入れた仕組み（`js/ui/audio.js`）
- 和音：9th・11th・13th・#9・♭9・#11・6/9、分数コード。テンションの多い和音はベースに根音を任せて抜き（ルートレス）、前の和音に近い転回形を選ぶ（声部のつながり）。隣り合う半音は避ける
- 拍：16分の食い（次のコードを16分・8分先取りする）、ゴーストノート、ハイハットとシェイカーの強弱、曲ごとのスウィング
- 音：曲ごとの響き（低い所は響かせない）、左右に跳ねる山びこ、左右の広がり（コーラス）、キックに合わせたうねり、区切りのフィルターの掃きと吹き上がる雑音、出口の EQ
- 物差し：`node tools/bgm_check.js --stats` で帯域の配分・左右の広がり・8小節ごとの音量を出す。`node tests/run.js` が和音の色（7th 以上の割合）と拍の裏の音の割合を確かめる
