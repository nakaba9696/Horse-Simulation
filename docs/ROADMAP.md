# ターフの系譜 ロードマップ（並行作業の分け方）

配り役（`/dispatcher`）が項目を配るときの正本。**子は読むだけで、チェックを編集しない**（更新は「ドキュメントのまとめ」の子が 1 本の PR で行う）。

## レーン
同じレーンの中は順番に、別のレーンは同時に。記号は issue の題（`M3: …`）とラベル（`lane:M`）に使う。
| 記号 | レーン | 書き換えてよいファイル（関数） | 同時に動かせる本数 |
|---|---|---|---|
| C | 中心の仕組み | `js/core/world.js`・`horse.js`・`util.js` | 1 |
| M | 仕組み（配合・レース・模擬） | `js/core/pedigree.js`・`races.js`・`racesim.js` | 2 |
| D | データ（史実） | `data/**`（新しいファイルを足すなら `index.html` の scripts も） | 3 |
| V | 絵・レース映像 | `js/ui/art.js`・`js/ui/raceview.js` | 1 |
| U | 画面（UI） | `js/ui/screens.js`・`js/ui/app.js`・`css/style.css` | 1 |
| T | CI・ツール・テスト | `tests/**`・`.github/**` | 1 |
| W | 設計書・まとめ | `docs/**`・`CHANGELOG.md` | 1 |

## 共有ファイルと、番号の範囲
| ファイル | 触り方 | 番号の範囲（係ごと） |
|---|---|---|
| セーブの形（`World.newGame` の G・`World.migrate`） | 項目を足すだけ。足したら migrate に既定値 | — |
| `index.html` の scripts | 追記だけ（並び順に注意） | — |
| `data/historic_*.js` | 生年ごとのまとまりに追記 | — |

## 衝突を避けるための約束
- 共有ファイルは追記だけ。消す・並べ替えるのは単独の期間を取る。
- セーブの版・読み込み順が重なったら、**後から入る側が振り直す**。
- 自動プレイの集計（史実どおりの割合など）が変わる PR は、PR の説明に前後の数字を書く。
- main の取り込みは merge（rebase・force-push はしない）。
- 史実のデータを直すときは、PR の説明に出典を書く。
