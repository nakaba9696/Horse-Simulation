# 騎乗の手ざわり（FEEL）

騎乗の画面の「手ざわり」の決まり。JS 版（`js/ui/ride.js`・`js/ui/race3d.js` のカメラ・`js/ui/rumble.js`・`js/ui/audio.js` の効果音）の今の値と、Godot 版の騎乗を作るときの目標を書く。数は JS 版で入れた値（★）か、目標（◎）か、仮（仮）かを付ける。

持ち主の指摘（2026-10-16、そのまま）：「全体的に細かいところがひどい」「人間が遊ぶ手触りになってない」「ムチうつとガクガクゆれる」「パッドの移動十字キー？　横移動できない」「溜めてるとか折り合ってるとか表示いらない」「折り合いゲージとかダサいのでもっときれいにして」「ゴールしたら少し走ってから順位表示して」。

## 0. 元にしたもの（作品の名前・絵・文はリポジトリに入れない）
- **古典的な騎手が主役の3D競馬ゲーム**：動画を落とす道具（yt-dlp）がこの環境に無く、動画は見られなかった。説明書の写し・攻略・レビュー・百科事典の記事から、次を確かめた（事実）：
  - 操作：十字の上＝スタートと手綱をしごく（1回で小さく、連打で大きく効く）、下＝引く、左右＝寄せる。左右のムチは別のボタン、持ち替えも別のボタン（逆の手のムチを押すと自動で持ち替える作品もある）。肩のボタンで左右を見る・レーダーの範囲。視点のボタン。振動に対応。
  - スタートは「ready」の合図が3回出て、4回目のころにゲートが開く（予告して合わせさせる）。
  - 後の作品では、スタミナの棒を「手応え」の棒に変えた（道中で溜めた手応えが終いの伸びになる）。速さの計器は「白と赤の境目が理想、赤は追いすぎ」の帯で見せる。馬の顔の表情で気持ちを見せる。
  - レビューでいちばん叩かれた点：計器が多く抽象的で「ごちゃごちゃ」、体で感じる興奮に欠ける、手綱とムチの感覚がつかみにくい。→ **計器は増やさず、まとめて、体（揺れ・音・振動・馬の動き）で返す**。
- **ゲームデザイナーの講座（UI・操作感の回）**：書き起こし・回の説明・週ごとのまとめ記事・コラムの英訳から（動画そのものは見ていない）。使った教え：
  1. 大事な瞬間は一瞬止める（ヒットストップ）。止める長さには上限。当たった側を強く揺らす。
  2. 揺れは最初が大きく、だんだん小さく（揺れの総量を先に決めて割り振る）。地面の上のものは左右に揺らす。カメラが近いほど小さく、遠いほど大きく。揺れている間も判定は動かさない。
  3. 押した感じ（重さ）はゲームの側で作る。構え（予備動作）は一瞬で大げさに。
  4. ボタン1つでできる遊びは4つ（連打・タイミング・反応・押し続けと離し）。→ しごく＝連打、ゲート＝タイミング、進路＝押し続け。
  5. ラグをなくす。1コマ（1/60 秒）を単位に考える。
  6. 効果音の大きさは派手さでなく大事さで決める。立ち上がりは強く、残響はほどほど。光を使いすぎると画面がぼやける。
  7. 言葉がなくても分かるように。大事なものとそうでないものを見た目で分ける。わかりやすさと格好よさを両立させる。
  8. 映像は必ず飛ばせる・止められるように。画面の切り替えは素早く。遊ぶ人の時間をいただいている。
  9. ギュッとしてパッと解消（緊張と解放）。予告すると合わせる楽しみが生まれる。

### 揺れ（`ride.js` の `kick`。3D のカメラだけを動かし、画面の箱・計器は揺らさない）

## 4. 計器のデザイン（騎乗中の画面）
原則 ◎：
- 計器は4か所だけ（左上・上の真ん中・右上・右）と左下の1つの塊。新しい計器は足さず、今の計器の中に入れる。
- 文字は短い英語の見出し（STAMINA・FIGHT・WHIP・PACE・TIME・RECORD・TO GO）と数だけ。日本語は馬名と特殊能力の名前だけ。
- 板は暗いガラス（上 rgba(14,30,23,0.82)→下 rgba(6,14,11,0.72)）に金の細い線（rgba(242,217,142,0.6)）。角を1つ斜めに落とし、上の縁につや。升は斜め（高さの 0.35 だけ傾ける）で、光っている升は同じ色の光をにじませる。
- 色の役目：良い＝緑 #57d17f・注意＝金 #ffd34d・悪い＝赤 #ff5a4d・抑え（落ち着き）＝青 #5fb4ff・速さ＝水色 #7fe6ff。同じ意味には同じ色。
- 数字は太い斜体。順位・時速・着順は大きく。

| 何を | どこに | どんな形で |
|---|---|---|
| 速さ | 左下の丸い計器（半径 56）の外の輪 | 下の空いた 270° の 30 の目盛り。巡航の速さに金の目盛り。巡航より下は青、上は水色、追い出したら金に光る。真ん中に時速（km/h）の数 |
| 気性（折り合い） | 丸い計器の内の輪 | 青（〜35）・緑（〜55）・金（〜75）・赤の4つの弧。今の所まで灯り、白い光る玉。高ぶるほど・掛かるほど玉が不規則に震え、手綱とケンカすると大きく暴れる。掛かると赤の弧と計器の縁が脈打つ。折り合うと輪全体が青く静かに光る |
| 手綱の段 | 丸い計器のすぐ右 | 上に ▲ 4つ（しごく。金）、下に ▼ 4つ（引く。青）、真ん中に横線。押した瞬間に白く光る |
| スタミナ | その右の板の上の段 | 8つの斜めの升。5つ以上は緑、3〜4 は金、2つ以下は赤で点滅。1つ減った瞬間、その升が白く光って浮きながら消える。空なら赤い枠だけが点滅 |
| 気合 | 板の下の段 | 12 の小さな斜めの升。橙→金→白に燃え、上がっている間は揺らめいて火の粉が立つ。ひるむと青い帯 |
| ムチの手 | 板の右下 | L・R の札。持っている手が金。持ち替えの間は点滅。下に打った数の点（12まで）。効きが落ちるほど暗く |
| 脚質（得意な位置） | 右の馬群レーダーの脇 | 金の括弧と薄い帯。その馬の脚質の位置（馬群を4つに分けたうちの1つ）。いまその中にいると濃く光る。自由自在の馬は出さない |
| 前が壁 | レーダーの自分の印の前 | 赤い短い線が点滅 |
| 順位・残り | 左上の板 | 順位の大きな数と st/nd/rd・頭数。残りの数（m）と、スタートからゴールまでの帯（200m ごとの目盛り・最後の直線は金・今の所に光る点） |
| ペース | 上の真ん中の板 | **先頭がチェックポイント（600m・1000m・1200m 通過。距離で決まる）を過ぎたときだけ 4.5 秒出す**。通過の距離と時計・SLOW/EVEN/HIGH・青→金→赤の目盛りの白い印。それ以外は出さない（持ち主の指摘 2026-10-17「常にわかるとつまらない。プレイヤーの読みに委ねたい」）。見込み（逃げ馬の数から）は出さない |
| 時計 | 右上の板 | TIME（大きく）・RECORD（小さく、金） |
| 馬群 | 右の縦長のレーダー | 上が前。自分は紫で光る。照準は白い輪、競り合いの相手は橙の輪。下に照準の馬の番号・順位・名前 |

前の形の悪いところ（直した）：日本語の見出し（スタミナ・速さ・手綱・ムチ・気合・脚質・気性）が並び、気性は小さな半円の針、手綱は「▲▲」の文字、脚質は4つの矢印。画面の真ん中に「折り合っている」「ためている」「追い出した」「前が壁」などの札が出ていた。

## 5. ゴールのあとの流れ
1. ゴール板：白い光・goal の音・cross の振動。**時は止めない・遅くしない**（持ち主の指摘 2026-10-17「ゴールしたあと止まらないで」）。**着順はまだ出さない**（左上の順位とレーダーの順位も伏せる）。
2. 流す（★ 2.4 秒 `HS.Ride.COOL`）：馬は映像の側で走り続ける。止めず、毎秒 0.8m/s ずつ駈歩の 8.5m/s（`HS.Ride.COAST_V`）まで落とし、そのまま流す（中継の画面も記録の最後のコマの後を同じように流す）。ゴールしていない馬も模擬が止まったら同じように流す。騎乗の視点ならカメラが引きながら斜め横へ回る。画面の下に小さく「[A] SKIP ▶」。
3. 着順：帯が左右から伸び、着順の数字が叩きつけられ、TIME と LAST 3F、「[A] NEXT [Y] POSE」。1着は金の帯と光、rank1 の音・win の振動。レコードなら 0.5 秒あとに RECORD。
4. 次へ：A・Enter・Start・画面を押すと結果へ。流している間に押すとすぐ着順へ（2回押せば結果まで飛ぶ）。
- 目標 ◎：ゴールから着順まで 2〜3 秒。飛ばすと 0.35 秒。着順から先は押すまで待つ（自動では進めない）。

## 6. 採点の物差し（直すたびに 1600×1000 で撮って付ける）
5つの軸を 0〜4 点で付ける。**合計 16 点以上、かつどの軸も 3 点以上**で合格。

| 軸 | 4 点 | 3 点 | 2 点 | 1 点以下 |
|---|---|---|---|---|
| A. ひと目で状態が分かる | 止め絵を1秒見て、順位・残り・スタミナ・速さ・掛かりの有無・手綱の段・得意な位置にいるかが全部言える | 1つ迷う | 2〜3 迷う | 4つ以上分からない |
| B. 騎乗中に文字で結果を出さない | 騎乗中に出る文字が短い英語の合図・見出し・数・馬名・特殊能力の名前だけ | 日本語の状態の文字が1種類ある | 2〜3 種類 | 4 種類以上 |
| C. 計器が派手で締まっている | 板・色・升の形がそろい、光る所は大事な所だけ。左下が1つの塊。見出しと数の大きさに差がある | そろっているが光が多すぎるか地味 | 板や色が場所ごとにばらばら | 文字の並び・枠だけ |
| D. 操作から反応まで速い | すべての操作が 2 コマ以内に光・音・振動のどれか2つで返る。揺れは小さくなめらか | 1 つの操作が1つでしか返らない | 返らない操作がある、または揺れがガクガク | 押しても何も見えない |
| E. 待たせない・飛ばせる | ゴールから着順まで 3 秒以内、どの待ちも押せば飛ぶ。一時停止できる | 飛ばせない待ちが1つ | 3 秒を越える待ちがある | 長い待ちが飛ばせない |

自己採点（2026-10-16）：
- 前の形：A 2・B 0・C 1・D 2・E 2＝7 点。
- JS 版の今の形：A 3（掛かりの有無は内の輪の色と縁で分かるが、小さい画面では玉の位置が読みにくい）・B 4・C 3（左下の塊はそろったが、上の真ん中のペースの板が細く地味）・D 4・E 4＝18 点。
- Godot 版で上げたい所：A の気性の玉を大きく、C のペースの板を丸い計器と同じ作りに。
- Godot 版（2026-10-17・`docs/shots/godot/v2/`）：前の形 13 点 → A 3・B 4・C 3・D 4・E 4＝18 点。気性の玉を大きくし、ペースの板を斜めの升にした。

## 7. 確かめ方
