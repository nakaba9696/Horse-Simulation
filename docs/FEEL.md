# 騎乗の手ざわり（FEEL）

騎乗の画面（`js/ui/ride.js`・`js/ui/race3d.js` のカメラ・`js/ui/rumble.js`・`js/ui/audio.js` の効果音）を直すときに読む。
持ち主の指摘（2026-10-16）：「全体的に細かいところがひどい」「人間が遊ぶ手触りになってない」「ムチうつとガクガクゆれる」「パッドの十字キーで横移動できない」「溜めてるとか折り合ってるとか表示いらない」「折り合いゲージとかダサい」「ゴールしたら少し走ってから順位表示して」。

元にしたもの：古典的な騎手が主役の3D競馬ゲーム（操作の割り当て・計器・レビューでの評判）と、ゲームデザイナーの UI・操作感の講座（ヒットストップ・揺れ・入力・情報の出し方・待たせない）。作品の名前・絵・文はリポジトリに入れない。調べた中身の控えは配り役への報告にある。

## 教え → このゲームでの形

### 1. 押したら、その瞬間に何かが返る
- 教え：ボタンの重さはゲームの側で作る。押した瞬間に見た目・音・振動のどれかが動かないと「効いていない」と受け取られる。構えは一瞬で、大げさに。
- このゲーム：
  - しごく・引く：押した瞬間に手綱の段の矢印（▲▼）が白く光り、カチッと鳴る。段が上がると矢印が金（しごく）か青（引く）で灯る。
  - ムチ：騎手の腕が振れ（race3d の骨の動き）、音・振動・打った側の端の短い光。カメラは打った側へ半周期だけ押されてすぐ収まる。
  - 進路：振動を軽く1回と、風を切る小さな音。カメラは動く向きへ少し傾き、遅れてついてくる。
  - ぶつかり：重い振動と鈍い音、カメラが相手と反対へ小さく押される、レーダーの自分の印に赤い輪。

### 2. 揺れは小さく、なめらかに、だんだん小さく
- 教え：揺れは最初が大きく、だんだん小さくする。地面の上のものは左右に揺らす（上下に揺らすと足がめり込む）。カメラが近いほど小さく。揺れている間も当たり判定（ここでは計器と操作）は動かさない。
- 前の形の悪いところ：ムチのたびに画面の箱ごと（計器も）を整数のピクセルで 160ms 揺らしていたので、ガクガクに見えた。
- 今の形：画面の箱は揺らさない。3D のカメラだけを、減衰する正弦（包み (1−u)²）でずらす（`ride.js` の `kick`・`race3d.js` の `orbit.shake`）。騎乗のカメラは馬のすぐ後ろなので、ムチは 3cm・0.26 秒、ぶつかりで 9cm・0.38 秒まで。計器は止まったまま読める。

### 3. 大事な瞬間は一瞬止める（ヒットストップ）
- 教え：当たった瞬間・倒した瞬間に一瞬止める。止める長さには上限を付ける。
- このゲーム：ゴール板を過ぎた瞬間、時の進みを 0.16 秒だけ 15% に落とし、画面が白く光る。着順を出す瞬間は数字が大きく叩きつけられ、白く光る。

### 4. 入力を取りこぼさない
- 教え：反応の遅れ（ラグ）は手ざわりを壊す。少し早く押した入力は受け付ける。
- このゲーム：
  - ゲートが開く 0.15 秒前からの ↑ は覚えておいて、開いた瞬間に受け付ける。それより前の ↑ は受け付けない（連打の運でなく、数え 3・2・1 の音と数字に合わせて押す）。
  - パッドは、標準の並びの十字（12〜15）・左スティック・標準でない並びの十字（hat の軸 `axes[9]`、`axes[6]`・`[7]`）を全部読む（`HS.Ride.padDirs`）。つながっているコントローラーは全部見る（中身の無い機器が先に並ぶ端末がある）。
  - 進路の ←→ は押し続けると続けて動く（はじめはすぐ、0.28 秒からは 0.2 秒ごと）。しごく・引くは連打の速さに意味があるので、押しっぱなしでは続けない。
  - ゴールの直前から連打していても、ゴールのあとの「次へ」はすぐには飛ばない（0.35 秒は受け付けない。Space は「次へ」に使わない）。

### 5. 何が起きたかは、ひと目で（文字で説明しない）
- 教え：言葉がなくても分かるように。大事なものとそうでないものを見た目で分ける。計器が多く抽象的だと「ごちゃごちゃ」と言われる（古典の騎手ゲームのレビューでいちばん叩かれた点）。
- このゲーム：騎乗中の日本語の状態の文字（「前が壁」「掛かっている」「折り合っている」「追い出した」「外を回っている」「ためている」「バテた」「発動！」）は全部消した。代わりに：
  - 掛かり：丸い計器の内の輪（気性）が赤く脈打ち、計器の縁と画面の縁が赤く光る。
  - 折り合い・ため：内の輪の光る玉が青い所にあり、手綱の段の ▼ が青く灯る。
  - 追い出し：外の輪（速さ）が金に光り、画面の端に速さの筋。
  - 前が壁：レーダーの自分の印の前に赤い線が点滅。
  - バテ：スタミナの升が赤く点滅し、空になると赤い枠だけ。
  - 得意な位置（脚質）：レーダーの脇の金の括弧。いまその中にいると濃く光る。
  - 特殊能力：真ん中に札（名前だけ）と集中線・縁の光。0.8 秒で右上へ退いて残る。近くの馬の発動はレーダーの輪。
- 出す文字は短い英語の合図だけ（START・GOOD START・LATE START・FIGHT・視点の名前・着順・RECORD・計器の見出し）。

### 6. 計器は少なく、締まった形で
- 左下に1つの塊：丸い計器（外の輪＝速さ。巡航の速さに金の目盛り。真ん中＝時速の数）・内の輪（気性）、その右に手綱の段（▲4つ・▼4つ）、スタミナ（8つの斜めの升）、気合（12の升。燃えると火の粉）、ムチの手（L・R の札と打った数の点。効きが落ちるほど暗く）。
- 左上：順位（大きな数と st/nd/rd）と頭数、残りの数（m）と、スタートからゴールまでの帯（ハロンごとの目盛り・最後の直線は金）。
- 上の真ん中：ペースの目盛り（判定の前は白抜きの印と「?」、判定のあとは光る印と SLOW・EVEN・HIGH）。
- 右上：TIME と RECORD。右：馬群レーダー。
- 板は暗いガラスに金の細い線、角を1つ斜めに落とす。升は斜めにして速さを感じさせる。数の色は「良い＝緑・注意＝金・悪い＝赤・抑え＝青」でそろえる。

### 7. 待たせない。飛ばせる
- 教え：映像は飛ばせる・止められるように。画面の切り替えは素早く。遊ぶ人の時間をいただいている。
- このゲーム：ゴールしてすぐ順位を出さない。ゴール板を過ぎると馬は流して減速し（駈歩から常歩へ。映像の側で）、騎乗のカメラは 1.8 秒かけて引きながら斜め横へ回る。2.4 秒（`HS.Ride.COOL`）で着順を出す。流している間に A・Enter・画面を押すとすぐ着順へ、着順で押すと結果へ。

### 8. 予告する（緊張と解放）
- 教え：ギュッとしてパッと解消。何が来るか分かると、合わせる楽しみが生まれる。
- このゲーム：ゲートの中は 3・2・1 の数字と音。開いた瞬間に START と小さな揺れ。

## 直すときの確かめ方
- `NODE_PATH=$(npm root -g) node tools/shot_feel.js docs/shots/feel after [--video]`：画面の時計を道具の側で進めて、ゲート・向こう正面・ムチ・流している所・着順の5枚（1600×1000）と、ムチから着順までの動画を撮る。遅い描画でも、遊んだときと同じ時の流れの絵になる。
- 揺れを足すときは `kick({ dur, hz, ax, ay, fov, roll })` を使い、画面の箱（DOM）を揺らさない。
- 騎乗中に新しい文字を出したくなったら、まず計器・レーダー・光・音・振動で返せないかを考える。
