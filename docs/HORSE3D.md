# 3D の馬の作り方（Three.js 版で分かったこと・Godot へ移す手順）

Three.js 版（`js/ui/horse_rigged.js`・`js/ui/race3d.js`）で、骨入りの素材の馬をサラブレッドらしく見せ、動かすまでに分かったことをまとめる。Godot 4 に移すときは、上から順に同じことをすればよい。絵は `docs/shots/horse3d_v2/`（big/before〜after4・video・fight）。

## 1. 素材

- `assets/horse_rigged.js`：Sketchfab「Horse Rigged (Game Ready)」（abhayexe・CC-BY-4.0）。GLB を base64 にしたもの。元の GLB は `tools/pack_horse.py` が作る（陰影の絵を R に焼く。G は空）。クレジットはタイトルの「クレジット」と `assets/CREDITS.md`。
  - Godot では GLB をそのまま読み込めばよい。CC-BY の表記は残す。
- 骨は 3ds Max の Biped（`Bip01_*`）で 42 本。名前の末尾の `_数_数` を外し、空白と `_` を除いて引く（`HR.keyOf`）。
  - 使う骨：Pelvis・Spine・Spine1・Neck・Neck1・Head・Ponytail2（両耳の先）・L/R Clavicle・UpperArm・Forearm・Hand・Finger0（前脚。Finger0 がつなぎ）・L/R Thigh・Calf・HorseLink・Foot・Toe0（後脚。Toe0 がつなぎ）・Tail〜Tail3。
- 座標：素材は +Z が前・+X が馬の左・+Y が上。地面が y=0。ゲームの馬は +X が前なので、Y のまわりに 90° 回して置く。

## 2. 比を直す（読み込んだあと1回。`prepare`）

素材のままだと脚が太く短く、首が細長く、頭が大きい。頂点と骨の位置を写して直し、`skeleton.calculateInverses()` で結び直す。頂点は骨の重みで、骨ごとの写し方を混ぜる。

| 部分 | 写し方 | 値 |
|---|---|---|
| 脚 | 骨の軸のまわりに細くする（上腕・脛 0.84、膝・飛節から下 0.7〜0.75） | `LEG_UP`・`LEG_LO` |
| 高さ | y0＝0.9 m より下を KY 倍に伸ばし、上はその分持ち上げる | `Y0 0.9`・`KY 1.08`（1.12 だと脚が長すぎた） |
| つなぎ | 球節より下を、下ほど前へずらす（蹄の底は平らのまま） | `PASTERN 0.55` |
| 首 | 首の軸に沿って 1.02 倍、太さ 0.98（横 0.9）。付け根ほど太く（最大 +20%）、首全体を前へ約3°倒す | `NK` |
| 頭 | 0.8 倍。首の倒れに合わせて動かし、付け根のまわりに約3°起こして鼻先を前へ | `HK`・`NK.nose` |
| 胴 | 横を 0.94 倍。腹は帯の後ろで 1.5 cm 下げる（前は持ち上げていて胴が浅く見えた） | `BODY_X`・`belly` |
| 素材の尾 | 平たい板なので、尾の骨（tail1〜3）が主の頂点のうち UV の島（u>0.6・v 0.43〜0.61）を付け根の一点につぶし、毛の房で描き直す | |

写したあとに寸法を測っておく（き甲・背・膝・飛節・球節の高さ、鼻先、胸の前、尻の後ろ、腹の下）。置く大きさは、鞍の下の背の高さと胸の前を手作りの馬に合わせて決める（`P.place`）。

見比べで分かった大事な点（参考の絵と同じ角度で撮って比べた）：
- 首は付け根を太く、のどへ細く。細い筒のままだと「キリン」に見える。
- 胴の深さ（き甲〜胸の底）は肘から下の脚とほぼ同じ。脚を伸ばしすぎると棒に見える。
- つなぎは斜め。まっすぐだと棒に見える。
- き甲と尻はほぼ同じ高さ。

## 3. 毛色（素材の絵は使わず、シェーダで塗る）

- 素材の絵は陰影（R×2 を明るさに掛ける）だけに使う。色は手作りの馬と同じ毛色の表（`HS.Art.coatLook`）から、頂点の元の位置（写す前でなく写した後の rest 位置）で塗る。
  - 腹 → 体 → 背（背の上 0.1 m で top を半分混ぜる）、脚先（膝・飛節から下）、白い靴下（脚ごとに名前から高さを決める）、蹄、鼻先、額の白徴（星・流星・作）、芦毛の連銭（3D の雑音）。
- つやは抑える（持ち主の指摘「つやつやしすぎ」）：roughness 0.78−0.08×gloss、環境の映り込み 0.6。
- 遮蔽の陰：下を向いた面・脚の内側・腹より下を暗く（最大 38%）。これが無いと平たく見える。
- Godot では ShaderMaterial（spatial）に同じ式を書く。頂点の rest 位置は CUSTOM0 などに入れて渡す。

## 4. たてがみ・前髪・尾（透ける細い板を重ねる）

体の面に線を飛ばして（Raycast）置き、当たった三角形の骨の重みをそのまま板の頂点に写す。これで首を上げても埋もれない（板を骨1本で動かすと首の上が体に埋もれた）。

- 毛の絵：64×256 の canvas に細い毛を 46 本。毛先は長さがばらけて透ける。alphaTest 0.3、両面。色は毛色の表のたてがみの色を少し明るく（真っ黒にしない）、板ごとに明るさのむら（頂点色）。映り込みは弱く（0.3）。
- たてがみ：き甲の少し後ろから、うなじ（頭の骨の位置）まで 100 か所。1か所に 3 束、首の右（カメラの側）へ垂らす。
  - 首の断面のまん中から、向き θ（0＝上、＋＝右）へ線を飛ばして面を拾う。
  - 長さは首の上の線からの「落ち」で測る（6〜11 cm）。面に沿った長さで測ると、首の上が平たいので横に寝てしまう。
- 前髪：額のまんなかから扇に 13 束、長さはまちまち。
- 尾：付け根の少し前（尾根の中）から 46 束。付け根を包み、なかほどで広がり、毛先へ細く。長さは飛節の下 22 cm まで。尾の骨の並びに沿って骨2本で動く。
- Godot では同じ形を ArrayMesh で作り、Skeleton3D に結ぶ（頂点ごとに BONES・WEIGHTS）。

## 5. 頭絡（細い革と金具）

- 頭の面に線を飛ばして輪を拾い、幅 2.4 cm・厚み 4 mm の帯（上の面と両の縁）にする。色は茶色の革、金具は灰色（頂点色）。
- 項革（耳の後ろ）・額革・鼻革（ぐるり）、頬革（耳の下 → 口の端のハミの輪まで、頬の面にまっすぐ写す）、額革と頬革のつなぎの小さな輪、ハミの輪。
- 前は黒い太い線で「描いた」ように見えた。細く、面に沿わせ、少し厚みを持たせると革に見える。

## 6. 動き（手作りの骨の角度を、素材の骨へ写す）

動きは手作りの馬の骨（`race3d.js` の `poseHorse`。骨 0〜23）で作り、`HR.pose` で素材の骨へ写す。

- 写し方：手作りの骨の z の回転を、素材の骨の中での「馬の横の軸」（世界の −X を骨の中の向きに直したもの）のまわりの回転として掛ける（`P.axis`）。尾は手作りの立ち姿の角度を 0 とみなす（素材の尾ははじめから垂れている）。
- 股（後脚の付け根）は 0.6 倍だけ回し、残りを後膝へ回す。股を大きく回すと素材の尻の皮が引っぱられて、付け根が伸びて見える。
- 蹄を地面へ：地面を押している脚の蹄の高さの重み付きの平均で、胴の高さを寄せる。4本とも浮く間は、いちばん低い蹄を少し上げる（`HR.settle`）。

### 襲歩（走り）

- 脚の角度は周期の折れ線を Catmull–Rom でつなぐ（`FK`・`HK`）。4拍子（左手前：右後 → 左後 → 右前 → 左前、そのあと4本とも浮く）。
- 硬さを取ったこと（持ち主の声「なんか硬い」）：
  - 関節ごとに少しずつ遅らせる：肩→肘→膝→球節、股→後膝→飛節→球節で、1周期の 0／1.8／3.6／5.5%（`LEG_LAG`）。
  - 腰のしなり：後脚が前へ踏み込むと骨盤が丸まり（尻が下がる）、蹴り出すと伸びる（後脚の付け根の角度の 0.38 倍）。背の骨（Spine 0.6・Spine1 0.4）がその分を戻すので、胴の前半と騎手は揺れない。
  - つなぎ：脚を畳むとき（球節が後ろへ折れるとき）、蹄が 0.55 倍遅れて後ろへ返る。
  - 首と頭：首の根元 → 首 → 頭の順に 0／3.5／7% 遅らせ、頭は胴の傾きにも遅れて付いてくる。
  - 尾：胴の上下に、根元から先へ 10／20／30% 遅れて波打つ。

### 常歩（ゆっくり）・立ち姿

- 常歩：4拍子（左後 → 左前 → 右後 → 右前）、脚は 62% の間地面に着く。前脚が着くたびに首がうなずき（1周期に2回）、尾は腰に遅れて左右へ振れる。4〜7 m/s で襲歩とまぜる。
- 立ち姿：息（1.7 rad/s）で胴がわずかに上下し、ゆっくり体重を左右へ移し、首と頭で見回し、ときどき尾を振る。

### 掛かりと耳

- 模擬の値：`sim.st[i].kakari`（0〜1）と `sim.st[i].ears`（−1〜1）。3D には `view.horses[i].kakari`・`.ears` で渡す（無いときは 0・0.3）。馬ごとに 1/3 秒ほどでなめらかに寄せる。
- 掛かり：首の根元・首・頭を上げ（走っている間は前へ伸ばした分も戻す）、鼻先を突き出し、頭を上下に煽り、首と頭を左右に振る（頭は首より遅れる）。騎手は上体を起こして腕を引く。
- 耳：Ponytail2 の骨（両耳の先。左右いっしょ）を馬の横の軸のまわりに 0.5×ears 回す。+1 で前へ立ち、−1 で伏せる。

## 7. 光と撮り方

- 肖像：日を頭の側の斜め上から（カメラの側からだと平たく見える）。空の光は弱め（0.4）。ACES、露出 0.95。
- 肖像は必ず 1600×1000 で撮り、前後を残す（持ち主の決定）。
- 動きは止め絵では伝わりにくい。連続のコマを並べた絵か、動画（800×450・15fps）で見せる。
- 参考作品の名前・絵はリポジトリに入れない。見比べの絵は作業場だけに置く。

## 8. Godot へ移す手順

1. GLB を `res://` に置いて読み込む。Skeleton3D の骨の名前を、上の名前で引けるように表を作る。
2. 2 の比を直す処理を、読み込み時に1回だけ走らせる（`MeshDataTool` か `ArrayMesh` で頂点を写し、骨の rest を置き直す）。または Blender で一度だけ焼いて GLB を作り直す（そのほうが速く、間違いも少ない）。
3. 3 の毛色のシェーダを書く（毛色の表は JSON にして共有する）。
4. 4・5 のたてがみ・尾・頭絡を、読み込み時に作る（Raycast は `PhysicsDirectSpaceState3D` でなく、三角形との当たりを自前で計算する。または Blender で焼く）。
5. 6 の動きは、手作りの骨を使わず、素材の骨へ直接書く。周期の表（`FK`・`HK`・`BOB`・`PITCH`・`NOD`・常歩の表）と遅れ（`LEG_LAG` など）をそのまま移せばよい。AnimationTree で作るより、毎フレームに式で骨の回転を置くほうが、模擬の値（速さ・手前・掛かり・耳）に合わせやすい。
6. 撮り比べ：同じ場面（`tools/shot3d.js` の場面）で Three.js 版と並べて撮る。
