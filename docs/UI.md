# 画面の決まり（騎乗の外の画面）

騎乗の外の画面（ホーム・厩舎・馬・番組表・馬の店・データ・メニュー・フリーレース・出走表）を作るときの決まり。
部品は `js/ui/uikit.js`（`HS.UI.kit`）、見た目は `css/ui.css`。色・字・余白・角丸は `css/style.css` の頭の変数だけを使う。
騎乗の画面（`js/ui/ride.js`・`race3d.js`）はここに入らない。

（持ち主の指摘 2026-10-16「店のUIが参考の作品のままで浮いている」「ほかのUIがわかりにくい」「フリーレースの馬選びもエディットのように能力値を出して並べ替え」「コース選択はもっと改善」「次走は番組表を出して選ばせて」「人間が遊ぶ手触りになってない」）

## 方針
- **一つの画面だけ参考の作品に寄せない。** 参考から取るのは手ざわり（並べ方・切り替え方・情報の量）だけ。全部の画面を、下の同じ部品でこのゲームの絵（深緑と金）で作る。
- **ひと目で分かる。** 一覧の1行は「名前・比べる数・状態の印」まで。長い説明は右の見本か、押して開く画面に置く。
- **押せる所が分かる。** 押せる物は厚みのある札（下に影、押すと沈む）か、行の札。押せない物に札の形を使わない。押せないときは理由を1行で出す（番組表の「年齢」「この週は予約あり」など）。
- **待たせない。** 画面の入りは 0.25 秒まで。毎週通る道（ホーム → レースへ → パドック → 発走）は決定の連打で進む。演出は押すと飛ばせる。
- **今の状態を見せる。** 上の帯にいつも「年目・月週・資金」。各画面の頭の帯の右にその画面の大事な数（資金・お手馬の数・毎月の費用）。

## 部品（`UI.kit`）
| 部品 | 関数 | 使い方 |
|---|---|---|
| 見出しの帯 | `K.band({ icon, title, sub, right })` | 画面のいちばん上に1つ。金の丸の印・明朝の題・ひと言・右に `K.stat` を並べる。騎手のゲームの「生産・レース・データ・記録・メニュー」は `UI.withBand` が自動で付ける |
| 帯の数 | `K.stat(見出し, 値, 'money'｜'warn')` | 資金は金、注意（お手馬がいっぱい）は橙 |
| タブ | `K.tabs(items, cur, act, attr)` | 両端に Q・E（パッドでは LB・RB）の印。前からある `.tabs` も同じ見た目にそろえた |
| 能力の数の札 | `K.num(v, title, big, lo, hi)` | 数の大きさで色（青 → 緑 → 金 → 赤）。能力は 50〜110、総合力は 40〜85 |
| 総合力（芝・ダ） | `K.fh(turf, dirt)` | 良いほうを芝の緑・ダートの茶で明るく |
| 値段 | `K.price(v, money)` | 金の字。資金が足りなければ赤 |
| 適性の印 | `K.mark(0〜3)` | ×△○◎（`HS.Program.fitDist`・`fitSurf`） |
| 並べ替えの見出し | `K.sortHead(cols, key, dir, act)` | 押すとその列で、もう一度で逆順。▲▼で向き。列の形は `HS.List`（`js/core/listsort.js`）と同じ |
| 選び肢の札 | `K.seg(label, opts, cur, act, k)` | select の代わり。十字キーで渡れる |
| 一覧の表 | `<table class="u-t">` | 行は1枚ずつの札。選んだ行は金の縁と左の金の線。月の区切りは `tr.u-month` |
| 二つの列 | `.u-split` ＋ `.u-side` | 左に一覧、右に見本（1100px 以上で横並び、右は付いてくる） |
| 右の見本 | 行に `data-pv="種類:鍵"`、板に `id="u-pv"` | 行に乗る・選ぶと `UI.previews[種類](鍵)` で中身が変わる（馬の店） |
| 操作の案内 | `K.keybar(extra)` | 右下に「↑↓←→ 選ぶ・Enter 決定・Esc もどる」。左に選んでいる札のひと言（`data-help` か `title`） |

## 色と字
- 色の役目：地 `--bg`・板 `--surface`/`--glass`・線 `--line`・強調の金 `--accent`（主な操作・選んだ状態・見出しの印だけ）・良い `--good`・悪い `--bad`・注意 `--warn`。芝 `--turf`・ダート `--dirt`。同じ画面に別の強調の色を足さない。
- 字の段：画面の題 26px（明朝）・節の見出し 17px（明朝）・本文と表 14〜15px・注記 12.5px・最小 11px。数は等幅（tabular-nums）。
- 文：見出しと札の名前は日本語。画面の中に英語の飾りの字を置かない（騎乗中の合図だけは英語）。説明は一画面に一つ、2行まで。

## 選ぶ操作（キーボード・パッド・マウス）
| 操作 | キーボード | パッド | マウス |
|---|---|---|---|
| 札を選ぶ | ↑↓←→ | 十字キー・左スティック（長押しで続けて） | 乗せる |
| 押す | Enter | A | クリック |
| 閉じる・もどる | Esc | B | 「もどる」 |
| タブを切り替える | Q・E（PageUp・PageDown） | LB・RB | タブを押す |

- **決定と戻るは全画面で同じ。** 小窓が開いていれば閉じる。画面が自分の「もどる」（`data-back`）を持っていればそれ。奥の画面なら一つもどる。タブの一番上ならホームへ。
- **タブは Q・E で端から反対の端へ回る。** 画面に `[data-lr]` があればそれを押し、無ければいちばん上のタブの隣を押す（`App.navLR`）。
- **カーソルの記憶。** 奥の画面へ進むとき、選んでいた札とスクロールの位置を覚え、もどったら同じ札に戻す（`App.go`・`App.back`）。
- **最初のカーソル。** キー・パッドで遊んでいるときは、画面を開いたら `data-autofocus` の札を選んでおく（ホームは「レースへ／次の週へ」、店と厩舎は1行目、番組表は最初に出走・予約できる行）。
- **取り返しのつかない確かめ（売る・引退・消す）は「やめる」を先に選ぶ。**
- **ボタンの名前は使っている道具に合わせる。** `body[data-input]`（key・pad・mouse）で、案内の印をキーの名前かパッドの名前に出し分ける。

## 画面ごと
- **ホーム**：上の管理の帯（騎手・リーディング・資金・暦・天気・レースへ）と大きなコマンドの札。その下に騎乗依頼・今週の騎乗・予約・お手馬・これからの G1・ニュース。
- **厩舎**：1頭1行（絵・名前・性齢とクラスと戦績・調子・総合力（いま）・次走・「番組表」）。行を押すと馬の画面。
- **馬の画面**：PC は左に絵と札（名前・血統・操作のボタン）、右にタブ（能力・番組表と次走・戦績・血統）。
- **番組表（次走）**：今週から1年先まで、月の区切りと週ごとの行。行は格・名前と条件・コース・距離と馬場の向き（◎○△×）・1着賞金・操作（出走する・予約する・取消、出られない理由）。絞り込みは「出られるレース／出られない重賞も」「重賞と条件戦／重賞だけ」「馬場」。仕組みは `js/core/program.js`。
- **馬の店**：帯（資金・お手馬）→ 牡馬・牝馬のタブ → 表（印・馬名・性齢・芝・ダ・距離・脚質・値段。見出しで並べ替え）と右の見本（能力・特殊能力・「買う」）→ 品ぞろえの広がり（鍵）。
- **フリーレース**：「① コースを選ぶ」（中央・地方・海外の札。札にはコースの形の小さな絵・回り・芝ダ。右で馬場・距離・状態・天気を札で選ぶ）と「② 出る馬を選ぶ」（能力の列の表。名前・年代・国・脚質・向きで絞り、見出しで並べ替え。行を押すと加える／外す。右に出る馬と「乗る」）。上の帯にいまの条件と「出走表へ」をいつも出す。

## 学んだこと（出典）
ゲーム作りの講座（桜井政博さんの YouTube「桜井政博のゲーム作るには」と、メニューについてのコラムの要約）から、このゲームの画面に使ったもの：
- 大事なものほど大きく。よく使う項目は大きな札に（ホームのコマンド・「レースへ」）。
- 色で区分を分ける。ただし同じ画面に色を混ぜすぎない（強調は金だけ）。
- 日本語は英語より大きく組む（本文 14〜15px より小さくしない）。
- カーソルが乗った項目には、決まった場所にひと言の説明（右下の案内の左）。項目名の言い換えは書かない。
- 押したら必ず反応を返す。反応しないボタンを作らない。押せないときは理由を出す。
- 決定・戻るの位置は事実上の標準にそろえ、全画面で同じにする。
- 遅さは罪。画面の切り替えは詰める。演出は飛ばせるようにする。
- 「何が効くか」を想像して選ぶ遊びでは、比べる数を並べて見せる（店・馬選びの能力の列と並べ替え）。

古典的な騎手ゲームの管理画面から取った手ざわり（作品の名前・絵は入れない）：
- 十字キーでカーソル、L・R で区分（ページ）の切り替え、決定と戻るの2つのボタンで全部の画面を回せる。
- 強さを1つの大きな数で見せ、細かい能力はその下に小さく置く。
- 後の作品で言われた不満（画面を挟みすぎ・説明の無い記号だらけ・飛ばせない画面）を作らない。
