# 画面の言語（日本語と英語）

持ち主の決定（2026-10-21）：「言語は日本語と英語にしたい」。Steam で 12 月 1 日に日本語と英語で売る。Godot 版だけに入れる（JS 版は作らない）。
この文書は、言語の切り替えの仕組み・文の足し方・データの英語の入れ口・用語の表。

## 1. 仕組み

| 場所 | 中身 |
|---|---|
| `godot/i18n/hs_text.gd`（`HSText`） | 言語（`HSText.lang`＝`"ja"`・`"en"`）と、文を引く関数の全部 |
| `godot/i18n/text_en.gd`（`HSTextEn`） | 英語の表。`T`（日本語の文 → 英語）・`SHORT`（狭い所の短い形）・`PATTERNS`（決まりの組む文の形） |
| `godot/ui/settings_store.gd`（`UiSettings`） | 言語の設定（`cur.lang`）。`user://settings.cfg` の `[general] lang` に書き、起動のたびに読む |
| `godot/ui/settings.gd` | 設定の画面の「言語」の行（画面の節の1行目。左右で替えると画面を組み直す） |
| `tools/i18n_keys.js` | 画面のコード（`godot/ui`・`godot/view`）の日本語の文を集め、英語の表に無い文を書き出す |

- **キーは日本語の文そのもの**（gettext の msgid と同じ考え方）。`HSText.t("出走表へ")` は、日本語のときは `"出走表へ"`、英語のときは表の `"Race Card"` を返す。日本語のときは何もしないので、日本語の画面は前と同じ。
- **共通の部品は自分で引く**：`UiTheme.label`・`title`・`num_label`・`chip`・`tabs`・`keybar`、`UiScreen.button`・`section`・`stat`・`toast`・`confirm`・`celebrate`、`UiGlyph` は、受け取った文を `HSText.auto()` で引く（ちょうどキーと同じ文なら英語）。だから `UiTheme.label("能力")` のような文は、表に足すだけで英語になる。
- **数を差し込む文**は、形をキーにしてから差し込む：`HSText.t("%d戦%d勝") % [starts, wins]`。英語の訳も `%s`・`%d` の数と並びを同じにする（GDScript の `%` は並べ替えられない。`%2$s` は使えない）。並びが英語で不自然になるときは、訳の言い回しを変える。
- **言語で変わる書き方**は関数にまとめた：着順 `HSText.ord(n)`（3着 → 3rd）、お金 `HSText.money(man)`（1億2,345万円 → ¥123,450,000）、月と週 `HSText.week_label(m, w)`（5月4週 → May W4）、年 `HSText.year_n(n)`（2年目 → Year 2）、日付 `HSText.date_label(y, m, w)`、性齢 `HSText.sex_age(h, age)`（牡3 → C3）、競馬場と距離 `HSText.course_dist(r)`（東京 芝2400m → Tokyo Turf 2400m）、出られる条件 `HSText.age_cond(r)`（3歳以上牝 → 3yo+ Fillies only）、着差 `HSText.margin(l)`、脚質 `HSText.style_text(h)`。
- **決まり（`godot/core`）が組んだ文**（ニュース・出られない理由・依頼の文・トロフィーの名前など）は `HSText.tx(s)` で引く。ちょうどのキーが無ければ、`PATTERNS` の形（`"%sが入厩した。"` など）に当てはめ、差し込まれた所（馬名・レース名・お金・日付）を引き直して英語の形に入れる。決まりのコードは日本語のまま（JS 版と同じ結果の一致テストを崩さない）。
- **狭い所**は `HSText.short(s)`（`SHORT` に無ければ `t`）。ホームのコマンドの札（Race Calendar → Calendar）・厩舎の札・能力の格子（Temperament → Temp.）。
- **言語で形を変える所**（字の大きさ・札の幅・1行を2行に分ける）は `HSText.is_en()` で分けてよい。英語の文そのものをコードに書かない（表に書く。`tests/extra_i18n.js` が見る）。
- **記録の鍵は日本語のまま**：リプレイの一覧の日付（`UiFlow.date_key`）・出走表の元のデータ（`UiFlow.desc` のレース名）は言語で変えない。画面に出すときに引く。

### 言語の決め方
1. 設定のファイルに `lang` があればそれ。
2. 無ければ（初めての起動）OS の言語：`OS.get_locale()` が `ja` で始まれば日本語、ほかは英語（`HSText.lang_for_locale`）。
3. 撮影（`--out=`）と headless（テスト）で設定のファイルに無いときは日本語（前の絵とテストが変わらないように）。
4. `-- --lang=en`（または `ja`）を渡すと、その起動だけその言語（英語の画面を撮るとき）。
- 「初めの設定に戻す」では言語は変えない。

## 2. 文の足し方・直し方
1. 画面のコードには日本語で書く（`UiTheme.label("新しい文")`、数を入れるなら `HSText.t("あと%d週") % n`）。直に `Label.text =`・`Button.text =`・`draw_string` に入れる文は `HSText.t()` を通す。
2. `godot/i18n/text_en.gd` の `T` に `"日本語": "English",` を足す（節の見出しのコメントの下、近い所に）。
3. `node tools/i18n_keys.js` で抜けが無いか見る（抜けた文と場所が出る）。`node tests/run.js` の「i18n:」の確かめも同じ。
4. 撮影の見本・記録の鍵など、訳さない日本語の行には `# i18n:skip` を付ける。
5. 決まり（core）が新しいニュース・理由の文を組んだら、その形を `T` に足し、`PATTERNS` にもキーを足す。英語で遊んで抜けを探すには `godot --headless --path godot -s res://tools/autoplay.gd -- --weeks=60 --lang=en`（最後に `i18n missing` の行が出る）。
6. 英語は短く、ゲームらしく。説明の文は命令形かそっけない言い方（"Select a horse to see details here"）。合図（START・GOOD START・視点の名前・着順）は前から英語で、どちらの言語でも同じ。

## 3. データの英語の入れ口（データの係と合わせた欄の名前）
画面は次の関数だけでデータの名前を出す。データに英語の欄があれば英語、無ければ日本語。

| 種類 | 関数 | データの英語の欄 |
|---|---|---|
| 馬名 | `HSText.horse_name(h)`（馬の辞書か名前） | 馬のデータ（`data/historic*.js` など → `godot/data/historic.json`）の `nameEn` |
| レース名 | `HSText.race_name(r)`・`HSText.race_label(r)`（短い名前） | レースのデータの `nameEn`（短い名前は `shortEn`。無ければ `nameEn`） |
| 競馬場名 | `HSText.course_name(key)`・`HSText.course_dist(r)` | `courses` の `nameEn` |
| 騎手名 | `HSText.jockey_name(j)` | 騎手のデータの `nameEn`（架空の名前の英語） |
| 特殊能力 | `HSText.skill_label(id)`・`HSText.skill_note(id)` | 特殊能力の `labelEn`・`noteEn` |
| 名鑑 | `HSText.profile_text(p)`・`HSText.main_wins(p)` | 名鑑の `textEn`・`mainWinsEn`（年代と戦績の欄は形で引く：「1964〜1965年」「8戦7勝」） |
| オーナーの台詞・名前 | `HSText.owner_line(s)` | まだ（いまは日本語のまま返す。データに英語が入ったらここで引く） |
| 名前のあるオープン | `HSText.race_label(r)` | 要らない（「3歳以上オープン（牝）」→ 3yo+ Fillies Open を形で作る） |

- ニュースなどに差し込まれた馬名・レース名も、同じ表（`nameEn`）で引き直す（`HSText.tx`）。
- トロフィー・スペシャルホースのグループ・GF の区分・成長型などのゲームの言葉は、データでなく `text_en.gd` の後半（godot/core が組む文）にある。

## 6. まだのこと
- データの英語（馬名・レース名・競馬場名・名鑑・特殊能力）は別の仕事。入るまでは日本語のまま出る。
- オーナーの名前・肩書き・台詞・ミッションの文（お手馬の段階）・GF の一族の人の台詞は英語の欄がまだ無い（`HSText.owner_line` が入れ口）。
- 騎手の架空の名前の英語（ローマ字など）はまだ。
- 実況の文（`godot/core/hs_sim.gd` の say）は形を表に入れたが、いまの画面では騎乗中に実況の文を出していない。
- 週の結果の背景の絵（3D を撮った絵）のゴール板の「ゴール」の字は絵の中にあるので替えていない。
- フォントは英数を含む（Noto Sans JP・Noto Serif JP）。英語だけの別のフォントにはしていない。
