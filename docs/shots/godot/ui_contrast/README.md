- 撮り方：`sh godot/tools/shot_screens.sh 出力先 --contrast`（1600×1000。決まった種の新しいゲームの見本 `--demo=1`。牧場は史実の名馬を引退馬に置いた見本）。

## 何を変えたか
- 押せる物（ボタン・行の操作の札・部品の絵の押せる行）を緑の仲間から外し、鞍の革の面・金の縁（四方 2px）・下の濃い影にした。選んだ物は明るい革と金の光。
- 読む板（面）を墨の緑にして、写真をほとんど透かさないようにした（84% → 93%）。
- 押せる物の行・ボタンを写真の上に直に置かず、面の台に載せた（番組表・店・出走表・厩舎・GF・データ・設定・オーナーの表、牧場の父・母の表、タイトルのメニュー、出走表の下のボタン）。
- 表の行は面より一段明るい地（並ぶ行には金の縁を付けない）にし、カーソルの行だけ明るい革と金の縁にした。
- 持ち主の部品の絵は、面だけを塗り替えた絵（`godot/assets/ui/role/`）を使う。もとの絵は変えていない。
