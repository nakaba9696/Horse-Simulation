# 番組表：1か月を1画面に（Godot 版・2026-10-24）

持ち主の指摘「番組表は情報量おおすぎてわかりづらい　第一週　第二週　第三週　第四週で列をわけてのそれぞれのG3-G1　欧州　その他　みたいな感じで表示して」「基本的にスクロールはさせないで　画面に収めてかつ情報量を抑えて」への対応。決まりは `docs/UI.md` 3「番組表」。

- 撮り方：`sh godot/tools/run_scene.sh res://scenes/program.tscn -- --demo=1 --out=出力先 --shot=1.2:名前`（1600×1000。決まった種の新しいゲームの見本）。`--month=k` で今月から k か月先を開き、`--book` でその月の最初に予約できるレースを予約しておく。GF の週は `--setup=gf`。
- `0_before.jpg`：直す前（週ごとの行を縦に並べ、スクロールする形）。
- `1_this_month.jpg`：今週の月（1月。1週は過ぎた週で細い列）。
- `2_later_month.jpg`：先の月（4月。予約した札は金の「予約済」・同じ週のほかの札は薄い）。
- `3_busy_month.jpg`：重賞の多い月（10月。欧州・その他の G1 が多く「ほか n」に回る）。
- `4_gf_week.jpg`：12月の GF の週（その週だけ5列目。過ぎた4週は細い列）。
- 押せる物の測り（`--contrast`）：1月 24 札・10月 49 札とも足りない 0（ボタンの面 2.17・縁 5.67・表の行の面 1.36）。
