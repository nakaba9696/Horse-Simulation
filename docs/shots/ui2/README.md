# 画面の見直し（2回目）：前と後

`before/` が直す前、`after/` が直した後。`mobile-*` はスマホ幅（390px）、`pc-*` は PC 幅（1280px）。Playwright（Chromium）で撮った。

## 前の画面で「ウェブのページ」に見えて安っぽかった所
- どの画面も同じ一色の深緑の地に、四角い板を積んだだけ。絵が無く、場所（厩舎・店・パドック・競馬場）の気配が無い。
- タイトルは小さな絵の帯と、縦に並んだ入力フォームのようなボタン。押して始まる「入り」が無い。
- PC では 880px の細い列の左右が、ただの暗い余白になる。
- ホームの大きなコマンドは平らな板と小さなアイコンで、押せる物に見えにくい。
- 馬の店は表計算の表。毛色も強さも値段も同じ大きさの字で、買い物の高揚が無い。
- 画面を替えても何も動かず、いきなり差し替わる（ページの再読み込みのよう）。
- 重賞を勝っても、結果の小窓に絵が一枚出るだけ。トロフィー・スペシャルホースはニュースの一行だけ。

## 直した所
- 背景の写真（`assets/ui_bg_*.js`。出典は `assets/CREDITS.md` の「画面の背景」）：タイトル＝夕暮れの草原、ホーム・厩舎＝干し草の納屋、馬の店＝夜の館、パドック＝木立、結果・見せ場＝スタンド。板は半透明にして写真が透ける。
- タイトル：大きな金の題字（光が走る）、写真がゆっくり寄る、柵の前を馬群が駆け抜ける、「クリック・Enter でスタート」（ゲームパッドのボタンでも）→ メニューが下から入る。
- 押せる物を厚みのある札に（下に縁の影、押すと沈む、金の札には光が走る）。下の並びは選んだ所が金のメダルになる。
- 画面の入り：タブを替えると金の光がよぎり、中身が下から入る。進むと右から、戻ると左から。
- 馬の店：順位・毛色の肖像・芝とダの総合力の札・値段を一行ずつ（並びと押すと馬の画面が開く仕組みは同じ）。
- パドック：木立の写真の前を馬が歩く。小窓の後ろにも写真。
- 見せ場（`after/*-22-win`・`23-trophy`・`24-special`）：回る光の筋・紙吹雪・判子のような札・大きな題字。クリック・Enter・ゲームパッドで閉じる。
- 十字キー・矢印キー・ゲームパッドで札を選べる。選んでいる札は金に光る（`after/pc1920-*`。Enter・A で押す、Esc・B で閉じる・もどる。騎乗中・パドックの左右・見せ場はそれぞれの画面が受け取る）。1600px 以上の画面では列を 1200px に広げる。
- 動きを減らす設定（prefers-reduced-motion）では、寄り・光・帯・紙吹雪を止める（紙吹雪は散った形を1枚だけ描く）。
