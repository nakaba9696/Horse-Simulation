# 掛かり・耳（素材の馬）

模擬の値 `sim.st[i].headUp`（0〜1。掛かり・ハミに逆らって頭を上げる。`S.moodOut`）と `sim.st[i].ears`（-1〜1。+1 前へ立てる・-1 伏せる）を、`view.horses[i].fight`・`.ears` で 3D の馬に渡す（`s.fight` は競り合いの気合 -40〜100 で別物なので使わない）。値が無いときは fight=0・ears=0.3（軽く前）。1コマで跳ばないよう、馬ごとになめらかに寄せる。

- `fight_ears.jpg`（1600×1000）：上の段が掛かり 0／0.5／1（首と頭を上げ、鼻先を突き出す）、下の段が耳 -1／0／+1（伏せる・ふつう・前へ立てる）
- `fight_run.mp4`（800×450・15fps・6秒）：走りながら掛かりが 0 → 1 → 0。首と頭を上げて左右に振り、騎手は上体を起こして手綱を引く。耳は掛かるほど伏せる

動き：首の根元と首・頭を上げ（走っている間は前へ伸ばした分も戻す）、頭を上下に煽り、首と頭を左右に振る（頭は首より遅れる）。騎手は上体を起こし、腕を後ろへ引く。耳は素材の両耳の先の骨（Ponytail2）を頭の横の軸のまわりに回す（左右いっしょ）。手作りの馬の耳は動かない。
