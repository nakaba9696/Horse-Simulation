# 馬の動きの動画（素材の馬・800×450・15fps・各6秒）

持ち主に動きの柔らかさを見せるための動画。after4 の動きの修正（関節の遅れ・腰のしなり・首と尾の遅れ・常歩・立ち姿の息）のあと。

- `run_side.mp4`：走る横（東京 芝2400 の残り900m から。自分の馬のまわりを回り込んだカメラ）
- `ride_rear.mp4`：騎乗の視点（後ろから）
- `walk_stand.mp4`：常歩で3秒ほど歩いて止まり、立ち姿（息・体重の移動・見回し・尾振り）
- `compare_run_side.mp4`：走る横の前と後（左が前・右が後。同じ時刻）
- `compare_walk_stand.mp4`：常歩と立ち姿の前と後（前は常歩が無く、ゆっくりでも襲歩を小さくしていた）

撮り方：Playwright の Chromium（ソフトウェア描画）でコマを連番の JPEG に撮り、ffmpeg で H.264 にした。描画の速さは実際の遊びの速さと関係ない（コマは時刻で決めている）。
