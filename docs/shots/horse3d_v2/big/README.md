# 肖像 1600×1000（持ち主の決定：肖像は必ずこの大きさで撮って前後を残す）

撮り方：`R3.portrait` に 1600×1000 の canvas（素材の馬・手作りの馬は `HS.HorseRigged.setModel('rigged'|'handmade')` で切り替える）。

- `before/`：たてがみ・尾を直す前（配り役が撮った絵）
- `after/`：たてがみを毛の房（首すじに沿って2層、毛先がぎざぎざ）に、尾を付け根から広がって毛先が細くなる房に、首の皮の毛の筋と黒い帯を消し、頭絡を素材の頭に合わせて作り直したあと。`head_鹿毛.jpg` は頭と首の寄り
- `after2/`：たてがみをうなじ（耳の後ろ）からき甲まで途切れずに首の右へ垂らし（首の上の線から 8〜15cm、毛先は透ける細い毛の束、毛色の表の色に明るさのむら）、前髪を足し、尾は付け根のこぶを毛で包んで飛節の下まで伸ばし、頭絡を細い茶色の革（幅 2.4cm・厚み 4mm）と小さな金具にしたあと。`rigged_<毛色>.jpg` が肖像（4毛色）、`head_鹿毛.jpg`・`neck_鹿毛.jpg`・`tail_鹿毛.jpg` が頭・首・尾の寄り（`R3.portrait` の3つめの引数 `view` でカメラを寄せる）
