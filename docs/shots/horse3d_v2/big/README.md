# 肖像 1600×1000（持ち主の決定：肖像は必ずこの大きさで撮って前後を残す）

撮り方：`R3.portrait` に 1600×1000 の canvas（素材の馬・手作りの馬は `HS.HorseRigged.setModel('rigged'|'handmade')` で切り替える）。

- `before/`：たてがみ・尾を直す前（配り役が撮った絵）
- `after/`：たてがみを毛の房（首すじに沿って2層、毛先がぎざぎざ）に、尾を付け根から広がって毛先が細くなる房に、首の皮の毛の筋と黒い帯を消し、頭絡を素材の頭に合わせて作り直したあと。`head_鹿毛.jpg` は頭と首の寄り
- `after2/`：たてがみをうなじ（耳の後ろ）からき甲まで途切れずに首の右へ垂らし（首の上の線から 8〜15cm、毛先は透ける細い毛の束、毛色の表の色に明るさのむら）、前髪を足し、尾は付け根のこぶを毛で包んで飛節の下まで伸ばし、頭絡を細い茶色の革（幅 2.4cm・厚み 4mm）と小さな金具にしたあと。`rigged_<毛色>.jpg` が肖像（4毛色）、`head_鹿毛.jpg`・`neck_鹿毛.jpg`・`tail_鹿毛.jpg` が頭・首・尾の寄り（`R3.portrait` の3つめの引数 `view` でカメラを寄せる）
- `after3/`：参考の絵（騎手が主役の古典的な3D競馬ゲームの、レース中とパドックの馬）と同じ角度で撮り比べて微修正したあと。`rigged_<毛色>.jpg` が肖像（4毛色）、`front34_鹿毛.jpg` が斜め前、`rear_鹿毛.jpg` が後ろ寄り、`run_side.jpg` が走る横（`tools/shot3d.js run_side`）

  参考と比べて変えたこと：
  - 首：付け根（胸前とき甲の間）を最大 2 割太くし、首全体を前へ約 3 度倒した。頭は付け根のまわりに約 3 度起こし、鼻先を少し前へ出した。参考の首も長めで立ち気味なので、倒しすぎない
  - 胴と脚：脚の伸ばしを 1.12 倍から 1.08 倍にした（置くときに背の高さで合わせるので、胴が相対的に深くなる）。前は胴の中ほどで腹を 5.5cm 持ち上げていたのをやめ、帯の後ろで 1.5cm 下げた
  - つなぎ：球節から下を前へ傾けた（下ほど前。蹄の底は平らなまま）。前はまっすぐな棒だった
  - たてがみ：首の上の線からの垂れを 8〜15cm から 6〜11cm に短くした。毛の映り込みを減らし（後ろから見て首の上が灰色に光らない）、色を少し明るくして真っ黒にしない
  - 尾：毛の束を 32 枚から 46 枚にし、1 枚を細くして板が見えにくくした
  - 陰：体の下を向いた面・脚の内側・腹より下を暗くする遮蔽の陰を、毛色の塗りに足した
  - 光：肖像の日を、カメラの側から頭の側の斜め上へ移した（肩・尻の張りに陰が付く）。空の光を少し弱めた
  - 参考と違って残したこと：参考は毛色がもっと濃い赤茶で、つやが強い。毛色の表は手作りの馬と共有で、持ち主の指摘（つやつやしすぎ）もあるので変えていない
