# オーナー（騎乗依頼をくれる人）の下書き

`data/owners.js` から `node tools/owners_draft.js` で書き出した一覧（手で直さない）。会話とミッション（依頼の馬とレース）はすべて下書きで、持ち主が読んで直す（仕様書 `docs/SPEC.md`「騎乗依頼」「持ち主の決定（2026-10-20・オーナーの依頼）」）。
直したい所は、この文書に書き込むか、そのまま伝えてくれれば `data/owners.js` に写す。`{me}` は騎手の名前、`{horse}` は馬名、`{race}` はレース名。台詞の頭の `[ダ]` などは「その場面のときだけ使う」印（ダ＝ダート・芝・短＝1400m まで・長＝2400m から・逃＝逃げ馬・差＝差し追込・牝＝牝馬・海＝海外）。

## 仕組み（数は仮）

- 出会いの点：その人のジャンルのレースを自分が乗って勝つと、点がたまる（OP 1点・G3 2点・G2 3点・G1 4点。合わせて4点で出会い）。出会いの場面は次の週の頭に出る。友好度（画面では数は出さず帯で見せる）は出会いのあとの仲の良さで、ミッションをやり終えるたびに上がる。
- 海外の人（米系・欧州系・豪州系）は「海外のレースに1度出た」印のあとで出会う（海外の解放の仕組みができたら差し替える）。
- 依頼はミッション形式：段階は OP → G3 → G2 → G1 → お手馬。OP〜G1 は「依頼の馬」と「レース」が決まっている（下の表）。レースの4週前に依頼が届き（場面）、依頼の馬がその人の馬として世界に出る。レースの週は依頼の馬に自分が乗る。勝てばクリアで、お礼のお金と友好度、会話の場面、次の段階のミッション（次のレースが近づいたら届く）。
- 負けた・見送ったときは、次の年の同じレースでもう一度（同じ馬。年齢や引退で出られなければ、出られる年齢で出し直す）。自分の馬が同じレースに出る予定なら、依頼が先で自分の馬の出走は取り消す。自分の馬に乗るなら、その年の依頼は見送り。
- 依頼の馬は、まだやり終えていないミッションのあいだ、ふだんのデビューと馬の店には出てこない。
- お礼（万円・1995年の物価）：OP 300・G3 600・G2 1000・G1 2000・お手馬 5000。G1 の段階になると、その人の勝負服を自分の馬に着せられる。
- お手馬の段階のミッション（自分の馬で）までやり終えると友好度がいっぱいになり、繁殖の永続のボーナスのアイテムをもらって、その人からの依頼は来なくなる。
- G3 の段階から、頼めば来月の馬の店にその人の好みの馬が並びやすくなる（牡馬・牝馬それぞれ3頭まで入れ替える）。
- 年末に、その年いちばん一緒に勝った人と「名コンビ賞」（2勝から）。

## GF を開いている一族の人（キンチェムモチーフ）

持ち主の決定（2026-10-19・改め）「キンチェムモチーフのキャラは別キャラでお願いします。GF を開催してる一族の謎の人物にします。ナビゲータはナビゲータです」。データは `data/gfhost.js`。

- 騎乗依頼のオーナーとは別で、依頼はしない。GF の場面（招待・GF の週・全部勝ったあと）にだけ現れる。
- アイテム：GF を全制覇したとき（6つの GF のトロフィーがそろったとき。年も馬も別でよい）、花輪をもう一つ渡す場面で「一族の花輪」（1頭の馬からオリジナルホースを作れる数＋1）を渡す（持ち主の決定 2026-10-20「生産可能数＋1はイロナのアイテム」「GF 全制覇でもらう」）。
- キンチェム本人ではない。名前や設定で「キンチェムそのもの」「馬の化身」とは書かない。キンチェムを思わせるモチーフで描く：花輪（勝った馬にかける）・栗色の髪・ハンガリー・無敗の牝馬の言い伝え・汽車の旅・黒い猫・「わたしの宝もの」（キンチェムはハンガリーの言葉で「わたしの宝もの」）。
- 一族の名と、本人の年・正体は明かさない（謎の人物のまま）。
- いま画面に出る所：Godot 版の GF の画面の右上（顔とひと言。場面は招待の前・招待・GF の週・全部勝ったあと）、JS 版の招待状。勝った・負けた・全部勝ったときの場面は、GF の結果の場面ができたら使う（GF の係と相談）。

- 名前：イロナ（いろな）・グランドフェスティバルを開いている一族の人・年：二十代の半ばに見える（本当の年は分からない）
- 人柄：栗色の長い髪に、白・桃・黄の花の花輪。黒い外套で、いつも少し遅れて汽車で来る。一族のことも自分のことも、ほとんど話さない。年に一度、GF の舞台にだけ現れ、勝った馬の首に自分で編んだ花輪をかける。足もとに黒い猫がいることが多い。
- 口調：一人称「わたし」・呼び方「{me}さん」・語尾 〜です・〜ます（静かでていねい。短く言い切る）・言わないこと：自分の正体や年を話す・一族の名を明かす・負けた馬を悪く言う
- 見た目（絵を描く手がかり）：髪 栗色（栗毛の色）の長い髪を下ろす・目 深い緑のやわらかい目・服 黒い長い外套・生成りのブラウス・小物 白・桃・黄の花の花輪・足もとの黒い猫・古い懐中の招待状。表情：ふだん 静かにほほえむ・ほほえみ 目を細める・喜び 花輪を差し出して笑う・残念 目を伏せる（それでもほほえんでいる）
