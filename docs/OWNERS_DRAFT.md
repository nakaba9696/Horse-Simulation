## 仕組み（数は仮）

- 好感度（0〜100。画面では数は出さず帯で見せる）は、その人のジャンルのレースで勝つと上がる（自分の馬でも依頼の馬でも）。まだ会っていない人は2着・3着でも少し上がる。10 たまると出会いの場面になり、次の週から依頼が来る。
- 海外の人（米系・欧州系・豪州系）は「海外のレースに1度出た」印のあとで出会う（海外の解放の仕組みができたら差し替える）。
- 段階は OP → G3 → G2 → G1 → お手馬。段階ごとの課題をやり終えると、お礼のお金と好感度、会話の場面、次の段階へ。課題をやらずに次の段階へは上がらない。段階が上がるほど格の高いレース・強い馬の依頼が来る（G1 の段階から海外の G1 と、その人のいちばん強い馬）。
- お礼（万円・1995年の物価）：OP 300・G3 600・G2 1000・G1 2000・お手馬 5000。G1 の段階になると、その人の勝負服を自分の馬に着せられる。
- お手馬の段階の課題までやり終えると好感度がいっぱいになり、繁殖の永続のボーナスのアイテムをもらって、その人からの依頼は来なくなる。
- G3 の段階から、頼めば来月の馬の店にその人の好みの馬が並びやすくなる（牡馬・牝馬それぞれ3頭まで入れ替える）。
- 年末に、その年いちばん一緒に勝った人と「名コンビ賞」（3勝から）。

## 秘書ユニと、正体のほのめかし（キンチェムモチーフ）

持ち主の決定（2026-10-19）「秘書の正体にしましょう。あくまでキンチェムモチーフなだけで本人ではないです」「正体はプレイヤーがもしかしてと思わせる程度でいいです。基本的に優秀なナビゲータであってください」。

- ユニの基本は優秀なナビゲーター（秘書）。導入・案内・報告（年明けの有力馬の紹介など）・節目に褒める、を的確に、分かりやすく。ナビゲーターの仕組みはまだ無い（別の仕事）。
- 正体ははっきり明かさない。キンチェムそのもの・馬の化身とは書かず、名前も出さない。プレイヤーが「もしかして」と思う程度に、さりげない一言・小物（花の髪留め）・反応でほのめかす（花輪・ハンガリー・無敗・バーデンの夏・黒い猫・「わたしの宝もの」。キンチェムはハンガリーの言葉で「わたしの宝もの」）。
- ほのめかしは、案内の分かりやすさを邪魔しない所（案内のあと・場面の終わり）に置く。
- 秘書として最初からそばにいることとの両立：クラシック系の依頼は「2歳・3歳のレースで勝ちを重ねると、ユニが子どものころからの憧れを話して、クラシックを目指す馬主たちの依頼を取り次ぎはじめる」形で始まる。

ほのめかしを置いた所：

1. 案内のあとのさりげない一言（ナビゲーターの仕組みができたら、ときどき混ぜる）：
   - 「バーデンバーデンの大きなレースは、昔から夏の終わりなんですよ。」
   - 「トランプですか。わたし、負けたことがないので、やめておきます。」
   - 「勝った日は、花瓶の花を多めにしておきます。昔からの習いなんです。」
   - 「黒い猫が厩舎に来ていました。追い払わないでくださいね。馬の旅の友だちなんです。」
   - 「ハンガリーの言葉で「わたしの宝もの」って、どう言うか知っていますか。いえ、なんでもありません。」
2. 依頼の台詞：パドックで「ハンガリーでは、勝った馬の首に花輪をかけるんですって」、勝ったあと「{horse}の首に、花輪をかけてあげたいです」。絵が無いときの顔に小さな花の髪留め。
3. クラシック系の課題の場面：G3（勝ち負けのつく遊びで負けたことがない）・G1（花輪をかける国・手が花を探す）・最後（手帳の表紙の押し花は、昔もらった花輪の花）。
4. GF を全部勝って、各 GF に無敗の牝馬が出てくるころ（ほのめかしが少し濃くなる。出す所の仕組みはまだ無い。GF の係と相談）：
   - 「{me}さん、次のグランドフェスティバルに、昔の無敗の牝馬が出てくるそうです。」
   - 「あの牝馬は、汽車で国から国へ旅をしても、いつも落ち着いていたんですって。本で読みました。」
   - 「案内に戻りますね。出走の予定は、いつもの所にまとめておきました。」

書き手のための裏設定の案（ゲームの中では明かさない。ほのめかしの向きをそろえるために、持ち主が1つ選ぶ）：

- 案a：花輪の家の娘（おすすめ）。ハンガリーの小さな村で、昔の無敗の牝馬をたたえる花輪を代々編んできた家の娘。花輪にふさわしい馬と騎手を見たくて日本へ来た。秘書は好きでやっている。
- 案b：負けなしで鞍を降りた元騎手。子どものころ欧州の若い騎手のレースで一度も負けなかった。けがで鞍を降り、名を伏せて秘書に。
- 案c：無敗の牝馬をたたえる牧場の跡取り。ハンガリーの古い牧場の娘。継ぐ前に、世界一の騎手のそばで学ぶため名を伏せて秘書をしている。
