# 依頼：競馬ゲームの「オーナー」9人のキャラクターとストーリーの下書き

## 1. ゲームのこと（短く）
- 騎手が主役の競馬ゲーム。プレイヤーは騎手で、自分で買った馬と、オーナー（馬主のキャラクター）から頼まれた馬に乗る。
- 馬名・レース名・競馬場名は実在のもの。人（騎手・調教師・馬主）は全部架空。
- 年代なし：1989〜2026年に走った実在の馬が、毎年ランダムにデビューする。それより前の名馬は「スペシャルホース」として特別な条件で出てくる。
- 週ごとのターン制で、1年に何十レースも走る。オーナーの話は、その合間に短い場面で進む。

## 2. オーナーの仕組み（決まっていること）
- オーナーは8人。それぞれ「得意なジャンル」がある（地方ダート・短距離・クラシック・牝馬・長距離・欧州・米国・豪州）。ほかに、依頼はしないが年末の大会（GF＝グランドフェスティバル）にだけ現れる謎の人物が1人いる。
- **出会い**：そのジャンルのレースで勝つと点がたまる（OP 1点・G3 2点・G2 3点・G1 4点）。4点で出会いの場面。
- **依頼はミッション形式**：段階は OP → G3 → G2 → G1 → 最終。OP〜G1 は「依頼の馬」と「レース」が決まっている（実在の馬で、実在のレース）。レースの4週前に依頼が届き、勝てばクリアで次の段階へ。負けたら次の年の同じレースでやり直し。
- **最終ミッション**は、プレイヤーが自分で育てた馬（お手馬）で大きな目標を達成する（例：自分の馬で米国三冠）。やり終えると、その人の「アイテム」（自分で作る馬＝オリジナルホースへのボーナス）をもらい、そのオーナーの話は終わる。
- G2 をクリアすると、そのオーナーの勝負服を自分の馬に着せられる。
- 画面の言葉は「オーナー」「友好度」「ミッション」。

## 3. 書き方の決まり（必ず守る）
- 日本語。会話は1つの場面で2〜5行。凝りすぎない、軽く読める長さ。
- 文中の差し込み：`{me}`＝騎手の名前、`{horse}`＝馬名、`{race}`＝レース名。
- **性的な描写は書かない**（体つき・服の下などに触れない）。恋愛・結婚の話にしない。キャラの見た目の「属性」は絵を描くための目安で、文には出さない。
- **実在の人の名前を出さない**（実在の騎手・調教師・馬主・生産者）。史実の馬の話をするときも人には触れず、馬とレースだけで語る。
- 実在の馬とレースは史実に合わせる（生年・勝ったレース・負けたレース）。史実と違う結果を目標にする「たられば」のミッションは歓迎（例：ミホノブルボンで菊花賞を勝つ＝史実では2着）。ミッションごとに「史実」か「たられば」かを書き、たらればなら史実はどうだったかを一行添える。
- 漫画・アニメ・ほかのゲームの名前、キャラ名、名台詞は使わない。
- 避ける癖：「……」の多用／締めの一行で余韻を付ける（〜気がした・なぜか）／感情を説明する（胸が温かくなった）／ぼかし語（どこか・少しだけ・そっと・ふと・まるで〜のように）／三つ並べと左右対称の文／どの場面も同じ長さ・同じ構成／読点の打ちすぎ／能力の数値や％を文に出す。
- 口調は人ごとにはっきり変える（一人称・プレイヤーの呼び方・語尾）。

## 4. 1人分に書いてほしいもの（この順で）
1. **プロフィール**：名前（読み）・年齢・肩書き・見た目（服・小物・髪。2〜3行）・人柄（2〜3行）。
2. **口調**：一人称・プレイヤーの呼び方（仲良くなると変わるならそれも）・語尾・言わないこと。
3. **ストーリーの芯**（4〜6行）：なぜ騎手に依頼するのか、段階が進むと何が分かるか、最後にどうなるか。凝りすぎず、1人に1つの小さな山場。
4. **ミッション表**：

   | 段階 | 依頼の馬 | レース | 史実／たられば | 頼むときのひと言 |
   |---|---|---|---|---|
   | OP | | | | |
   | G3 | | | | |
   | G2 | | | | |
   | G1 | | | | |
   | 最終 | 自分の馬 | （目標） | — | |

   - 依頼の馬は、そのジャンルに合う実在の名馬。年齢はレースの条件（2歳戦・3歳戦など）に合わせる。
   - OP の段階は実在のオープン特別やリステッド（G 表記のない大きめのレース）。
5. **場面の会話**：出会い／OP クリア／G3 クリア／G2 クリア（勝負服を渡す）／G1 クリア／最終クリア（アイテムを渡す・別れ）。
6. **ひと言**（短く1行ずつ、各3つ）：依頼が来たとき／パドック／勝った／G1 を勝った／惜しい負け／負け／依頼を見送られた。
7. **最後のアイテム**の名前と、それがその人らしい理由（1行）。効き目はこちらで決めるので、名前と由来だけでよい。
