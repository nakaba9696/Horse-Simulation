# スペシャルホースの一覧

`node tools/special_list.js` で `js/core/special.js` から作る（手で直さない）。

1989年より前に走り終えた名馬が、条件のグループに入る。自分の馬がグループの条件にリーチをかける（あと1勝でそろう）と、そのグループの名馬が最後のレースに出てくる（1レースに最大4頭。大レースのグループからは強い順に2頭まで）。勝つと、出てきた名馬が馬の店に並ぶ。名馬は1頭で複数のグループに入ることがある。

スペシャルホース 1594頭・条件の組み合わせのグループ 17・大レースのグループ 90
