# スペシャルホースの一覧

`node tools/special_list.js` で `js/core/special.js` から作る（手で直さない）。

1989年より前に走り終えた名馬が、条件のグループに入る。自分の馬がグループの条件にリーチをかける（あと1勝でそろう）と、そのグループの名馬が最後のレースに出てくる（1レースに最大4頭。大レースのグループからは強い順に2頭まで）。勝つと、出てきた名馬が馬の店に並ぶ。1頭が出てくる条件は1つだけ。（）の中は生年・国・競走生活の年・通算の戦績。年代・戦績・主な勝鞍・解説は data/profiles.js。

スペシャルホース 78頭・条件の組み合わせのグループ 15・大レースのグループ 13
