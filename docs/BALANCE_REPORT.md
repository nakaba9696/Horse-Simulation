# バランスの測定（2026-10-21・測っただけ。直しは入れていない）

持ち主の言葉「ゲームバランスはあとからいくらでもなんとかなるのでぼちぼちでいいです」に合わせて、気になる所の上位5つと直し方の案だけを書く。

## 測り方
- 道具：`node tools/balance_autoplay.js all --seeds=1,2,3,4 --years=10`（表は `node tools/balance_autoplay.js report`）。JS のコア（Godot 版と同じ決まりを一致テストで持つ）で、騎手のゲーム（年代なし）を自動で遊んだ。
- 種4つ × 乗り方2つ（上手な人＝`tests/ridebot.js` の fit・ふつうの人＝push）× 10年。資金切れの2本は途中で終わり。
- 立ち回りは両方同じ：毎月、半年分の預託料を残して店でいまの総合力がいちばん高い馬を買う（10頭まで）・ふだんはおまかせ出走、トロフィーのリーチと強い馬の G1（海外も）は自分で登録・1月に弱い馬と7歳を引退・引退馬でオリジナルホースを作る・GF は招待されたら出る・依頼には必ず乗る。
- 立ち回りは素朴なので、うまい人間より弱めに出る（とくに「お手馬がいっぱいでも買い替える」はしていない。`--swap` で試せるが今回は回していない）。

## 気になる所の上位5つと直し方の案

1. **トロフィーが10年でほとんど取れない（上手な人で平均0.3個・ふつうの人は0）。**
   店で買える馬の総合力が1年目 52〜59・10年目でも 68 まで、三冠や GS の G1 を続けて勝てる強さ（65〜70以上）に届かない。店は牡牝10頭ずつの抽選なので、強い馬に当たりにくい。
   - 案：店の品数 `E.STOCK` を 10 → 20 にする、または毎月1〜2頭は総合力 62 以上の馬を必ず並べる。いちばん易しいトロフィー（日本ダート三冠・難しさ1、仏国三冠・豪州三冠・牝馬三冠など難しさ2）は、隠し馬（`data/trophy_horses.js`）をリーチで出さないか、1頭だけにする。

2. **お金が余る（上手な人は3年目から店の馬を全部買える。10年目は20億）。**
   お手馬10頭の上限があるので、店で使える額はすぐ頭打ちになる。賞金の取り分（年3〜6億）に対して、出口は預託料（年0.8億）と遠征費だけ。
   - 案：入口は削らず、出口を足す。店の値段の倍率 `E.PRICE_DOUBLE` 5 → 4（総合力が5上がるごとに2倍 → 4上がるごとに2倍。68の馬が約1.7億 → 約2.7億）、預託料 60 → 100万円/月、店の「入れ替え」（`E.restock(true)`）に値段を付ける。

3. **ふつうの人は資金切れが多い（4本のうち2本、3〜4年目）。上手な人は0本。**
   1年目に始めの資金（0.8億）を店でほぼ使い切り、勝てない年に預託料で沈む。乗り方の差が、そのまま終わりにつながっている。
   - 案：`T.BROKE_MONTHS` 2 → 3、出走手当（自分の馬が出るたびの 30万円・`W.applyResults`）を 50万円に。または1〜2年目だけ預託料を半分。

4. **隠し馬と GF がほぼ勝てない（隠し馬のいるレースで9%・GF は19回で1勝）。**
   隠し馬が1レースに何頭もまとめて出ることがある（宝塚記念・有馬記念など）。GF に出た自分の馬は総合力 62〜69 で、相手の上位に届かない。トロフィーと GF が取れないので、引退でのトロフィーの上がりもオリジナルホースも伸びない（5と同じ根）。
   - 案：1レースに出る隠し馬を4頭まで → 1頭まで（`SP.MAX_IN_RACE`）。GF の招待の埋めの AI の馬（`T.dcStanding` の tier 3・4）を総合力の上限つきにする。

5. **オリジナルホースが親より強くならない（2世代とも 親55前後 → 仔54前後。走って届いたいちばん上は74）。**
   引退で能力が上がるのはトロフィーだけなので、トロフィーが取れない今は親の平均にばらつきが乗るだけになる。
   - 案：G1 の勝ち1つごとに引退で +1（focus の能力・上限4）を足す、または仔の能力を「両親の平均」から「平均と高いほうの中間」にする（`O.make` の `(a + b) / 2`）。上位1の店を直すと、親が強くなってこれも少し良くなる。

ほか：ファリナさんは4本とも出会うが、最初のミッション（ハナズゴールでリゲルS・3歳12月）を9回挑んで一度も勝てず、段階0のまま止まった。依頼の馬が弱すぎる見込み。最初の段階の馬かレースの見直しを勧める。
