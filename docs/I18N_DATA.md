# データの英語の名前

持ち主の決定（2026-10-21）「言語は日本語と英語にしたい」。画面の英語の仕組み（Godot 版）が読む、データの側の英語の名前の決まり。
名鑑の文とオーナーの台詞の翻訳は別の仕事（ここでは扱わない）。

## 欄の名前

| もの | 欄 | 置き場所 |
|---|---|---|
| 馬（史実馬・記録から作った馬・スペシャルホース） | `nameEn` | 海外の馬はデータの `nameEn`。日本の馬は `data/names_en.js`、無ければ決まりで作る（`js/core/datafix.js`）。決まりで作った名前には `nameEnRule: true` |
| レース（暦の重賞・史実の勝ち鞍のためのレース・オーナーの依頼のオープン） | `nameEn` | `data/races_en.js`（暦の名前 → 英語）。`js/core/datafix.js` が各レースに入れる |
| グランドフェスティバル | `nameEn`・`trophyEn` | `data/gf.js` |
| 競馬場 | `nameEn` | `data/courses.js` |
| 特殊能力（発動する技・手書きの能力・名馬の固有の技） | `labelEn`・`noteEn` | `js/core/skills.js`・`js/core/horse.js`・`data/uniques.js`。Godot の `godot/core/hs_skills.gd`・`hs_horse.gd` にも同じ値 |
| 騎手（架空の名前） | `nameEn`（`D.jockeys`）・`D.jockeyNamesEn`（架空の名前 → 英語） | `js/core/fictional.js` |

Godot へは `node tools/export_godot.js` が `datafix` のあとの値を書き出す（`godot/data/*.json`）。

## 馬名

1. 海外の馬：元の英語の名前（データの `nameEn`。記録から作る馬は記録の `horseEn`）。今ある値は変えない。
2. 日本の馬：登録の英語名を出典で確かめて `data/names_en.js` に書く（`{ 'ディープインパクト': 'Deep Impact', ... }`）。出典は
   - ja.wikipedia の競走馬の記事の枠の「英」（ほとんどが JBIS を出典にしている）。
   - JBIS サーチ（`www.jbis.or.jp` で名前を引き、名前と生まれ年が合う馬の英語のページ `www.jbis.jp/horse/<番号>/` の見出し。末尾の国の印「(JPN)」は外す。全部大文字の名前は語の頭だけ大文字にする）。
   - どちらも、名前と生まれ年（±1年）が合う馬だけ採る。同じ名前で年が違う馬（`スズホープ（1974）` など）は年で分ける。
3. 出典で見つからない馬は、カナをヘボン式のローマ字にする（`HS.romaji`）。**カナの外来語でも元の綴りを推さない**（推測で英単語にしない）。
   - 1語にまとめ、頭だけ大文字（`スペシャルウィーク` → `Supesharuwiku`）。「・」は語の切れ目（空白）。
   - 長音の「ー」と、オウ・オオ・ウウの伸ばす音は書かない（`トウカイテイオー` → `Tokaiteio`）。エイは `ei` のまま。
   - ンは b・m・p の前で m（`シンボリ` → `Shimbori`）。ッは次の子音を重ねる（チの前は t：`サッチャー` → `Satcha`）。
   - 外来語の音：ティ ti・ディ di・ファ fa・フィ fi・フェ fe・フォ fo・ウィ wi・ウェ we・ウォ wo・ヴァ va・ヴ vu・シェ she・ジェ je・チェ che など。昔の登録の大きなカナ（ニユーフオード）は書いてあるとおりに読む（`Niyufuodo`）。
   - 名前の後ろの `（1974）` のような年は付けない。
4. 確かめた名前が後で見つかったら `data/names_en.js` に足す（`datafix` は決まりで作った名前より表を先に使う）。記録から作る馬は `node tools/build_auto.js` を回すと、記録の英語名 → 表 → 決まり の順で `nameEn` を作る。

## レース名

- JRA・地方の重賞は JRA の英語の名前（JRA の英語サイトの表記）。賞＝Sho・記念＝Kinen・杯＝Hai・特別＝Tokubetsu・大賞典＝Daishoten・3歳＝Sansai・2歳＝Nisai・4歳＝Yonsai・牝馬＝Himba・金杯＝Kimpai。クラシックは JRA と同じく括弧で英国の名を添える（`東京優駿` → `Tokyo Yushun (Japanese Derby)`）。
- 今は無い昔の重賞（1960〜1994）も同じ決まりでローマ字にした（`日本短波賞` → `Nihon Tampa Sho`）。
- 海外は元の名前（en.wikipedia の各レースの記事の名前。`凱旋門賞` → `Prix de l'Arc de Triomphe`）。香港のクイーンエリザベス2世カップはエリザベス女王杯と分けるため `Queen Elizabeth II Cup (Hong Kong)`、米国のホープフルステークスは `Hopeful Stakes (USA)`。
- 同じ名前のレースは年代が違っても同じ英語名（名前が変われば暦の名前が変わるので、英語名も別になる）。
- 名前の無いオープン（`2歳オープン` など）はコードが作る名前なので、画面の側で訳す。

## 競馬場

JRA・地方は公式の英語表記（Tokyo・Nakayama・Oi・Mombetsu など）。海外は元の名前（ParisLongchamp・The Curragh・Churchill Downs など）。

## 特殊能力

短い英語の名前と1文の説明。固有の技の名前は異名の意訳（`芦毛の怪物` → `Grey Monster`、`エクリプス・ファースト` → `Eclipse First`）。英語の名前は全部の技で重ならない。

## 騎手

架空の名前（`js/core/fictional.js`）の読みをヘボン式にし、「名 姓」の順（JRA の英語の表記と同じ）。同じ読みにならないよう、名前の読みは一つに決めた（木暮＝Kigure・小暮＝Kogure、渉＝Wataru・亘＝Ko・航＝Kakeru、仁＝Hitoshi・迅＝Jin など）。外国の騎手の架空の名前は頭文字と英語の姓（`A. Arnaud`）。

## 確かめ

`tests/extra_i18n.js`：史実馬・スペシャルホース・トロフィーの隠し馬・全部の重賞・競馬場・技・騎手に英語の名前があり、日本語の字が入っていない。G1 馬と名鑑のある馬は、決まりで作った名前が上限（下の表の数）以下。

## 数（2026-10-21）

- 史実馬とスペシャルホースの補い（`data/legends.js`）は 7340頭。もとからデータに英語名があった海外の馬などが 3598頭。
- `data/names_en.js` に出典で確かめた名前が 3685頭（ja.wikipedia の枠 1512・JBIS 2162・海外の馬で en.wikipedia の名前 11）。外国産馬（タイキシャトル＝Taiki Shuttle など）は JBIS の日本語の検索に出ないので、英語の名前で JBIS を引き、生まれ年とカナの名前が合ったものを採った。
- 決まり（ヘボン式）で作った名前は 89頭＋スペシャルホースの補いの古い名馬 6頭。ほとんどが 1950〜60年代の馬で、JBIS に登録の英語名が無い（英語の欄が空）。
