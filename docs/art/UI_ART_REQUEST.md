# 画面の部品の絵の依頼（GPT の画像生成へ）

競馬ゲーム「ターフの系譜」の画面の部品（ボタン・枠・帯・アイコン・背景）の絵を頼むための文です。下の「---」から下を、そのまま GPT（画像生成）に渡してください。一度に全部は頼めないので、「頼む順」の1回分ずつ渡します。

できた絵は PNG のまま持ち主に渡してもらい、配り役が `godot/assets/ui/` に置いて画面に組み込みます。

---

PC 向けの競馬ゲーム（Steam で売る。日本語。騎手が主役で、実在の競馬場と名馬が出てくる）の画面の部品を描いてください。

## 雰囲気
- 競馬らしさを出す。出馬表・競馬新聞の馬柱の罫線、競馬場の掲示板・電光板、ゲート、芝の緑、ターフの柵（白いラチ）、ハロン棒、蹄鉄、優勝のレイ（花輪）、トロフィー、勝負服の色分け、ゼッケン。
- 高級感のある「深緑と金」が基本。下地は暗い深緑（#07140d〜#1b5536）、強調は金（#d6ad4c。明るい金 #f2d98e、暗い金 #a37a26）。金の面は上から #f6e1a0 → #dcb455 → #c4952f。
- 立体感のある札とボタン（薄い厚み・上の縁のつや・下に影）。ただし文字が読みにくくなるほど飾らない。
- 写実よりも、きれいなゲームの UI（家庭用の競馬ゲームのメニューのような、くっきりした形）。

## してはいけないこと
- 文字を絵に入れない（ゲームが上に字を載せる）。数字・英字・ロゴも入れない。
- 実在の団体（JRA など）・競馬場・ゲーム会社のロゴや、既存のゲームの画面に似せたデザインは使わない。
- 人の顔は描かない（背景に人が入るときは遠景の群衆だけ）。

## 共通の決まり
- 形式：PNG。背景は透明（背景の絵だけは不透明）。
- ボタン・枠・帯は、ゲームで伸び縮みさせる（九つに切って角はそのまま、辺と中を伸ばす）。角の飾りは四隅に、辺は同じ模様の繰り返しにする。角の大きさ（切る位置）は、ファイルごとに「角 ○px」と書いて返してください。
- 大きさは下の表のとおり（2倍の解像度で描いてよい）。
- ファイル名は表の名前のまま。

## 配り役のメモ（GPT には渡さない）
- 置き場所：`godot/assets/ui/`。Godot では九つ切り（NinePatchRect・StyleBoxTexture）で使う。角の px はファイルごとに `godot/assets/ui/slices.json` に書く。
- 出典は `godot/CREDITS.md` と `assets/CREDITS.md` に「GPT の画像生成で作った絵（持ち主が生成。2026-10-xx）」と書く。
- Steam に出すときは、ストアの「AI で作った内容」の申告に、画面の部品と背景の絵を書く。
- 絵が届くまでは今の形と色で描く部品のまま。届いたら1画面（牧場）で試して、持ち主に撮った絵を見せてから全部に広げる。
