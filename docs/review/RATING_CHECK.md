# 史実馬の総合力のチェック依頼

競馬ゲーム「ターフの系譜」の史実馬の総合力（強さの数）を、外の目で見てもらうための依頼文です。主な勝鞍のチェック（`MAIN_WINS_CHECK.md`）のとき「総合力は仕上げのあとに別の依頼でまとめて見てもらう」としていたもので、持ち主の値の入力とクイズが終わったので出します（2026-10-22）。

---

あなたは競馬（日本・海外の平地競走、1800年代〜2026年）に詳しいレビュアーです。PC 向けの競馬ゲームに載る史実馬（約5,000頭）の「総合力」を見て、史実の強さの並びとおかしい所を挙げてください。

## 見てほしいファイル
- リポジトリ `nakaba9696/Horse-Simulation`、ブランチ `claude/lucid-ptolemy-j204a3`。
- 一覧：`docs/review/horses.csv`（UTF-8）。
  - 列：区分・名前・生年・国・性・芝の総合力・ダートの総合力・能力の数・脚質・距離・特殊能力・G1 の勝ち数・G1 の勝ち鞍（ゲームの番組にある分）・トロフィーの隠し馬・**持ち主が決めた値**（○）・**史実の主な勝鞍**。
  - 総合力はゲームの画面に出す数（0.5 刻み）。
- G1 の格の表：`docs/review/g1_tiers.csv`（レースごとの「その G1 を1つ勝った馬の総合力」）。
- 元のデータ：`data/horse_fix.js`（総合力を決めた値と、その理由 `why`）。

## 総合力の決まり
- 目盛りは 45〜80。名馬は 65.0〜80.0 で、いちばん上はキンチェム 80.0。芝とダートで別の数を持ち、主な馬場の数がその馬の強さ。
- 区分は3つ。
  - **史実馬（毎年デビュー）**：1989〜2026年に走った馬。
  - **スペシャルホース**：1989年より前に走り終えた名馬。
  - **隠し馬**：トロフィーで出てくる馬。
- 決め方（持ち主の決定 2026-10-22）：
  - G1 を1勝した馬は、勝った G1 の格（`g1_tiers.csv`。64.5〜60.0 の10段）の値にする。
  - 2勝以上した馬は、いちばん上の格 ＋1.0、3勝目から1勝ごとに ＋0.5 を下限にする。
  - G2・G3 だけの馬は勝ち数で決める。
- **持ち主が決めた値（○の 574 頭）は、持ち主が自分で入れた数かクイズの答えから決めた数。** 決まりより優先する。
  - おかしいと思ったら挙げてかまわない。そのときは「持ち主の値」と分かるように書く。
  - 例：セクレタリアト 77.0、イクイノックスとアーモンドアイ 74.0、タケシバオー 71.5、パセアナ 70.0（ダ）。
- 着差・レースの中身・勝った相手の強さは、一部しか入っていない（自動で作った馬の G1 の相手だけ）。

## 見てほしいこと（大事な順）
1. **名馬どうしの並び（65.0 以上の約1,240頭）**：
   - 史実の評価（年度代表馬・殿堂・Timeform の値・国際レーティングなど）と比べて、明らかに高すぎる・低すぎる馬。
   - 同じ時代・同じ路線で、強い方が低くなっている組み合わせ。
2. **低すぎる名馬（65.0 未満）**：G1 を多く勝った・年度代表馬・殿堂入りなのに 65.0 未満の馬。
3. **芝とダートの取り違え**：主な馬場が逆になっている馬（ダートの名馬なのに芝の数が高いなど）。
4. **G1 の格の表**：格が高すぎる・低すぎるレース。

全部の馬を見なくてかまいません。名の知れた馬・G1 を多く勝った馬を優先し、確かな食い違いから挙げてください。外部のサイトで確かめられなかったものは「未確認」と書いて分けてください。数の案は 0.5 刻みで。
