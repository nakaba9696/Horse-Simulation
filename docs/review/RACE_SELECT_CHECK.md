# 番組（重賞）の取捨選択のチェック依頼

`node tools/race_select.js` で `data/races*.js` から作る（手で直さない。直すのは道具の中の文）。番組を変えたら作り直す。

下の「---」から「依頼の文」の前までを、そのまま別の AI に貼る（短い依頼の文は末尾）。

---

あなたは競馬（日本・海外の平地競走）に詳しいレビュアーです。PC 向けの競馬ゲームに入れる重賞の一覧を、作者が「残す／外す」で選びました。この選び方と、各レースのデータが2025年の実際と合っているかを確かめてください。

## ゲームの前提
- 騎手が主役の競馬ゲーム。プレイヤーは自分で買った馬と、オーナー（架空の人物）に頼まれた馬に乗る。1年は1か月4週・週ごとに進む。
- 実在の馬（1989〜2026年に走った馬）と実在のレース名を使う。番組（格・競馬場・距離・時期・賞金）は2025年の形で毎年同じ。
- 出られるのはオープン以上。ここに載っているのは重賞だけ（オープン特別は競馬場ごとに自動で作るので、この一覧に無い）。障害競走は無い。
- 時期は「月と週」（5週目は無い）。2025年の施行日から、1〜7日＝1週・8〜14日＝2週・15〜21日＝3週・22日〜＝4週で決める（全部のデータのファイルで同じ）。別の週末の G1 が同じ週に重なるときは、早いほうの週末を前の週へ寄せた（マイルCS・エリザベス女王杯）。2025年だけの例外（中京の京都金杯・4月のドバイワールドカップデー・サラトガのJCゴールドカップなど）は入れず、ふだんの形にしてある。
- 海外は日本の地方・米・加・英・愛・仏・独・豪・香港・UAE・サウジ。豪州の2歳 G1 には出られない（作者の決定）。番組には残り、ゲームの中の他の馬だけが走る。この一覧では「外す」。
- 日本の地方のダートの重賞は、ゲームの中では Jpn1〜3 と出す（国際 GI の東京大賞典だけ G1）。
- 賞金は1着の賞金（万円・2025年の円換算の目安）。海外の賞金は概算。
- 列「トロフィー」は、レースの組み合わせを制覇する目標（例：日本三冠）の条件に使っているもの。「オーナー」は依頼（段階1〜4の固定のレース・お手馬での最後の依頼）に使っているもの。「スペシャル」は、昔の名馬が出てくる条件（歴代の○○馬など）に使っているもの。どれも、外すと成り立たなくなる。
- 「この形の始まり」は、その形（格・距離・競馬場）の行の始まりの年。海外の補い（`data/races_more.js`）の世界の有名な重賞は2015年からの形だけを持つ決まり（FAMOUS_FROM）なので、2015 は「それより前を持たない」の意味のことが多い。ただし2015〜2024年に格の変わったレースは、史実馬の勝ち鞍の格の数え方に響くので指摘してほしい。
- 「前の年の形は未確認」は、2025年の形は確かめたが、それより前の年の距離・競馬場の移り変わりまでは確かめきれていないもの（このレビューでは2025年の形だけ見ればよい）。

## 見てほしいこと
1. **入れたほうがよいのに一覧に無い重賞**（世界的に格が高い・有名な名馬が勝っている・日本の競馬ファンが知っている、など）。国・格・距離・時期・理由を添えて。末尾の「記録だけのレース」「2025年に無いレース」も参考に。
2. **外したほうがよい重賞**（格が低い・廃止された・ゲームで遊ぶ価値が薄い）。理由を添えて。トロフィー・オーナー・スペシャルの列にあるものは、外すと代わりが要る。
3. **データの誤り**：格（G1/G2/G3）・競馬場・芝ダート・距離・時期（月と週）・年齢・性別の条件・賞金が2025年の実際と違うもの。同じレースが2行ある・名前の違う同じレースがある、なども。正しい値と出典の URL を添えて。
4. 年間の番組として、時期や距離の偏り（ある月に重賞が無い、短距離ばかり、など）があれば。
