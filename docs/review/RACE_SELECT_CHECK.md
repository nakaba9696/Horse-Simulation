## ゲームの前提
- 騎手が主役の競馬ゲーム。プレイヤーは自分で買った馬と、頼まれた馬に乗る。1年は週ごとに進む。
- 実在の馬（1989〜2026年に走った馬）と実在のレース名を使う。番組は2025年の形で固定。
- 出られるのはオープン以上（ここに載っているのは重賞だけ。名前のあるオープン特別は別の一覧）。
- 海外は日本・米・英・愛・仏・豪・香港・ドバイなど。豪州の2歳 G1 はゲームでは出ない決まり（作者の決定）。
- 「使っている所」はゲームのトロフィー（レースの組み合わせを制覇する目標）やオーナーの依頼で使うレース。外すとそれらが成り立たない。
- 賞金の単位は万円（1着、2025年の円換算の目安）。

## 見てほしいこと
1. **入れたほうがよいのに一覧に無い重賞**（世界的に格が高い・有名な名馬が勝っている・日本の競馬ファンが知っている、など）。国・格・距離・時期・理由を添えて。
2. **外したほうがよい重賞**（格が低い・廃止された・ゲームで遊ぶ価値が薄い）。理由を添えて。
3. **データの誤り**：格（G1/G2/G3）・競馬場・芝ダート・距離・時期（月と週）・年齢・性別の条件・賞金が2025年の実際と違うもの。正しい値と出典の目安を添えて。
4. 年間の番組として、時期や距離の偏り（ある月に重賞が無い、短距離ばかり、など）があれば。
