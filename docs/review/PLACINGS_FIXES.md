# G1 の上位着順の直し（Codex のレビューへの対応）

2026-10-22。対象は `data/src/placings_jra.jsonl`・`data/src/placings_world.jsonl` と、そこから作る `docs/review/placings.csv`。
もとのレビューは [codex/PLACINGS_REVIEW.md](codex/PLACINGS_REVIEW.md)（確定指摘57件・カナの補い20頭21行・未確認31件）、依頼文は [PLACINGS_CHECK.md](PLACINGS_CHECK.md)。
持ち主の指示（2026-10-22）の順（1. 別馬の混入・重複・裁決・別競走 → 2. 国内の同名別世代馬 → 3. 米国 G1 の着差 → 4. カナと英字名）で直した。

## 道具とテスト

- `node tools/build_placings_csv.js`：元データから一覧（placings.csv）を作り直す。`--check` で、いまの CSV が元データと同じかだけを確かめる。列の決め方は前のとおり（JRA・地方の基準は「勝ち馬との差」、海外は marginTo＝prev→「前の馬との差」・winner→「勝ち馬との差」、注は 同着（dh）・note・着差の出典（marginSrc）を「；」で並べる）。直す前の元データから作ると、前の CSV とバイト単位で同じになることを確かめてある。
- `tests/extra_placings.js`（`tests/run.js` から読む）：
  - 一覧が元データから作り直したものと同じで、行が1対1。
  - 馬の識別：ゲームにいる行（○）はゲームの馬がいて、レースの年に2〜12歳。海外の行は英字名もゲームの馬の英語名と同じ。同名の別世代の9行は紐づかない。カナの無い外国馬と、英字名の混ざり物（脚注の印・性別の印・着順の説明・生産国）が無い。
  - 着順と同着：1着がある・同じ馬が2度出ない・同着の印と着順が合う・同着の後の着順・同着の組の着差がそろう。有馬記念2020の5着同着・ジャパンカップ1996の3着同着・ベルモントS2023の4着同着（2頭とも ¾）を保つ。
  - 着差の基準：JRA・地方は勝ち馬との差で、降着の6レース（2009秋華賞・2010スプリンターズS・2010ジャパンカップ・2016皐月賞・2019NHKマイルC・2020高松宮記念）の2着以下は空で注がある。JBIS の「*****」より後ろも空。海外は前の馬との差（勝ち馬との差は香港だけ）で、着差の表記が読める。米国の en.wikipedia の表から来た着差が勝ち馬との差の累計のまま残っていない・「0」が無い。Codex の確定指摘の着差の値。
  - 収録：レース×年がゲームの暦の G1 の年にある・1989〜2026年・2026年は暦で10月3週（10月18日の秋華賞・17日の英チャンピオンズデー）まで・出典の日付も10月18日まで。2026年 BC フィリー＆メアターフが無い、サウジカップ2020が裁決後の着順。
- 集めた道具（リポジトリの外。親のセッションの scratchpad の `plwork/`）：`gs.js` の年の区切りの読み落とし（下の1-2）を直した。`finalize.js` の wiki の一律の行ずらしは使わないよう印をつけ、表ごとの判別は scratchpad の `wiki_vs_gs.js`、今回の直しの全体は `apply_fixes.js` に置いた。

## 3. 米国 G1 の着差（Codex の確定指摘 25件すべて対応・ほか同じ原因の所も）

集めたときは en.wikipedia の表を「勝ち馬の行に着差があれば1行ずらす」と一律に扱っていた。表ごとに型が違うので、**表の着差の列を全頭で読み直して型を判別**し、前の馬との差に直した。

- 前の馬との差（勝ち馬の行が空・値がばらばら）：そのまま。
- 次の馬との差（勝ち馬の行に値・ばらばら）：1行下げる（前のとおり）。BC クラシック2005〜2017・ベルモントS2001〜2006・プリークネスS2022。
- 勝ち馬との差の累計（全頭でふえていく。勝ち馬の行が空・0・—、または勝ち馬の行に勝ち着差で2着の行も同じ値）：隣どうしの差を取る。BC クラシック2018〜2025、ケンタッキーダービー2003〜2006・2014〜2026、プリークネスS1989〜2015・2018〜2026、ベルモントS2018〜2026。長い表は5着より後ろの1か所の書き違いを許す。
- 失格馬からの差（勝ち馬の行の値が2着より小さく、ふえていく）：ケンタッキーダービー2019（Maximum Security 降着）・2021（Medina Spirit 失格）。1着の行の値を起点に差を取る。
- 小数の馬身の累計：メルボルンC2005（前は2着に走破タイム「3:19.17」が入っていた）・プリークネスS2021。galopp-sieger の Richterspruch を採った（累計と合う）。

**微差の丸め**：累計の表は1行ごとに ¼ 馬身へ丸めてあるので、差が0になる所（ハナ・アタマの差）や ¼ ずれる所がある。そこは、前の馬との差をじかに書く galopp-sieger の Richterspruch を採り、注に「着差の出典」を付けた（例：BC クラシック2018の4着・2020の5着 ns。Codex の確かめと同じ）。
**同着**：同着の組は2頭とも前の着順の馬との差にそろえた（ケンタッキーダービー2006の4着・BC クラシック2017の5着の「dead heat」・ベルモントS2023の4着 ¾）。

## 5. 着差の表記の混ざり物（今回見つけた・139行）

テストで着差の表記を読めるか確かめたところ、galopp-sieger の Richterspruch の読み違いが残っていた。値は変えずに表記を直した所と、読めないので空にした所がある。

- 勝ち方の略号が2着の着差に付いていた（ドイツダービー・バーデン大賞・ベルリン大賞の2着など109行）：「Le:2」→「2」、「Ka:H」→「nk」など（Le・Si・Ka・Üb・Hü は勝ち方。K＝hd・H＝nk・kK＝shd）。「Rsp.K」「Rsp.H」も同じ。
- 「*3¼」→「3¼」、「20Längen」→「20」、「NLg.」→「ns」。
- 失格馬からの差（BC ディスタフ2006 の「5½(AsiSiempre)」・ドイツダービー2020 の「¾(GrocerJack)」・JCゴールドC2025 の「1¼(PhileasFogg)」・CCA オークス2015 の「N(Chatterbox)」）：繰り上がった前の馬との差が分からないので空にし、注に元の表記を残した。
- 読めない表記（コックスプレート2017 の「41/14」・ドイツダービー2017 の「¾1」・ベルリン大賞1996 の「1¾2½」・フロリダダービー2017 の「11/」・ウッドワードS1997 の「W」）、ジョージライダーS2000 の「tR」（同着の印。相手と着順が分からない）：空にして注に元の表記を残した。
- 同着の組で片方が「dh」「d.h」「dead heat」だった15組：2頭とも前の着順の馬との差にそろえた。
