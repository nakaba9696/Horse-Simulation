## 1. 能力の決まり方（いま）

どの値がどこで決まるか（`js/core/horse.js` の `H.fromHistoric`・`js/core/datafix.js`・`data/horse_fix.js`・`data/mud.js`・`data/style_fix.js`・`data/famous*.js`）。r は実績の格から決めた強さ（`rating`。総合力の元）。

| 能力 | 決め方 | 名馬 1,512頭のうち手で決めた馬（1回目の数え） |
|---|---|---|
| 根性 | r − 1 ＋ 勝率の補正（−3〜＋5）＋ 無敗（5戦以上）で ＋2 | 0（全部自動） |
| 気性 | r − 6 ＋ 脚質（逃げ −3・先行 ＋2・差し 0・追込 −2）。掛かり癖・出遅れ癖があれば −14 | 17（ほかに癖で下げた馬 24） |
| 坂 | r − 5 ＋ ダートの馬 ＋3 ＋ 急坂の競馬場で重賞を2つ以上勝った ＋2 | 0（全部自動） |
| 健康 | 75 ＋ 戦数（40戦以上 ＋8・25戦以上 ＋4・8戦以下 −4） | 17 |
| 切れ（1〜8。小さいほど長く脚を使う） | 名馬の解説（`data/famous*.js`）の値。無ければ脚質（逃げ3・先行4・差し6・追込6、ダート −1、長距離 −1） | 648 |
| 脚質 | 手で確かめたデータ（`data/historic_*.js`）。記録から作った馬（`historic_auto.js`）は名前からの引き。名の知れた馬は `data/style_fix.js` で直す | 1,005（引きのまま 507） |
| 距離 | データの幅。勝った G1（2歳戦を除く）の距離は必ず幅に入る | ― |
| 芝・ダートの適性 | 勝ち鞍の格から（`H.surfaceApt`） | ― |
| 重馬場の適性 | 66（ふつう）。`data/mud.js` の馬だけ得意 90（道悪○）／苦手 35 | 87 |
| 成長型 | 手で確かめたデータ。記録から作った馬は勝った年齢から | 986 |
| 癖（特殊能力） | 名馬の解説か `data/horse_fix.js` に手で書く（運では付けない。持ち主の決定 2026-10-20） | ― |

**全体の所見**
- 根性・気性・坂は、ほぼ「強さ（r）」の言い換えになっている。強い馬ほど気性が良く、坂に強い。気性難で知られた馬も、癖の特殊能力が無ければ気性は 80〜95 になる。
- 健康は戦数だけで決まり、度重なる骨折の馬も 75 のまま（ゲームに故障は無く、健康は疲労の抜けに効く）。
- 記録から作った名の知れた海外の馬 525頭は、脚質が名前からの引きのままだった（名鑑・名馬の解説が無いので、いままで決め直していない）。今回18頭を直し、残りは 507頭。

## 5. 2回目：Codex のレビューを受けて（2026-10-25）

Codex のレビュー（枝 `codex/abilities-review` の `docs/review/codex/ABILITIES_REVIEW.md`）が挙げた候補を、外の出典を開いて1頭ずつ確かめた。確かめられたものだけ直した（直す前の値は `data/horse_fix.js` の `was`）。

**総合力は1頭も動いていない。** 確かめ方：直す前と後で、史実馬・スペシャルホース・伝説級の全 7,255頭の画面の総合力（芝・ダート）を書き出して比べた（動いたのは下の表の能力だけ）。`tests/extra_abilities.js` も、`was` の馬ごとに直す前と後の総合力が同じことを確かめる。逃げが付く・外れる馬と距離の上が広がった馬は、スピード・スタミナを直す前の値に止めた。

### 5-1. 距離の根の直し
