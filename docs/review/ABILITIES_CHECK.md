## 1. 能力の決まり方（いま）

どの値がどこで決まるか（`js/core/horse.js` の `H.fromHistoric`・`js/core/datafix.js`・`data/horse_fix.js`・`data/mud.js`・`data/style_fix.js`・`data/famous*.js`）。r は実績の格から決めた強さ（`rating`。総合力の元）。

| 能力 | 決め方 | 名馬 1,512頭のうち手で決めた馬 |
|---|---|---|
| 根性 | r − 1 ＋ 勝率の補正（−3〜＋5）＋ 無敗（5戦以上）で ＋2 | 0（全部自動） |
| 気性 | r − 6 ＋ 脚質（逃げ −3・先行 ＋2・差し 0・追込 −2）。掛かり癖・出遅れ癖があれば −14 | 17（ほかに癖で下げた馬 24） |
| 坂 | r − 5 ＋ ダートの馬 ＋3 ＋ 急坂の競馬場で重賞を2つ以上勝った ＋2 | 0（全部自動） |
| 健康 | 75 ＋ 戦数（40戦以上 ＋8・25戦以上 ＋4・8戦以下 −4） | 17 |
| 切れ（1〜8。小さいほど長く脚を使う） | 名馬の解説（`data/famous*.js`）の値。無ければ脚質（逃げ3・先行4・差し6・追込6、ダート −1、長距離 −1） | 648 |
| 脚質 | 手で確かめたデータ（`data/historic_*.js`）。記録から作った馬（`historic_auto.js`）は名前からの引き。名の知れた馬は `data/style_fix.js` で直す | 987（引きのまま 525） |
| 距離 | データの幅。勝った G1（2歳戦を除く）の距離は必ず幅に入る | ― |
| 芝・ダートの適性 | 勝ち鞍の格から（`H.surfaceApt`） | ― |
| 重馬場の適性 | 66（ふつう）。`data/mud.js` の馬だけ得意 90（道悪○）／苦手 35 | 87 |
| 成長型 | 手で確かめたデータ。記録から作った馬は勝った年齢から | 986 |
| 癖（特殊能力） | 名馬の解説か `data/horse_fix.js` に手で書く（運では付けない。持ち主の決定 2026-10-20） | ― |

**全体の所見**
- 根性・気性・坂は、ほぼ「強さ（r）」の言い換えになっている。強い馬ほど気性が良く、坂に強い。気性難で知られた馬も、癖の特殊能力が無ければ気性は 80〜95 になる。
- 健康は戦数だけで決まり、度重なる骨折の馬も 75 のまま（ゲームに故障は無く、健康は疲労の抜けに効く）。
- 記録から作った名の知れた海外の馬 525頭は、脚質が名前からの引きのまま（名鑑・名馬の解説が無いので、いままで決め直していない）。

## 2. 直したもの（確かな食い違い）

出典は名鑑（`data/profiles*.js`。JBIS・netkeiba・ja/en.wikipedia で確かめた史実）と名馬の解説（`data/famous*.js`）の文。直す前の値は `data/horse_fix.js` の `was` に残した。

**決め方（今回の線引き）**
- 気性：名鑑・解説が気性難を馬の特徴として書いている馬だけ。癖の形（ゲート・掛かる）が書いてあれば癖の特殊能力（気性 −14 は今の仕組み）、形が書いていなければ気性を自動の値から −10。1回だけ「折り合いを欠いた」「出遅れた」馬は直さない。
- 健康：骨折・屈腱炎などを2度以上、または脚部不安で何度も休んだと書いてある馬を 65（健康を手で決めた前例：パーソナルエンスン 60）。
- 道悪：`data/mud.js` の決め方（得意＝重・不良の大レースを大差で勝った・道悪巧者と呼ばれた／苦手＝苦手と言われた・1番人気の道悪の大レースで大敗）に合う馬。
- 距離：勝った重賞（G2・G3 を含む）の距離が幅から 400m 以上外れている馬。

## 4. Codex に見てほしいこと

- 記録から作った名の知れた海外の馬の脚質（引きのまま 525頭。`abilities.csv` の「脚質の出どころ」が「自動（引き）」）。
- 名鑑・解説の無い名馬の気性・癖・道悪（世間の評判で明らかなもの）。
- 根性・気性・坂がほぼ強さで決まる作りそのもの（勝負根性で知られる馬・坂巧者の扱い）。
