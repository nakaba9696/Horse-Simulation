## 1. 全体の方針

1. **固有の技は「その馬のキャリア全体の走り方」を表す**（配り役の推し。持ち主の確認待ち）。代表の一戦だけで決まる条件（例：直線入口で2〜4番手だけ・後ろ3頭以内だけ）は、その馬がよくした勝ち方に広げる。
2. **条件はいまの部品で作る。** 使う部品：順位 `rank`・頭数 `n`・距離 `D`・残り `R`・直線 `inStraight`/`straight`・先頭との差 `leader`・2番手との差 `second`・並び `close`・壁 `wall`/`wallFor`・残り600mで先頭 `led600`・**中間点の順位 `rankMid`**（記録はもうあるが、固有の条件ではまだ使っていない）・進路 `lane`・出遅れ `late`・斤量 `weight`。
   - **新しい部品は1つだけ要る：「その場で斤量が重い」（`heavy`）。** いまの「57kg以上」は、ゲームの斤量の決まり（`S.weightFor`：古馬の牡馬は58kg、3歳戦の牡馬は57kg）ではほとんどの牡馬が当てはまり、重い斤量の名馬らしさにならない。案：レースの初め（`K.setup`）に出走馬の斤量を見て「自分がいちばん重い、または平均より2kg以上重い」なら `s.heavy = true`。
3. **強さの釣り合い。** 効き目は今の固有の技の幅に収める：速さ＋3〜8%・2.5〜5秒、スタミナ＋0.03〜0.06、終いの上限＋0.1〜0.3。条件を広げた馬は、速さか秒を少し下げて、出る回数が増えた分を相殺する（表に書く）。
4. **名前。** 出典で確かめた異名はそのまま使い、出典を表に書く。出典の無い評価語（〜の女王・〜の至宝・〜の巨人など）は、**その馬の数字かレース名から取った名前**に替える案を出す（`data/uniques.js` の冒頭の決まり「異名は出典で確かめたものだけ」に合わせる）。人の名前は入れない。
5. 同じ条件・効き目の組（レビューの一覧で10組）は、史実の違いがはっきりしている所だけ分ける。マイルの3頭（ブリガディアジェラード・ゴルディコヴァ・ミエスク）や短距離の型は、史実の勝ち方が近いので同じ型のままでよい。
6. 実装は Godot 版（`hs_skills.gd` と `hs_skills.cpp`）に入れる（JS 版は作らない決まり）。データ `data/uniques.js` は正のまま直し、`node tools/export_godot.js` で書き出す。新しい条件は `godot/tests/` で、当てはまる場面と当てはまらない場面を確かめる。

## 4. 持ち主に決めてほしいこと

1. **前提**：固有の技は「キャリア全体の走り方」で作る（代表の一戦の再現にしない）。→ 推し：はい。
2. **名前**：出典の無い評価語の名前（29頭）を、数字・レース名の名前に替える。→ 推し：替える。残したい名前があれば、その馬だけ指名してください（例：「府中の女神」は残す）。
3. **エクリプスの「ほかの馬の脚を削る」効き目**（foeE）：史実の言葉「Eclipse first, the rest nowhere」は、ほかの馬が大きく離された（失格の距離）という意味で、相手が弱ったという記録ではない。→ 推し：外して、自分の脚の持ち（スタミナ＋0.03）に替える。ゲームの演出として残すのも可。
4. **新しい部品 `heavy`（その場で斤量が重い）を足す**。→ 推し：足す。
5. **レビューが維持とした馬の動きを直す**（オーモンド・ブリガディアジェラード・テイエムオペラオー・セクレタリアト・ドクターフェイガー）。→ 推し：直す（理由は表）。

注意（実装のとき）：
- `rankMid` は中間点を過ぎた最初の 0.1 秒の順位。中間点より前の「後ろ」を見たい型（longMakuri など）はこれでよいが、中間点より後に下がった馬（オルフェーヴルの逸走のような場面）は拾えない。それでよいかは遊んで確かめる。
- 「直線入口」は今の型と同じく `straight - R < 30`。
- 型を足したら、JS（データの道具と一致テストのため）・GDScript・C++ の3か所の `UWHEN` を同じにする。一致テスト（golden）は今ある仕組みの分だけなので、新しい型は Godot のテストで確かめる。

## 7. 確かめられなかったこと

- ミルリーフの凱旋門賞・キングジョージ・エクリプスの道中の位置。
- クリフジの道中の位置。
- カウントフリートのベルモントSが逃げ切りか。
- ネアルコの伊ダービーの勝ち方、フォアゴーのマールボロCの着差、プリティーポリーのオークス・セントレジャーの着差。
- 「〜の女王」「〜の至宝」など29頭の名前の出典（見つからなかったので名前の案を出した）。
- 日本の馬は JRA・JBIS の公式の記録、海外の馬は各国の公式の成績表（Racing Post・Equibase など）で、データを直す前に数字を見直す。
