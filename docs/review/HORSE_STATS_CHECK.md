競馬ゲーム「ターフの系譜」の馬の能力値を見てもらうための依頼文です。下の「---」から下を、レビューする AI（Codex など）に渡してください。

あなたは競馬（日本・海外の平地競走、1800年代〜2026年）に詳しいレビュアーです。PC 向けの競馬ゲームに出てくる実在の馬の能力値を見て、史実の強さと合わない所を挙げてください。

## 一覧の区分
- **史実馬（毎年デビュー）**（4740頭）：1989〜2026年に走った馬。毎年ランダムにデビューし、プレイヤーが買って乗る。AI の馬としても走る。
- **スペシャルホース**（244頭）：1989年より前に走り終えた名馬。条件（歴代の三冠馬など）のリーチがかかったときだけ、最後のレースに出てくる。
- **スペシャル＋隠し馬**（78頭）：上のうち、トロフィー（レースの組み合わせの制覇）のリーチで出てくる馬。
  - 「トロフィーの隠し馬」の列は、どのトロフィーで出るかを示す。
  - 「（無敗のとき）」は、プレイヤーの馬が無敗のときだけ出る馬。

## 数の読み方
- **総合力**（芝・ダート別、1〜99）はその馬場のスピードとスタミナだけで決まり、いちばん良い時期の値を載せている。作者の決めた目安は次のとおり。

| 総合力 | 目安 |
|---|---|
| 46〜50 | OP 馬 |
| 51〜55 | G3 馬 |
| 56〜60 | G2 馬 |
| 61〜65 | G1 馬 |
| 66〜80 | G1 を何度も勝った名馬 |
| 81〜85 | 神話の名馬 |
| 86〜99 | オリジナルホース（ゲームで作る馬）だけ |

- **能力**（スピード・スタミナ・根性・気性・坂）は 100 前後が名馬。芝とダートでスピード・スタミナが別。
- **適性**は 100 が得意。走っていない馬場は低い。
- **切れ**は1〜10。
- **成長型**は8つ（超早熟・早熟・早め・普通・遅め・晩成・超晩成・持続）。
- **特殊能力**は馬の性質（大舞台・出遅れ癖・掛かり癖など）。
- **発動する特殊能力**は、レース中の場面で効く技（上限1〜4。一部の名馬には固有の技）。
- **隠し馬の総合力**は表の値のまま出るとは限らない。トロフィーの難しさごとに下限（70・72・75・78・81・84）があり、出るときは下限まで上がる。表に載っているのは上げる前の値。

## 作者の方針（守ってほしいこと）
- 値は運（乱数）で決めず、実績と逸話から決める。
- 芝・ダートは勝ち鞍から決める。走っていない馬場は低くする（−15 ほど）。
- 古い馬は伝説の扱いで決める。
- 史実の裏付けの無い弱み（出遅れ癖・掛かり癖など）は付けない。
- 1989〜2026年の現役馬のいちばん上は80前後。

## 見てほしいこと
1. **強さの順が史実と合わない馬**：格下の馬がずっと上にいる、名馬が低すぎる、など。比べる相手の馬を添えて。
2. **芝とダートの向きの間違い**：ダートの名馬なのにダートが低い、など。
3. **距離・脚質・成長型の間違い**：例えば、逃げ馬なのに差しになっている。
4. **特殊能力の間違い**：史実の裏付けの無い弱みが付いている、名馬に「大舞台」が無い、など。
5. **区分の間違い**：スペシャルホースに入るべき有名な馬が無い、名の知れていない馬が入っている。
6. **隠し馬の選び**：そのトロフィーの最後に出る相手として、ふさわしくない馬。

全部の馬を見なくてかまいません。名の知れた馬（G1 を勝った馬・スペシャルホース・隠し馬）を優先し、目立つ間違いを挙げてください。
