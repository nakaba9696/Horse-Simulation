## 2. ほかに見つけた問題：直すもの（小さく、決まりがはっきりしている）
今回の枝では直していない（色の役目の仕事と混ぜないため）。次の UI の仕事で直す。

1. **GF の順位の表**：全部の行に「その距離の実力」「—」が同じ字で出ていて、作りかけに見える（`hs_season.gd` の `why`）。列の見出しが無い。→ 列に見出し（「出られる理由」「G1」）を付け、同じ理由が並ぶときは字を薄くする。
2. **店・厩舎・お手馬の詳しい画面の 3D の馬の見本**：床が平らな明るい緑一色で、背景の草と同じ色の帯になり、安っぽい。→ 床を暗い面の色にして、影だけ落とす（または厩舎の床の質感）。
3. **表の列の見出し**（11px・控えめの色）が写真の上にあり、明るい所で読みにくい（店・厩舎・番組表・ホームのお手馬）。→ 見出しの行も面の台の中に入れる。
4. **ホームのお手馬が少ないとき**、左の下が大きく空く（2026-10-17 の表にもある）。→ いまは今週の重賞で埋めているが、お手馬 3 頭のときも重賞の枠を伸ばす。
5. **データの画面**：表が 1 行のときに画面の大半が空く。→ 空のときは「まだ記録が無い」の 1 行と、何をすると記録が付くかを 1 行。
6. **お手馬の詳しい画面の能力のタブ**：下が大きく空く（前から）。→ 成長の山（曲線）をここに出す（docs/UI.md「馬の画面」の 2）。
7. **タイトルの「つづきから」**：セーブが無いときに、空の暗い箱が一番上に来る。→ セーブが無いときは出さない（「はじめから」を一番上に）。

## 3. 持ち主に聞くこと（推しの案つき）

**持ち主の決定 2026-10-24「UI 一旦おすすめにして」：1-1・2-1・3-1・4-1（いま入っている形）で決まり。**
答えは番号と案の番号で（例「1-1、2-1、3-1、4-1」）。「全部おすすめで」でもよい。

### 1. 押せる物（ボタン・行の札）の色
比べた絵：[choice_act_color.jpg](../shots/godot/ui_contrast/choice_act_color.jpg)（上が牧場・下がタイトル。どれも測りは合格）
- **1-1. 鞍の革（推し・いま入れた色）**：緑の背景とも緑の板とも色の仲間が違い、金の縁と合う。競馬の道具（鞍・手綱）の色。
- 1-2. 青竹（明るい緑）：テーマの緑のまま明るくした色。明るさの差はあるが、牧場の草と同じ緑の仲間に見える。
- 1-3. 鉄紺（青み）：緑とはっきり違うが、深緑と金のテーマから離れ、紺のテーマに近く見える。

### 2. 表の行の色
比べた絵：[choice_row_color.jpg](../shots/godot/ui_contrast/choice_row_color.jpg)（左がいま・右が行も革にした場合）
- **2-1. 行は墨の緑（面より一段明るい）、カーソルの行と行の操作の札（予約する）だけ革（推し・いま）**：20 行の表が重くならない。カーソルの行がよく目立つ。
- 2-2. 行も全部革：押せることは分かりやすいが、表が茶色一面になり、ダートの札（茶）と混ざる。

### 3. 持ち主の部品の絵（GPT で作った絵）の扱い
- **3-1. いまの絵の面だけを塗り替えて使う（推し・いま）**：絵の金の縁・角の飾りはそのまま。もとの絵は残してあり、すぐ戻せる（`UiSkin.roles = false`）。
- 3-2. 鞍の革の面で、ボタン・行の絵を GPT で作り直す（頼み方は `docs/art/UI_ART_REQUEST.md` に足す）。革の質感（しぼ・ステッチ）が入って、もっと「それっぽく」なる。持ち主の手間がかかる。

### 4. 背景の写真の見せ方
- **4-1. 表やボタンのある所は面の台で写真を隠し、空いた所（牧場の下半分・タイトルの右）だけ写真を見せる（推し・いま）**
- 4-2. 面の台をやめ、幕を濃くして全体に写真を暗くする（写真がほとんど見えなくなる）

## 4. 測り方（次に UI を直すときも）
- `sh godot/tools/shot_screens.sh 出力先 --contrast`：16 画面を撮って、押せる物ごとに測る。`contrast.txt` の「足りない=0」がどの画面も 0 になること。
- `sh godot/tests/run.sh test_contrast`：役目の色の値（面・行・押せる物・選んだ物・縁・字）と、塗り替えた絵が theme.gd の色とそろっているか。
- 色を変えたら `python3 godot/tools/ui_roles.py` を回してから撮る。
