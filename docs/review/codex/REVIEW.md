## 能力の条件・効き目を踏まえた注意

全定義の条件・効果は [SKILL_REFERENCE.md](SKILL_REFERENCE.md)、関数の原文と数値は [skill-catalog.json](skill-catalog.json)。指定の `js/core/skills.js`・`js/core/horse.js` を読み、定義の効果が実際に使われる `racesim.js` と Godot 対応箇所も静的に確認した。

- 馬の性質25種・発動26種・固有50種を確認。「名前だけ同じなら同じ効果」として扱わない。
- 通常の発動は1〜4枠、固有は別枠なのでCSVに5つ並んでも上限違反ではない。個別指定trigも考慮する。
- CSVはピーク時の自動習得。実レースでは成長後の現在能力から再判定するため、若い時もCSVどおり全スキルがあるとは限らない。
- シンボリルドルフは既に折り合い上手（1600m以上、中間点まで掛からないとE+0.02）を持つ。賢い競馬の表現がないという指摘はしない。
- セントサイモンは掛かり癖が既に付いている。固有自体が純粋なプラスでも、馬全体にデメリットがないとは言えない。
- キンチェムは指定のど根性・折り合い上手を既に持つ。「タフネス表現が未実装」とは言わない。ただしど根性はレース中のE回復で、レース後の疲労回復ではない。
- 「追走○」「外回し○」のwhen=falseは未実装ではない。シミュレータの継続フラグでそれぞれ消耗軽減や外回りの損を減らす。
- 左右の苦手は実際に力−1.5。単なる説明文ではない。G1での大舞台+2や得意回り+1.8と比較して小さくない。
- 一気系は3種を持っても1レースで1つだけ発動。発動時Eで速度効果が0.6〜1.6倍になる。固有を含め、速度ブーストは同時に単純加算されず後の発動で上書きする。
- 「大舞台がない」だけでは強さ不足と断定しない。パッシブ・固有・発動の条件、基礎値を合わせて見る。

## 個別の値より先に見直したい生成根拠

1. **脚質が名前由来の抽選のまま。** `tools/build_auto.js:122–124` でhashRngから決めており、能力生成を乱数から外した後も残っている。ラヴァマン追込・タイムワープ差し・フィアースネス追込等は通過順位の照合対象。現在のGodot書き出し済みデータにも反映されている。「決定的な結果」でも「史実に基づく結果」とは違う。
2. **反対回りでの勝鞍ゼロを不得手とみなす。** `js/core/horse.js:319–324` と `godot/core/hs_horse.gd:346–351`。本当の全出走・敗戦・証言を見ずに×が付く。作者の「裏付けのない弱みは付けない」と食い違う。自動付与をやめて個別出典へ分ける案。
3. **ゲームの暦と史実実績が結びつきすぎる。** 暦にない主要競走の実績は、芝ダ適性・大舞台・スペシャル選定・CSV G1数へ反映されにくい。フォルリで登場漏れを確認。「G1勝ち数」は現実の全G1勝利数と同義ではなく、今回も当時の格を年で選ばず判定する書き出し部分がある。史実用の競走実績メタデータを遊ぶ暦と分けるとよい。
4. **距離の表記が実力へ直接影響する。** Godot hs_sim.gd:305–306で範囲外100mごとに短距離側−1.4・長距離側−1.2、:496で上限距離がスタミナ距離へ入る。68頭のG1距離範囲外候補を抽出したが、古馬と2歳の適性差や10mの差も混ざるため全件を誤りとはしない。AIは史実目標優先の処理が距離フィルタより前にあり、「距離外だから必ず自動出走しない」とは言わない。
