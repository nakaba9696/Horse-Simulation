## 検証・採用時の注意

- CSVの現行生成結果との完全一致を確認。`tests/extra_abilities.js` の既存3チェックはすべて成功。報告書だけの変更のため、全ゲームの `node tests/run.js` は実行していない。
- 勝ったG1相当の距離を内部照合すると、生の距離では20件が幅の外だった。ただしこの数は誤り件数ではない。2410→2400m、2040→2000m、1850→1900mなどは既存の100m丸め。ヒカルタカイの1966全日本三才優駿は満2歳であり、幼齢戦除外の対象として扱う。これらを上の4頭と混ぜて訂正しない。
- 距離を変えると、総合力を出すスタミナの重みも変わる。スピード・スタミナを単に固定するだけでは維持できない例があり、メモリ上の試算でファーラップは芝77.5→78、テツノカチドキはダート64→65へ動いた。**これは採用案の総合力ではなく、避けるべき副作用の確認**。元の芝・ダートの重み付き値を保つ補正で、距離4頭とカブトシローの現行総合力を維持できることを確認した。コードやデータには適用していない。
- 脚質変更は気性・切れ・自動習得する発動能力へも波及する。カブトシローの気性は、先行→追込の自動差だけで70→66となるため、今回は70を維持する案とした。新しい気性難の裏取りなしに減点を重ねない。
- 出遅れ癖は実装上、発馬遅れの確率へ直接加算される。気性難なら何でも出遅れ癖に置き換えると、ゲート入り拒否・掛かり・単なる臆病さを混同する。GDScript [godot/core/hs_sim.gd](../../../godot/core/hs_sim.gd#L527) と C++ [godot/native/src/hs_sim.cpp](../../../godot/native/src/hs_sim.cpp#L157) を確認した。
