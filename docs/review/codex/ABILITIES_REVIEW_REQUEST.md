# 名馬の能力（総合力の下）のチェック依頼

競馬ゲーム「ターフの系譜」の史実馬の、総合力の下にある能力（根性・気性・坂・健康・切れ・脚質・距離・馬場の適性・癖）を、外の目で見てもらうための依頼文です。持ち主の決定（2026-10-24「Codexとまたレビューしあいながら世間の認識と乖離がないようにしたい」）で、こちら（Claude）の洗い出し（`docs/review/ABILITIES_CHECK.md`）と突き合わせます。

---

あなたは競馬（日本・海外の平地競走、1800年代〜2026年）に詳しいレビュアーです。PC 向けの競馬ゲームに載る名馬（1,512頭）の能力の数を見て、出典や世間の評判（気性難で知られる・道悪巧者・坂に強い・晩成・脚の切れ・逃げ馬など）と明らかに食い違う所を挙げてください。

## 見てほしいファイル
- リポジトリ `nakaba9696/Horse-Simulation`、ブランチ `claude/ability-review`。
- 一覧：`docs/review/abilities.csv`（UTF-8。`node tools/review_abilities.js` で作ったもの）。
  - 列：区分・名前・英名・生年・国・性・芝とダートの総合力・根性・気性・坂・健康・切れ・脚質・距離・芝とダートと重馬場の適性・成長型・特殊能力（癖を含む）・発動する特殊能力・戦績・G1 の勝ち数・主な勝鞍・持ち主が決めた総合力（○）・名鑑の手がかり・見どころ。
  - 能力ごとに「出どころ」の列がある。「手」は手で決めた値、「自動」は下の決まりで出した値、「自動（引き）」は名前から引いただけで裏付けの無い値。
  - 「見どころ」は、名鑑の文の言葉といまの値が食い違っていそうな所を機械で拾った目安（多くは食い違いでない）。
- こちらの洗い出し：`docs/review/ABILITIES_CHECK.md`（能力の決まり方・直したもの・直さなかったもの）。
- 元のデータ：`data/horse_fix.js`（手で決めた値と理由 `why`。`was` は今回直す前の値）・`data/mud.js`（道悪の得意・苦手）・`data/style_fix.js`（脚質を決め直した馬）・`data/famous*.js`（名馬の解説・切れ・特殊能力）・`data/profiles*.js`（名鑑の文）。

## 能力の決まり
- **総合力（芝・ダートの数）は持ち主が決めたので、ここでは見ない。** 能力を直すときも総合力は動かさない。
- 能力の数のめやす：名馬の根性・気性・坂は 80〜105。気性は 70 より下で掛かりやすく、75 より下で出遅れやすい。
- 癖（特殊能力）：掛かり癖・出遅れ癖（気性 −14）・ソラ癖・砂かぶり×・左回り×・右回り× など。癖は逸話のある馬だけ手で付ける（運では付けない）。
- 健康：疲労の抜けだけに効く（ゲームに故障は無い）。ふつう 75、度重なる故障の馬を 65 にした。
- 切れ：1〜8。小さいほど長く脚を使う（ズブい）、大きいほど一瞬で突き抜ける。
- 脚質：逃げ・先行・差し・追込（と脚質自在）。
- 重馬場：66 がふつう。得意 90（特殊能力の道悪○も付く）・苦手 35。決め方は `data/mud.js` の頭の注。
- 距離：得意な距離の幅。勝った G1 の距離（2歳戦を除く）は必ず幅に入る。
- 持ち主が決めた値（`why` に「持ち主」とあるもの）は、そのまま残す前提。おかしいと思ったら挙げてかまわないが、「持ち主の値」と分かるように書く。

## 見てほしいこと（大事な順）
1. **脚質が引きのままの名馬**（「脚質の出どころ」が「自動（引き）」の 525頭）：とくに G1 を多く勝った馬・総合力の高い馬。出典（Wikipedia の本文・レースの記事）で、ふだんどの位置で運んだかが分かる馬の脚質。
2. **気性・癖**：気性難・掛かる・ゲートが悪いことで知られた馬に癖が無い、または気性が高すぎる。逆に、落ち着いた名馬に癖が付いている。
3. **道悪・坂**：道悪巧者・道悪が苦手と言われた馬、坂（中山・阪神・ニューマーケットなど）の巧拙で知られた馬が、ふつうの値のまま。
4. **切れ・距離・成長型**：瞬発力型か長く脚を使う型か、距離の幅、早熟・晩成が、評判と逆になっている馬。
5. **健康**：鉄の馬と呼ばれた馬・故障の多かった馬。
6. こちらの直し（`ABILITIES_CHECK.md` の2）と、直さなかった案（同じく3）への意見。

全部の馬を見なくてかまいません。名の知れた馬・G1 を多く勝った馬を優先し、確かな食い違いから挙げてください。出典で確かめられなかったものは「未確認」と書いて分けてください。数の案は整数か 0.5 刻みで。
