## 決まり（持ち主が決めたこと）
- 名鑑は出典で確かめた史実だけを書く。人の名前（騎手・調教師・馬主・生産者）は書かない。
- 年齢は満年齢（2000年以前の旧表記の「3歳」は満2歳）。
- **細かい着差・時計・頭数が出典で確かめられないときは、具体的な数字を書かない**（持ち主の決定 2026-10-24）。「大差」は10馬身以上と読まれるので、10馬身以上と確かめられないときは使わない。
- 固有の技の名前に、秒数・馬身・勝ち数などの数字は入れない。
- 固有の技の型（when・at）は、**その馬のイメージに合っていればよい**（代表の一戦の展開と細かく合っている必要はない。持ち主の決定 2026-10-24）。

## 見てほしいこと（大事な順）
1. **名鑑の誤り**（確かめ済みの217頭のほかの約567頭を優先。名の知れた馬から）：
   - 年・年齢・戦績（戦数と勝ち数）・主な勝鞍・相手の馬・着差・時計・出来事・種牡馬や繁殖の成績・死んだ年。
   - 出典どうしが食い違うときは「食い違い」と書き、両方の出典を挙げる。
2. **確かめられない細かい数字**：出典が見つからない着差・時計・頭数・日付。数字を外す案を書く。
3. **固有の技の型が、その馬のイメージに合わない所**（D3。特にカウントフリート・クリフジ）：逃げ馬なのに差しの型、など。名前（label）に数字が入っていないかも見る。
4. 人の名前が入っている所（あれば）。

全部の馬を見なくてかまいません。確かな食い違いから挙げてください。外部のサイトで確かめられなかったものは「未確認」と書いて分けてください。
