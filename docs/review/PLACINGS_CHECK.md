## 作り方（知っておいてほしいこと）
- JRA・地方の出典は JBIS サーチのレース結果。
- 「勝ち馬との着差」は、前の馬との差を積み上げて作った（3着より下は、馬身は足し算、ハナ・アタマ・クビは後ろに並べる。例「3+クビ」）。
- 降着が5着までにあるレース（2009秋華賞・2010スプリンターズS・2010ジャパンカップ・2016皐月賞・2019NHKマイルC・2020高松宮記念）は、2着より下の着差を空にしてある。
- 外国馬は JBIS では英字なので、カナに直した（元の綴りの列）。カナを確かめられなかった20頭は英字のまま「注」がある。
- 2026年は10月18日の秋華賞まで。

## 見てほしいこと
1. **着順の誤り**：着順の入れ違い・別の年の結果・同名の別馬・抜けた馬。
2. **着差の誤り**：元の表記の写し間違い、積み上げの計算違い。
3. **カナ名**：外国馬のカナが日本で通っている呼び方と違うもの。英字のままの20頭のカナ。
4. **レース名と年**：ゲームのレース名（年代で名前が違うもの）と年の対応のずれ。
