## 要点

- 1989〜2026年に走った馬（毎年デビューする馬。4,630頭）で、画面の総合力が **73.0 以上は25頭**。
  - ロマンチックウォリアーは、もう香港トリプルクラウンの隠し馬。そのまま。
  - **22頭**は史実で取った条件に合うトロフィーがある。13のトロフィーに入れる。
  - **2頭**（エルコンドルパサー・ワイズダン）は合うトロフィーが無い。入れず、今までどおりデビューする。
- 22頭は、いまはどのグループにも入っていない（1989年からの馬は、香港の6頭のほかスペシャルホースの元に入っていない）。**抜けるグループは無い**。古い隠し馬は全部残す。
- データの写しに推しの形を入れて読み込み、22頭がどれもそのトロフィーのグループ1つだけに入ることを確かめた。スペシャルホースは 334 → 356 頭になる。
- 1つのレースに出てくる名馬は4頭まで（`SP.MAX_IN_RACE`。データの評価の高い順）。推しの形では、**22頭とも出番がある**（下の「4頭の枠」）。
- 最初の頼みで選んだ「いい隠し馬がいないトロフィー」15のうち、この25頭で埋まるのは7つ。残りの8つには、72.9 以下の候補を別に書いた（入れるかは持ち主が決める）。
- 70.0 以上のデビューの帯に残る馬は **138頭**（164頭 − 香港の4頭 − 22頭）。帯は足りる。

## 読み方

- **総合力**は画面に出す数（`HS.Season.fhShowPeak`。`tools/special_audit.js` の makeKit と同じく、データのままの馬をいちばん良いときの力で数えた）。`HIDDEN_HORSES.md` の数（`fhPeak`）とは目盛りが違う。「芝」「ダ」は、その馬の高いほうの馬場。
- いまの隠し馬の画面の総合力の、難しさごとの中央値：1：60・2：67.5・3：71・4：74・5：72.75・6：75.5。
- **印**（`HIDDEN_HORSES_CHECK.md` と同じ）：
  - ◎：条件を全部（同じ年に。連覇のトロフィーは2年続けて）
  - ○：同じ年に条件の2つ以上、または半分より多い
  - ○別：条件の2つ以上を、別の年に（例：シガーの1995年 BCクラシックと1996年ドバイWC）
  - △：条件のレースを1つだけ（入れない）
- 取った条件は、ゲームのデータ（`data/historic*.js`・`data/historic_auto.js` の勝ち鞍）から数え、22頭とも出典で確かめた（最後の「出典」）。

1. 馬ごとに、いちばん印の良いトロフィーへ（◎ ＞ ○ ＞ ○別）。同じ印がいくつかあれば、いまの顔ぶれの少ないほうへ。

## 隠し馬にすると、デビューしなくなる（損と得）

持ち主の決定「隠し馬は基本プールからはずしたい」で、隠し馬にした馬は1989年からの馬でも、毎年のデビューと始めの世界に出なくなる。店にも、倒すまで並ばない。倒すと店にいつも並ぶ。

- **損**：22頭は、ライバルとして世界を走らなくなる。店の品ぞろえで偶然に出会うことも無くなる。日本の馬は9頭（ディープインパクト・オルフェーヴル・ナリタブライアン・アーモンドアイ・イクイノックス・テイエムオペラオー・キタサンブラック・ロードカナロア・フォーエバーヤング）で、デビューの年から自分で買って育てる遊びができなくなる。
- **得**：その馬に会えるのは、自分の馬がそのトロフィーにリーチをかけたときだけになり、出会いに意味がつく（三冠の最後の菊花賞でディープインパクトとオルフェーヴルが待つ、ジャパン GS の最後の有馬記念でテイエムオペラオーが待つ、など）。倒せば、そのあとはいつでも店で買える。いちばん強い馬が世界に散らばらないので、ふだんのレースで勝ちを取られにくくなる。
- **釣り合い**：73.0 以上に絞ったので、外れるのは25頭のうち22頭だけ。70.0〜72.9 の138頭（シンボリクリスエス・ウオッカ・ゴールドシップ・ジェンティルドンナなど）は今までどおりデビューするので、世界の顔ぶれは名の知れた馬が多いまま。推しは「22頭とも隠し馬にする」。
- 前の版のこの文書に書いた「その年に世界で走っていると隠し馬として出ない」は、この決定で起きなくなる（隠し馬はデビューしないので、走っていることが無い）。

## 70.0 以上のデビューの帯への影響

デビューの割合（総合力70.0以上の帯から5%＝毎年300頭のうち15頭。帯に残りが足りなければ下の帯から埋める）は、別の子セッションが入れている作りで、ここでは届いた説明から見積もった。

- 70.0 以上の帯に残る馬は **138頭**（164頭 − 香港の4頭 − 22頭）。
- 始めの世界は2〜6歳の5世代で、帯から使うのは 15×5＝75頭。帯は足りて、下の帯から埋めることは無い。そのあとも毎年の15頭は、走っていない残り（およそ60頭）から出せる。

## 頭の決まりのコメントの直し方（案）

```js
// 名馬は1989年より前に走り終えた馬と、1989〜2026年の馬のうち総合力（画面の数）73.0以上の馬で、
// そのトロフィーの条件を史実で取った馬（持ち主の決定 2026-10-24「89-26でも一部は隠し馬にいれていいかも」・
```

## 決めてほしいこと

1. **推しの一覧で入れるか**（13のトロフィーに22頭を足す）。推し：推しで。
2. **ブラックキャビアとウィンクスを、インモータルロードでなく豪州スプリント三冠・オーストラリアン GS に入れるか**。推し：入れる（インモータルロードの芝が4頭の枠に収まり、いい隠し馬のいなかった2つが埋まる）。
3. **あふれる古い隠し馬**（日本牝馬三冠の5頭など）のために、出る順を「まだ倒していない馬を先に」にするか。推し：する（直すのは `SP.pending` の並べ方だけ）。急がないので、別の仕事にしてもよい。
4. **72.9 以下の候補を、残る8つのトロフィーに入れるか**（オクタゴナル・スノーフェアリー・スカンジナビア・ストラディバリウス・ウィジャボード・ジャイアンツコーズウェイ・ファンタスティックライト・スマートファルコン・ホッコータルマエ・サンダースノー）。推し：持ち主が範囲を73.0以上に決めたので、入れない。入れるなら1頭ずつ言えば入る。
5. **キングオブエベレストは替えない**（候補なし）。推し：このまま。
6. PENDING の B1・B2・B4・B5（タロック・トリプティク・オールアロング・トムフール）は、この案と重ならない（同じトロフィーに一緒に入れられる）。別に決める。
