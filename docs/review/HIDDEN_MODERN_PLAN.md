# トロフィーの隠し馬に1989〜2026年の名馬を入れる案（2026-10-24）

持ち主の言葉（2026-10-24）「89-26でも一部は隠し馬にいれていいかも　トロフィー達成系でいいのがいないなら」への案。**データとコードは直していない**（決めるのは持ち主）。最後の「推しの一覧」は「推しで」と言えばその形で入る。

材料：`data/trophies.js`（41個）・`data/trophy_horses.js`・洗い出し [HIDDEN_HORSES_CHECK.md](HIDDEN_HORSES_CHECK.md)・強さ [HIDDEN_HORSES.md](HIDDEN_HORSES.md)・保留 [PENDING.md](PENDING.md) の B。

## 読み方

- **総合力**は画面に出す数（`HS.Season.fhShowPeak`。`tools/special_audit.js` の makeKit と同じく、データのままの馬をいちばん良いときの力で数えた）。`HIDDEN_HORSES.md` の数（`fhPeak`）とは目盛りが違う。出るレースの馬場（芝・ダ）の数を書いた。
- いまの隠し馬の画面の総合力の、難しさごとの中央値：1：60・2：67.5・3：71・4：74・5：72.75・6：75.5。
  - ▼：ひとつ易しい難しさの中央値より低い。▼▼：ふたつ易しい難しさの中央値よりも低い（`HIDDEN_HORSES.md` と同じ決め方）。
  - 1989〜2026年の馬でいちばん高いのは芝76（シーザスターズ・フランケル）、ダ75.5（フライトライン）。難しさ5で ▼ が残るのは、データの上限のため。
- **ふさわしさ**（`HIDDEN_HORSES_CHECK.md` と同じ印）：◎ 条件を全部（当時の名前・形でよい）・○ 半分より多い、または同じ年に2つ以上・△ 1つだけ・□ 条件のレースが当時まだ無い・× あったのに1つも勝っていない。
- 出典は en/ja.wikipedia。JRA・主催者の頁との突き合わせはしていない。

## 1989年からの馬を隠し馬にするときに気をつけること

- **世界で走っている年は出ない**（`SP.canAppear`）。毎年300頭がデビューし、いつも走っている史実馬はおよそ800頭、出られる馬は4,630頭なので、ある馬が走っている年はおよそ6年に1年。その年は、同じトロフィーの古い隠し馬だけが出る。**だから古い隠し馬は残すのを推す**（控えになる）。
- **倒すと店にいつも並び、それからは毎年のデビューに選ばれない**（`E.pick`）。テイエムオペラオーやディープインパクトを倒すと、そのセーブでは世界のライバルとして走らなくなる。店の品ぞろえ（毎月の牡馬・牝馬10頭ずつ）を待たずに、いつでも買える。
- 自分の馬として引退させた馬は「走っている」に数えないので、隠し馬として出てくる（香港の三冠と同じ）。
- **1頭は1つの条件だけ**：下の候補はどれもいまはスペシャルホースではない（1989年からの馬は、香港の6頭のほかスペシャルホースの元に入っていない）。足しても抜けるグループは無い。候補どうしも重ねていない（エネイブルはターフロイヤル GS だけ、マカイビーディーヴァはオーストラリアン GS だけ、など）。
- 1つのレースに出てくる名馬は4頭まで（`SP.MAX_IN_RACE`）で、データの評価（rating）の高い順。

## 頭の決まりのコメントの直し方（案）

`data/trophy_horses.js` の 80〜82行目を、次のように替える。

```js
// 名馬は1989年より前に走り終えた馬を主にする（持ち主の決定 2026-10-19）。1頭が出てくる条件は1つだけ。
// そのトロフィーにふさわしい1989年より前の馬がいない・弱いときは、1989〜2026年の馬も入れてよい（持ち主の決定 2026-10-24

// 1989年からの馬は毎年ランダムにデビューする馬でもあるので、その年に世界で走っている（入厩・牧場の）ときは隠し馬として出さない。
// その年のために、古い隠し馬は控えとして残す。
```

## 決めてほしいこと

1. **推しの一覧で入れるか**（15のトロフィーのうち14に21頭を足す・ペブルスを外す）。推し：推しで。
2. **古い隠し馬を残すか**：推しは「残す」（1989年からの馬が世界で走っている年の控え。強さもたいてい古い馬と同じくらいか上）。替えて1989年からの馬だけにする手もある。
3. **弱いがぴったりの馬を入れるか**：ストラディバリウス（芝70・▼▼）とサンダースノー（ダ66.5・▼▼）。推しは「入れる」（同じトロフィーに強い古い馬が残るので、出てくる顔ぶれは弱くならない）。
4. **倒した1989年からの馬が、それから毎年のデビューに出なくなる**決まり（香港と同じ）のままでよいか。推しは「このまま」。
5. **キングオブエベレストは替えない**（候補なし）。推し：このまま。
6. PENDING の B1・B2・B4・B5（タロック・トリプティク・オールアロング・トムフール）は、この案と重ならない（同じトロフィーに一緒に入れられる）。別に決める。
