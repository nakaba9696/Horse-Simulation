**データとコードは直していない**（決めるのは持ち主）。最後の「推しの一覧」は「推しで」と言えばその形で入る。

持ち主の言葉（どれも 2026-10-24）：
- 「89-26でも一部は隠し馬にいれていいかも　トロフィー達成系でいいのがいないなら」（最初の頼み）
- 「隠し馬は基本プールからはずしたい」（隠し馬にした馬は、1989年からの馬でも毎年のデビューと始めの世界に出なくなる。別の子セッションで入れている）
- 「総合力上位の馬はだいたい隠し馬にしたい」（1989〜2026年の馬のうち、画面の総合力が70.0以上の馬を中心に、だいたい全部どこかのトロフィーへ。合わない馬は無理に入れない）

材料：`data/trophies.js`（41個）・`data/trophy_horses.js`・洗い出し [HIDDEN_HORSES_CHECK.md](HIDDEN_HORSES_CHECK.md)・強さ [HIDDEN_HORSES.md](HIDDEN_HORSES.md)・保留 [PENDING.md](PENDING.md) の B。

## 要点

- 1989〜2026年に走った馬（毎年デビューする馬。4,630頭）のうち、画面の総合力が **70.0 以上は164頭**。そのうち4頭（ロマンチックウォリアー・サイレントウィットネス・ヴォイッジバブル・リヴァーヴァードン）は、いまも香港の三冠の隠し馬。
- 残りの160頭のうち **94頭** は、史実で取った条件に合うトロフィーがある（◎・○）。**66頭** は合うトロフィーが無い（条件のレースを1つだけか、1つも勝っていない）ので入れない。
- 70.0 に届かないが、条件にぴったりで、ほかに合う馬のいないトロフィーを埋める **6頭**（＊）も足す。オクタゴナル・ネイチャーストリップ・スカイビューティ・ウィジャボード・ホッコータルマエ・サンダースノー。
- 足すのは **合わせて100頭・29のトロフィー**。どの馬も、いまはどのグループにも入っていない（1989年からの馬は、香港の6頭のほかスペシャルホースの元に入っていない）ので、**抜けるグループは無い**。外すのは条件のレースを1つも勝っていないペブルス（ワールドティアラ GS）だけで、歴代の BCターフ馬へ自動で移る。
- データの写しに推しの形を入れて読み込み、100頭がどれもそのトロフィーのグループ1つだけに入ることを確かめた。スペシャルホースは 334 → 434 頭になる。
- **いちばん大きな問題**：1つのレースに出てくる名馬は4頭まで（`SP.MAX_IN_RACE`）で、データの評価の高い順に選ぶ。このままだと、16のトロフィーで合わせて **58頭が一度も出てこない**（うち1989年からの馬42頭・古い隠し馬16頭）。出てこない1989年からの馬は、デビューもしない・店にも並ばないので、ゲームから消えてしまう。出る順の決まりを変えるのを推す（「決めてほしいこと」の2）。

## 読み方

- **総合力**は画面に出す数（`HS.Season.fhShowPeak`。`tools/special_audit.js` の makeKit と同じく、データのままの馬をいちばん良いときの力で数えた）。`HIDDEN_HORSES.md` の数（`fhPeak`）とは目盛りが違う。「芝」「ダ」は、その馬の高いほうの馬場。
- いまの隠し馬の画面の総合力の、難しさごとの中央値：1：60・2：67.5・3：71・4：74・5：72.75・6：75.5。1989〜2026年の馬でいちばん高いのは芝76（シーザスターズ・フランケル）とダ75.5（フライトライン）なので、難しさ5・6はどの馬でも中央値の差が小さい。
- **印**（`HIDDEN_HORSES_CHECK.md` と同じ）：
  - ◎：条件を全部（同じ年に。連覇のトロフィーは2年続けて）
  - ○：同じ年に条件の2つ以上、または半分より多い
  - ○別：条件の2つ以上を、別の年に（例：シガーの1995年 BCクラシックと1996年ドバイWC）
  - △：条件のレースを1つだけ（入れない）
- **取った条件**はゲームのデータ（`data/historic*.js`・`data/historic_auto.js` の勝ち鞍）から数えた。出典で1頭ずつ確かめたのは、下の「出典」に URL を書いた馬だけ。ほかの馬はデータの勝ち鞍のまま（データは重賞の勝ち馬の記録から作ったもの）。

## 割り振りの決まり

1. 馬ごとに、いちばん印の良いトロフィーへ（◎ ＞ ○ ＞ ○別）。
2. 同じ印のトロフィーがいくつかあるときは、いまの顔ぶれ（古い隠し馬も数える）の少ないほうへ。顔ぶれがトロフィーに散るようにした。
3. 手で決めたもの：G1 を10連勝以上した4頭（フランケル・ブラックキャビア・ウィンクス・ゼニヤッタ）は、ほかのトロフィーより条件にぴったりなので、インモータルロード（G1 を10連勝）の◎にした。G1 の連勝は出典で確かめた。フランケルは G1 に出て10戦10勝（ゲームは G1 だけを数えるので、間の G3 は数えない）。
4. 芝とダートで分かれるトロフィー（クラウンオブブリーダーズ・インモータルロード）は、その馬の得意な馬場の側（`TURF`・`DIRT`）。
5. いまの古い隠し馬は残す。どのトロフィーでも条件をそろえた馬で、外す理由が無い。外すのは × のペブルスだけ。

## 隠し馬にすると、デビューしなくなる（損と得）

持ち主の決定「隠し馬は基本プールからはずしたい」で、隠し馬にした馬は1989年からの馬でも、毎年のデビューと始めの世界に出なくなる。店にも、倒すまで並ばない。倒すと店にいつも並ぶ。

- **損**：上の100頭は、ライバルとして世界を走らなくなる。店の品ぞろえ（毎月の牡馬・牝馬10頭ずつ）で偶然に出会うことも無くなる。日本の名馬（ディープインパクト・アーモンドアイ・テイエムオペラオー・イクイノックスなど）を、デビューの年から自分で買って育てる遊びはできない。
- **得**：その馬が出てくるのは、自分の馬がそのトロフィーにリーチをかけたときだけになり、出会いに意味がつく（三冠の最後の菊花賞でディープインパクトとオルフェーヴルが待つ、など）。倒せば、そのあとはいつでも店で買える。強い馬が世界に散らばらないので、ふだんのレースで勝てない理由が減る。
- **釣り合い**：推しは「70.0 以上で条件に合う馬は隠し馬にする」。上位の馬は、ふだんのレースに出ると勝ちを持っていく馬で、出会いを条件に結びつけたほうが印象が強い。条件に合わない66頭（エルコンドルパサー・オグリキャップ・キングカメハメハ・グランアレグリアなど）は、今までどおりデビューするので、名の知れた馬が世界から消えきることは無い。
- 前の版のこの文書に書いた「その年に世界で走っていると隠し馬として出ない」は、この決定で起きなくなる（隠し馬はデビューしないので、走っていることが無い）。

## 70.0 以上のデビューの帯への影響

デビューの割合（総合力70.0以上の帯から5%＝毎年300頭のうち15頭。帯に残りが足りなければ下の帯から埋める）は、別の子セッションが入れている作りで、ここでは届いた説明から見積もった。

- 70.0 以上の帯に残る馬は **66頭**（164頭 − 香港の4頭 − 足す94頭）。
- 始めの世界は2〜6歳の5世代なので、帯から 15×5＝75頭を出そうとして66頭で尽き、足りない約9頭は下の帯から埋まる。そのあとも毎年の15頭は、引退して帯に戻る馬（年に十数頭）で回るので、帯の馬はほとんどいつも世界で走っていて、店に並ぶことはまれになる。
- 70.0 以上の66頭は、合うトロフィーの無い馬なので、隠し馬に回せない。帯を厚くしたいなら、足す馬を減らす（例：○別の14頭を入れない）か、帯の割合を下げる。推しは「このまま」（上位の馬が世界に少ないのは、得のほうに書いたとおりねらい）。

2. 出る順を直す（「決めてほしいこと」の2を推しで決めたとき）：`js/core/special.js` の `SP.pending` の並べ方 `key` に「もう倒した（`G.unlocked` にある）馬は後ろ」を足す。`godot/core/hs_special.gd` も同じに。
3. `js/core/special.js`（147・156行）と `godot/core/hs_special.gd`（202・209行）のコメントの「香港の三冠だけ」を直す（動きは変わらない。どちらも modern をトロフィーで分けずに読む）。

5. `node tools/hidden_horses.js`・`node tools/special_list.js`・`node tools/export_godot.js` を回し、`node tests/run.js` と Godot のテストで確かめる。

## 頭の決まりのコメントの直し方（案）

`data/trophy_horses.js` の 80〜82行目を、次のように替える。

```js
// 名馬は1989年より前に走り終えた馬と、1989〜2026年の馬のうち総合力の高い馬（画面の数で70.0以上を中心に）で、
// そのトロフィーの条件を史実で取った馬（持ち主の決定 2026-10-24「89-26でも一部は隠し馬にいれていいかも」
// 「総合力上位の馬はだいたい隠し馬にしたい」。前は1989年より前の馬だけ・香港の三冠2つは例外 2026-10-19・2026-10-20）。
// 1989年からの馬は M(…)（modern）で書く。条件に合わない馬は入れない。1頭が出てくる条件は1つだけ。
// 隠し馬にした馬は、1989年からの馬でも毎年のデビューと始めの世界に出ない（持ち主の決定 2026-10-24「隠し馬は基本プールからはずしたい」）。
// 倒すと店にいつも並ぶ
```

## 決めてほしいこと

1. **推しの一覧で入れるか**（29のトロフィーに100頭を足す・ペブルスを外す）。推し：推しで。
2. **出てこない58頭をどうするか**。いまは評価の高い順に4頭までなので、ジャパン GS（19頭）なら同じ4頭が毎回出て、15頭は一度も出ない。
   - 案1（推し）：**まだ倒していない馬を先に出す**（その中は評価の高い順）。リーチをかけるたびに新しい顔が出て、全部倒すと強い順に戻る。直すのは `SP.pending` の並べ方だけ。
   - 案2：トロフィーごとに4頭までにして、残りは入れない（デビューに戻す）。
   - 案3：毎回、種付きの乱数で4頭を選ぶ。
3. **○別（別の年に条件の2つ以上）の14頭も入れるか**。シガー・モンジュー・ウオッカ・メジロマックイーンなど。推し：入れる（どれも条件の大レースを2つ以上勝った馬）。入れなければ、70.0以上の帯に残る馬は80頭になる。
4. **70.0 に届かない6頭（＊）を入れるか**。推し：入れる（ほかに合う馬のいないトロフィーを埋める）。
5. **日本の名馬をデビューから外してよいか**（損と得は上の節）。推し：外す（条件に合わない日本の名馬は、今までどおりデビューする）。
6. **キングオブエベレストは替えない**（候補なし）。推し：このまま。
7. PENDING の B1・B2・B4・B5（タロック・トリプティク・オールアロング・トムフール）は、この案と重ならない（同じトロフィーに一緒に入れられる）。別に決める。
