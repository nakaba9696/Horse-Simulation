# トロフィーの隠し馬の強さ（データのまま）

持ち主の願い「難しいトロフィーほど強い馬だしてほしい」を、隠し馬の選び方で満たすための材料（2026-10-20）。出てくるときに能力を上げる仕組みは、持ち主の「これ言ってないんだけど　こんな仕様やめてね」でやめた。隠し馬はデータのままの能力で出てくる。選び直しはしていない（持ち主が決める）。

- 総合力：その隠し馬が出るレースの馬場（芝・ダ）の総合力。データ（史実馬・名鑑・`data/legends.js`）のまま、いちばん良いときの力。芝にもダートにもなるトロフィー（クラウンオブブリーダーズ・ホールオブフェイム・ワンダーホース・インモータルロード）は、その馬の受け持つ馬場（`data/trophy_horses.js` の `surf`）で数えた。
- 無敗：★は「無敗のとき」だけ出てくる馬。
- 印（弱く見える組）：▼＝ひとつ易しい難しさの隠し馬の総合力の中央値より低い。▼▼＝ふたつ易しい難しさの中央値よりも低い。難しさごとの中央値は 1：61・2：68・3：71・4：76.5・5：74.5・6：78。
- 作り方：`js/core/special.js` の `SP.horse`（その場限りの馬）を `HS.Season.fhOf` で数えた。データを直したら数は変わる。

## 要点

- 隠し馬 78 組（馬 × 出る馬場）のうち、弱く見える組は 20 組（▼▼ は 4 組：ジャパンダート GS（難しさ3）のテツノカチドキ［ダ］60・ワールドティアラ GS（難しさ4）のパーソナルエンスン［芝］62・ホールオブフェイム（難しさ5）のオールアロング［芝］70・インモータルロード（難しさ6）のスペクタキュラービッド［ダ］76）。
- ▼ の例：ジャパンダート GS（3）のヤシマナシヨナル［ダ］65・ジャパンダート GS（3）のロッキータイガー［ダ］62・香港スプリント三冠（3）のラッキースワイネス［芝］63・オーストラリアン GS（5）のキングストンタウン［芝］73・ジャパン GS（5）のタマモクロス［芝］73・ジャパン GS（5）のトウショウボーイ［芝］73・ジャパン GS（5）のテンポイント［芝］73・ジャパン GS（5）のハクチカラ［芝］72 など。
- 難しさごとの総合力の幅：1：59〜65・2：62〜75・3：60〜77・4：62〜80・5：70〜80・6：76〜79。難しさ5 の中央値（74.5）が難しさ4（76.5）より低く、難しさ5 の隠し馬の多くが難しさ4 の並の馬より弱い。難しさ1〜3 のダートの隠し馬（日本ダート三冠・ジャパンダート GS）と米国牝馬三冠のマスケットは 60 前後。
- 参考：前に底上げで使っていた下限（難しさ1〜6で 70・72・75・78・81・84）に届かない組は 65 組。
- 隠し馬のいないトロフィー：アメリカン GS・GF スプリント覇者・GF マイル覇者・GF ディスタンス覇者・GF クラシック覇者・GF ステイヤー覇者・GF ダート覇者（GF の6つは伝説級の名馬のグループが受け持つ）。
