# トロフィーの隠し馬の強さ（データのまま）

`node tools/hidden_horses.js` で作る（手で直さない）。持ち主の願い「難しいトロフィーほど強い馬だしてほしい」を、隠し馬の選び方で満たすための材料（2026-10-20）。隠し馬はデータのままの能力で出てくる（出てくるときに能力を上げる仕組みは、持ち主の「これ言ってないんだけど　こんな仕様やめてね」でやめた）。

- 総合力：その隠し馬が出るレースの馬場（芝・ダ）の総合力。データ（史実馬・名鑑・`data/legends.js`・見直しの `data/horse_fix.js`）のまま、いちばん良いときの力。芝にもダートにもなるトロフィー（クラウンオブブリーダーズ・ホールオブフェイム・ワンダーホース・インモータルロード）は、その馬の受け持つ馬場（`data/trophy_horses.js` の `surf`）で数えた。
- 無敗：★は「無敗のとき」だけ出てくる馬。
- 印（弱く見える組）：▼＝ひとつ易しい難しさの隠し馬の総合力の中央値より低い。▼▼＝ふたつ易しい難しさの中央値よりも低い。難しさごとの中央値は 1：63.5・2：69・3：72・4：76・5：76。
- 作り方：`js/core/special.js` の `SP.horse`（その場限りの馬）を `HS.Season.fhPeak` で数えた。データを直したら数は変わる。

## 要点

- 隠し馬 101 組（馬 × 出る馬場）のうち、弱く見える組は 12 組（▼▼ は ジャパン GS（難しさ5）のテンポイント［芝］71）。
- 難しさごとの総合力の幅：1：63〜66・2：66〜76・3：69〜77・4：72〜79・5：71〜81。
- 隠し馬のいないトロフィー：豪州スプリント三冠・ホールオブフェイム・ワンダーホース・インモータルロード・GF スプリント覇者・GF マイル覇者・GF ディスタンス覇者・GF クラシック覇者・GF ステイヤー覇者・GF ダート覇者（GF の6つは伝説級の名馬のグループが受け持つ）。
