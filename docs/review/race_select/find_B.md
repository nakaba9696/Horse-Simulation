# rows_B（61件）と2025年の実際の突き合わせ

- 調べた範囲：rows_B.md の 61 行すべて（香港 13・UAE 7・サウジ 7・豪州 23・日本の地方 13 ※豪州は G2 のスキラッチSを含む）。
- 週の数え方：施行日が 15日・22日・23日で、数え方の違いだけで1週ずれて見えるものは食い違いにしていない（日付だけ書いた）。
- 賞金の円換算は概算。1香港ドル≒20円（JRA の香港の頁の換算）、1米ドル≒150円、1豪ドル≒97円とした。1着の割合は、香港＝総額の56%（JRA の頁の香港 G1 の数から。例 HK$40,000,000→HK$22,400,000）、豪州＝おおむね58%（JRA の QE ステークス 2,950,000/5,000,000、TJ スミス 1,725,000/3,000,000 など）として出した。1.5倍以上ずれるものだけ表に入れた。
