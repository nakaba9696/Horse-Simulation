- 年齢は満年齢、レース名はその年代の名前。

3. **主な勝鞍と解説の食い違い**、名鑑とゲームの勝ち鞍のデータ（`data/historic_*.js`）の食い違い。
4. **書き方**：同じ言い回しの繰り返し、不自然な日本語、誇張（「史上最強」などの出典の無い評価語）。
