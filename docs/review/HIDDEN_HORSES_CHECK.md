# トロフィーの条件と隠し馬の組み合わせの洗い出し（2026-10-23）

持ち主の指示（2026-10-23）「隠し馬の条件精査」の材料。トロフィーは `data/trophies.js`、隠し馬は `data/trophy_horses.js`、強さは `docs/review/HIDDEN_HORSES.md`（同じ日に `node tools/hidden_horses.js` で作り直した数）。**データとコードは直していない**（決めるのは持ち主）。最後の「推しの案」は「推しで」と言えばその形で入れる。

## 読み方

- **走れるか**：いまの番組（2025年の形・`U.ERA`）で、条件のレースが全部あり、同じ年のものは出られる年齢がそろい、週が重ならず、国が違うレースどうしが中1週より詰まっていない（`js/core/fatigue.js` の `F.MIN_GAP`＝2）か。週は「月-週」。
- **ふさわしいか**（隠し馬ごと）：
  - ◎：史実で条件を全部取った（当時の名前・形でよい）
  - ○：条件の半分より多く、または「あと1つ」
  - △：条件のレースを1つだけ
  - □：条件のレースが当時まだ無く、その路線の名馬として選んだ
  - ×：条件のレースがあったのに1つも勝っていない
- **強さ**：隠し馬が出る馬場の総合力（★は無敗のときだけ出る）。▼・▼▼は `HIDDEN_HORSES.md` の印で、▼はひとつ易しい難しさの中央値より低いこと、▼▼はふたつ易しい難しさの中央値よりも低いこと。難しさごとの中央値は 1：61・2：68・3：72・4：77・5：75・6：78。
- **出典**は en/ja.wikipedia を主に、JRA と報道を使った。確かめられなかったものは最後の「未確認」に書いた。
- 「1989年より前」は、隠し馬にできる馬（1989年より前に走り終えた馬。香港の2つだけ1989年からの馬でもよい）。「名鑑無」は史実馬のデータはあるが名鑑（`data/profiles*.js`）が無いのでスペシャルホースにならない馬、「データ無」は史実馬のデータも無い馬。

## 要点

- トロフィーは **40**（三冠・グランドスラム・称号の34と GF の6）。
- **走れない条件は1つ**：欧州オークス三冠。英オークス（6-1・英）の次の週が仏オークス（6-2・仏）で、国の違う連闘は出られない。史実では2025年が6月6日と6月15日で、9日あいている。1976年にポーニーズが同じ年に両方を勝っている。
- ほかの33は走れる。ただし次の2つは詰まっている。
  - オーストラリアン GS：ジ・エベレスト（10-3）→コックスプレート（10-4）→メルボルンカップ（11-1）が3週続く。同じ国なので出られるが、疲労がたまり、距離も1200→2040→3200と開く。
  - 豪州三冠：ローズヒルギニー（3-4）→豪ダービー（4-1）が連闘になる。同じ国なので出られる。
- **条件のレースを1つも取っていないのに、そのレースが当時あった隠し馬（×）**：ペブルス（ワールドティアラ GS）。
- **条件を1つしか取っていない隠し馬（△）**：12頭。
  - キングストンタウン（オーストラリアン GS）
  - トロイ（ヨーロピアン GS）
  - ダリア・プティトエトワール（欧州オークス三冠）
  - エルグランセニョール（欧州マイル三冠）
  - コロネーション（仏国牝馬三冠）
  - アジャックス（豪州三冠）
  - マスケット（米国牝馬三冠）
  - トウショウボーイ（ジャパン GS。同じ年には1つずつ）
  - ザフライングダッチマン・バヤルド（ワールドステイヤー GS）
  - ロッキータイガー・ヤシマナシヨナル（ジャパンダート GS）
  - ヴェイグリーノーブル（ホールオブフェイム）
- **キングストンタウン**：クイーンエリザベスS（ATC）を勝っていない。1980〜1982年の勝ち馬は Iko・My Blue Denim・Prince Majestic。条件の4つで取ったのはコックスプレートだけ。
  - 4つのうち3つをそろえた1989年より前の馬は、ファーラップ（1930年）だけ。勝ったのはクイーンエリザベスSの前身の AJC プレート・コックスプレート・メルボルンカップで、ジ・エベレストはまだ無かった。
  - ファーラップは伝説級（GF の長距離）なので、トロフィーの隠し馬にはできない（`js/core/special.js` の `SP.isTop`）。
  - 2つをそろえたのはタロック（1960年にクイーンエリザベスSとコックスプレート。クイーンエリザベスSはレース最多の3勝）で、名鑑があるので入れられる。
- **難しさと強さのずれ**：難しさ5の中央値（75）が難しさ4（77）より低い。弱いのは日本の名馬の上限が芝70〜76・ダート64〜66で、ジャパン GS・ジャパンダート GS に強い馬を置けないため。隠し馬の選び方だけでは直らない（強さの見直しは `data/horse_fix.js` の別の仕事）。
- **データの穴**（隠し馬の判定と名鑑に関わる）：
  1. 地方の名馬の勝ち鞍が `data/historic_old.js` に入っていない。サンオーイ・ハツシバオー・テツノカチドキは空で、ヒカルタカイは中央の2勝だけ。名鑑の主な勝鞍には書いてあり、史実と合っている。
  2. 暦のクイーンエリザベスS（豪）は2015年から、グッドウッドCは2017年から、ランドウィックギニーは2014年からしか無い。古い勝ち（タロックのクイーンエリザベスS、セントサイモンのグッドウッドC 1884、ファーラップの AJC プレート）がデータの勝ち鞍に結びつかない。
  3. 候補の一覧を作る道具は、牝馬三冠の3つ目を秋華賞だけで数えた。データには「1986エリザベス女王杯」があり、ゲーム（`SP.mapWin`）は1995年までのエリザベス女王杯を秋華賞に読み替えるので、メジロラモーヌは旧の三冠をそろえている。

## GF の6つ（GF スプリント・マイル・ディスタンス・クラシック・ステイヤー・ダートの覇者。難しさ4）

- GF を勝てば手にする（`kind: 'gf'`）。トロフィーのリーチが無いので、トロフィーの隠し馬はいない。
- 名馬が出てくるのは、次の年の同じ GF へ連覇をかけるとき（伝説級のグループ `gf`）。顔ぶれはザテトラーク（短距離・芝81）、セントサイモン（マイル・芝83）、エクリプス（中距離・芝84）、グラディアトゥール（クラシック・芝81）、ファーラップ（長距離・芝81）、マンノウォー（ダート・ダ83）。全部制覇したあとはキンチェム（芝85）。
- 年末の12月4週のあとの「GF の週」に走るので、有馬記念・東京大賞典（12-4）とは重ならない。

## 推しの案（「推しで」と言えばこの形で入れる）

1. **欧州オークス三冠を走れるようにする**：仏オークス（ディアヌ賞）を6月2週 → 6月3週（`data/races_world.js` の仏オークスの2行）。2025年は6月15日で、英オークス（6月6日）から9日あく。仏国牝馬三冠（仏1000ギニー 5-2 → 6-3）も間があくだけ。入れるときは `node tools/export_godot.js` と検証を回す。
2. **オーストラリアン GS にタロックを足す**（キングストンタウンと2頭）。1960年にクイーンエリザベスSとコックスプレート、クイーンエリザベスSは最多の3勝。キングストンタウンは残す（強さ75。替えると芝69の1頭になる）。
3. **ヨーロピアン GS にトリプティクを足す**（1987年に4つのうち3つ。歴代でただ1頭）。
4. **英国牝馬三冠にオーソーシャープを足す**（1985年の三冠馬）。
5. **欧州マイル三冠にノノアルコを足す**（1974年に英2000ギニーとジャックルマロワ賞）。
6. **日本ダート三冠にヒカルタカイを足す**（1967年に初めての南関東三冠。ダ66で、いまの3頭より強い）。
7. **ワールドティアラ GS にオールアロングを足す**（1982年のヴェルメイユ賞。ペブルスは条件のレースが0）。
8. **アメリカン GS にトムフールを戻す**（1953年にメトロポリタンHとホイットニーS・10戦全勝。いまはダ75）。
9. **「選んだわけ」の文を直す**：
   - ラフィアン：「デビューから10連勝。1975年にエイコーンS・マザーグースS・CCAオークス（当時の牝馬三冠）」
   - アジャックス：「ローズヒルギニー（1937年）。のちに18連勝」
   - スペクタキュラービッド：「ダートの世界レコード」と書く

- 2〜7 の馬は、いま入っている下のグループ（「歴代の○○馬」・「G1を5勝した名馬」・「地方から来た名馬」）から抜ける（1頭が出てくる条件は1つだけ）。
- 足した馬は、どれも出る馬場の総合力が68〜72で、強さの▼は増える。「史実に合う馬を足し、強い馬は残す」形にした。
