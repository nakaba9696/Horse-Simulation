# 競馬場の形の出典

`data/layouts.js`（競馬場ごとの回り・コーナー・直線・高低差）の数と出典の一覧。持ち主の指示「レース場の坂やコーナーは全部実際の設定通りにして」のためのデータ。

## 読み方と作り方

- **1周・直線・高低差・使う距離**：出典の表の値（JRA は A コース）。
- **高さ（elev）**：JRA の10場は、コース紹介のページの「高低断面図」の画像から、塗りの上の縁を画素で読んで点にした（表の高低差と0.1〜0.2m の差で合う）。
- **コーナーの半径（segs）**：JRA はコーナーの半径を公表していない。断面図の下の区切り（直線・4コーナー・3コーナー・向正面・2コーナー・1コーナー）の位置から各部分の長さを取り、表の1周と直線に合わせ、形がゴールに戻って閉じるように角度と向正面の長さを解いた。そのため半径は目安（`approx: true`）。
  - スパイラルカーブ（入口の半径が大きく、出口が小さい）は、出典に書かれた所だけにした。入口と出口の比は図の区切りからの目安。
  - 京都の芝の内回りは、表の1周と直線の数からは、円のコーナーで外回りよりきつい形にすると閉じない。1周と直線の長さを優先したので、3、4コーナーの半径は外回りと同じくらいになっている。
- **使う距離（use）**：JRA の表の発走距離。内回り・外回りの両方で行う距離（京都の芝1400・1600・2000、新潟の芝1400・2000 など）は、重賞が使う側に入れた。阪神・中山の3200（外→内）は最後の1周の内回りに入れた。今は行わない昔の距離（阪神の芝1850・1900・2500・3100、中京の芝1700・1800・2400・2800 など）は、今の形のどれかに入れてある。
