# 競馬場の形の出典

`data/layouts.js`（競馬場ごとの回り・コーナー・直線・高低差）の数と出典の一覧。持ち主の指示「レース場の坂やコーナーは全部実際の設定通りにして」のためのデータ。

## 読み方と作り方

- **1周・直線・高低差・使う距離**：出典の表の値（JRA は A コース）。
- **高さ（elev）**：JRA の10場は、コース紹介のページの「高低断面図」の画像から、塗りの上の縁を画素で読んで点にした（表の高低差と0.1〜0.2m の差で合う）。
- **コーナーの半径（segs）**：JRA はコーナーの半径を公表していない。断面図の下の区切り（直線・4コーナー・3コーナー・向正面・2コーナー・1コーナー）の位置から各部分の長さを取り、表の1周と直線に合わせ、形がゴールに戻って閉じるように角度と向正面の長さを解いた。そのため半径は目安（`approx: true`）。
  - スパイラルカーブ（入口の半径が大きく、出口が小さい）は、出典に書かれた所だけにした。入口と出口の比は図の区切りからの目安。
  - 京都の芝の内回りは、表の1周と直線の数からは、円のコーナーで外回りよりきつい形にすると閉じない。1周と直線の長さを優先したので、3、4コーナーの半径は外回りと同じくらいになっている。
- **使う距離（use）**：JRA の表の発走距離。内回り・外回りの両方で行う距離（京都の芝1400・1600・2000、新潟の芝1400・2000 など）は、重賞が使う側に入れた。阪神・中山の3200（外→内）は最後の1周の内回りに入れた。今は行わない昔の距離（阪神の芝1850・1900・2500・3100、中京の芝1700・1800・2400・2800 など）は、今の形のどれかに入れてある。
- **地方**：1周・直線・高低差は地方競馬全国協会（keiba.go.jp）のコース一覧と各主催者のページ。「直線距離 X（ゴールまで Y）」は X＝4コーナーの出口から1コーナーの入口まで、Y＝ゴールまでと読んだ（straight は Y）。
  - コーナーの半径はどの出典にも無いので、向正面を正面と同じ長さにして1周の残りから出した（approx）。園田・高知の左右のコーナーの大きさの違いは keiba.go.jp のコース図から。園田・名古屋・浦和・笠松は、形が閉じるように向正面の長さを少し直した（園田・笠松は出典の向正面246m・251m → 241m・238m）。
  - 盛岡は岩手競馬の公式の高低図に区間の長さと高さがあるので、それに合わせた（approx なし）。名古屋の高さは名古屋競馬の施設案内 PDF の断面図から。
  - 高低差の数だけあって坂の位置が出典に無い門別（1.54m）・佐賀（1m）・笠松（1.92m）・高知（1.58m）は平らにした（approx）。園田の3〜4コーナーの下りの位置は目安。
  - スパイラルカーブ（船橋の両コーナー、名古屋の3〜4コーナー、浦和の3コーナー）の入口と出口の比は出典に無く、±10〜12% の目安。
  - 大井の左回り（2021年から、1650m）は courses.js の回りの向き（右）と逆なので入れていない。名古屋の1400m・1900m（かきつばた記念・名古屋大賞典）は前の土古のコースの距離で、いまの弥富のコースに入れてある。船橋の内コース（1250m）は2006年11月を最後にレースで使っていない。
  - data/courses.js の水沢の直線を 247m → 245m に直した（keiba.go.jp「317m（ゴールまで245m）」）。
- **海外（米・加・豪・香港・UAE・サウジ・星）**：米国のダートは DRF の米国の寸法表（2015年）の直線・ゴール〜1コーナー・コーナーの半径。表に無い場は同じ大きさの場の半径を使った。内側の芝はダートと同じ中心の楕円とみた。ほかは JRA の海外競馬のコース解説・JAIRS・HKJC・en/ja.wikipedia。全部 approx（米国の楕円などは高低差の数が無く平ら）。
  - 高さを出典の文から入れた所：シャティン（向正面が2.2m高い。HKJC）、ムーニーバレー（約5m。JRA）、コーフィールド（遠いターンで1〜2m。JRA）、ウッドバイン（向正面が0.8m高い。en.wikipedia）、クランジ（直線に0.2%の上り）。ランドウィックの直線の上り（ザ・ライズ）は高さの数が無く1mの目安。サンタアニタのダウンヒルの高さは非公式の見積もり（丘の上がゴールより約12m高い）。
  - 形が閉じなかった所（メイダンのダート・シャティンの芝・ウッドバインの芝・フレミントン・コーフィールド・米国の1マイル1/8の数場）は、角度と向正面の長さを解き直して閉じた。フレミントンの洋梨型は、大きな3〜4コーナーと締まった1〜2コーナーの2つで表した目安。
  - ナドアルシバ（2009年まで）は三角形。直線は en.wikipedia と courses.js の400m（ja.wikipedia の600mでは三角形が閉じない）にし、ほかの2辺500m・角は同じ半径の120度の目安。1周は ja.wikipedia（芝2121m・ダ2254m）。
  - ベルモント（2026年に建て直し）・ガルフストリームの芝（2021年に変わった）・ムーニーバレー（2027年から新コース）は、変わる前の形。
  - data/courses.js の lap・straight を出典に合わせた（2%より違った所）：ナドアルシバ・シャティンのダ・ハッピーバレー・サンタアニタの芝・アケダクトの芝・ローレル・キーンランド・ガルフストリーム・ローンスター・アーリントン・ハリウッドパーク・ウッドバイン・キングアブドゥルアジーズ。ウッドバインの回りの向きを右 → 左に直した（en.wikipedia「30 degree left … 150 degree left」）。
- **海外（欧州）**：JRA の海外競馬のコース解説（ロンシャン・シャンティイ・ドーヴィル・アスコット・ヨーク・グッドウッド・サンダウン・レパーズタウン）と、ja・en・fr・de の wikipedia。France Galop・Racing Post などは読めず、検索の要約を出典にした所がある（URL は src にある）。approx でないのはロンシャンとドーヴィルの直線だけ。
  - 名物の形：ロンシャンは直線533m の手前のフォルスストレート（約250m）と、向正面の上りから3コーナーの下り（約10m）。エプソムは周回しない（open）形で、発走から上って下り、タッテナムコーナーから内へ傾いた直線（高さは出典の数）。アスコットはスウィンリーボトムからゴールまで約22m 上る三角形。ニューマーケットのローリーマイルは直線10ハロンとゴール前のディップ（下ってから上る）。サンダウンは上る直線、シャンティイは最後の800m で上る直線。
  - 高さの数が出典に無く、坂の向きと位置だけ出典どおりにして m は小さめの目安にした所：ニューマーケット（ディップ3m・ジュライ4m）、グッドウッド、カラ、レパーズタウン、ドンカスター、ニューベリー、エア、サンクルー、ホッペガルテン、ケンプトン、ロンシャンの中回り・小回り・新コース。
  - 形が閉じなかった周回は、下調べのコーナーの半径を保ったまま、ゴールの先の直線と向正面で長さを受け渡し、角度を解き直して閉じた。デュッセルドルフはおむすび型（同じ半径の3つの角の二等辺三角形）。フェニックスパーク（1990年に閉場）は形の出典が無く、courses.js の数の楕円。ドイツの4場は1周と直線だけ分かる楕円。
  - 同じ馬場で距離が重なるので決めた割り振り：アスコットの1600m はラウンド（クイーンエリザベス2世S）、ニューマーケットの1200m・1600m はローリーマイル、シャンティイの1400m は大回り、ロンシャンの2500m は中回り。
  - data/courses.js を出典に合わせた（周回の回りで2%より違った所）：サンクルー・ドンカスター・サンダウン・レパーズタウン・バーデンバーデン・ハンブルク・ホッペガルテン・デュッセルドルフ。直線・周回しない回りが既定の場（ニューマーケット・エプソム・グッドウッド・カラなど）は courses.js をそのままにした。ドーヴィルの直線も、大レースが直線のコースなので1000m のまま。
