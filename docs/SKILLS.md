# 特殊能力の一覧（効果と条件）

`js/core/skills.js`（発動する特殊能力）と `js/core/horse.js` の `H.SKILLS`（持っている特性。効き目は `js/core/racesim.js`）を読んで書いた一覧。2026-10-16 の時点。数は式どおり。

- **持っている史実馬の数**：史実馬 7,291 頭を `H.fromHistoric` で馬にし、素質（いちばん良いときの能力）で数えた。
- **勝率**：`tests/run.js` の `skills:` と同じやり方。東京・芝2000・14頭（全頭 level 82 の頭数合わせの馬）を 400 回走らせ、1頭目にだけその能力を持たせた。脚質の条件がある能力は、1頭目をその脚質の馬にして比べた。「なし」は同じ脚質で能力を持たない場合。勝率の数％の差は誤差の内（400 回で ±2〜3％）なので、平均着順も添える。
- 能力の速さの効き：`S.power` の総合（total）が +1 で、巡航の速さが ×1.0012。

## 1. 発動する特殊能力（`HS.Skills.LIST`）

レース中の決まった場面で一度だけ発動する。どれを持つかは能力値から自動で決まる。

- 持てる数：(スピード＋スタミナ＋根性)÷3 が 65 未満で1つ、78 未満で2つ、90 未満で3つ、それ以上で4つ（スピード・スタミナは芝・ダートの高いほう）。
- 多いときは系統の順（爆発 → 損 → 速さ → 気性 → 根性）で選ぶ。弱み（損）は2番目に来るので、条件を満たすと持てる数の枠を取る。
- オリジナルホースは親から受け継いだものに決まる（`trigFixed`）。
- 効き目は3種類：速さ ×(1＋spd) を sec 秒、スタミナ E を増減（E は 1＝満タン）、よれる（進路が1つずれる）。
- 場面：start＝スタートから4秒、mid＝直線の前、st＝直線（残りが直線＋30m 以内）、any＝いつも。

## 3. 測って見えたこと

- **効いていない**：スタートダッシュ・出ムチ・逃げ粘りは、発動しても着順が変わらない（スタートの2秒の速さは隊列の位置合わせで打ち消され、逃げ粘りは発動が 1％）。馬混み嫌いは発動 0％、ささり癖は AI の馬には効き目が無い（よれるのは騎乗中だけ）。
- **逆に効いている**：二の脚は勝率 9→5％・平均着順 7.42→8.27 と、持つと弱くなる。前半の速さの分だけ脚を使っている。
- **強い**：ロングスパートは勝率 9→15％。大逃げは平均着順 11.0→5.9（勝率は変わらない）。折り合い上手・ど根性は平均着順を 0.7〜0.9 上げる。
- **ほとんど持たれない**：ささり癖（1頭）・接戦に弱い（0頭）・馬混み嫌い（6頭）・まくり（6頭）・二枚腰（25頭）。条件が重なりにくい（まくりは「切れ3以下・差しか追込」）。
- **多すぎる**：馬群割り 4,032頭・直線一気 2,941頭・逃げ粘り 2,795頭・大外一気 2,739頭・スタートダッシュ 2,408頭。史実馬の半分近くが同じ能力を持つ。
- **逃げ馬そのもの**：頭数合わせの馬の逃げは、どのコースでも平均着順が 10〜11番（14頭）。能力より先に、逃げの脚質の釣り合いを見直す必要があるかもしれない。
