# 特殊能力の一覧（効果と条件）

`js/core/skills.js`（発動する特殊能力）と `js/core/horse.js` の `H.SKILLS`（持っている特性。効き目は `js/core/racesim.js`）・`data/uniques.js`（選んだ名馬の固有の能力）を読んで書いた一覧。2026-10-16 に直したあとの値。前の値は「前→今」で並べる。2026-10-17 に足したものは「新」と書く。

測り方（`node tools/skills_bench.js [trig|passive|count|style|perstyle|unique] [回数]` で出せる）：

- **持っている史実馬の数**：史実馬 7,291 頭を `H.fromHistoric` で馬にし、素質（いちばん良いときの能力）で数えた。
- **勝率**：東京・芝2000・14頭（全頭 level 82 の頭数合わせの馬）を 400 回走らせ、1頭目にだけその能力を持たせた。脚質の条件がある能力は、1頭目をその脚質の馬にして比べた。「なし」は同じ脚質で能力を持たない場合。勝率の数％の差は誤差の内（400 回で ±2〜3％）なので、平均着順も添える。
- 前の値は、直す前の測り方（同じ場面・同じ回数）のもの。ペースと脚質の釣り合いも直したので、「なし」の勝率も変わっている。

## 1. 発動する特殊能力（`HS.Skills.LIST`）

レース中の決まった場面で一度だけ発動する。どれを持つかは能力値から自動で決まる。

- 持てる数：(スピード＋スタミナ＋根性)÷3 が 65 未満で1つ、78 未満で2つ、90 未満で3つ、それ以上で4つ（スピード・スタミナは芝・ダートの高いほう）。前と同じ。
- **選び方（直した）**：系統を1つずつ回して取る（爆発 → 損 → 速さ → 気性 → 根性 → 爆発…）。系統の中は表の順。前は系統の順に全部取ってから次へ行ったので、爆発系を持つ馬が多すぎた。
- **一気系（豪脚・末脚・大外一気）は、1レースに1つだけ発動する**（1頭が2つ以上持っていても）。
- **一気系は、ためた脚で伸びが変わる**（2026-10-16・docs/BALANCE.md）：発動したときのスタミナ E で速さの倍率が ×(0.4＋2×E)（0.6〜1.6倍）になり、そのあと終いの伸びの上限が上がる（豪脚 ＋0.3・末脚 ＋0.2・大外一気 ＋0.2。`fx.top`）。後ろでためて直線で使うと大きく、早めに脚を使ったあとだと小さい。東京芝2000・14頭の比べ（tools/skills_bench.js trig）：豪脚 7→9％・末脚 5→8％・大外一気 5→9％。
- オリジナルホースは親から受け継いだものに決まる（`trigFixed`）。
- 効き目：速さ ×(1＋spd) を sec 秒（「脚を使わない」ものは、その間スタミナの減りが増えない）、スタミナ E を増減（E は 1＝満タン）、よれる（進路が外へずれる）、隊列の位置の目標を前へ（m）。
- 場面：start＝スタートから4秒、mid＝直線の前、st＝直線（残りが直線＋30m 以内）、any＝いつも。

## 4. 測って見えたこと・残り

- どの発動の能力も、勝率を +1〜+6 ポイントほど動かす（マイナスは −1〜−3）。いちばん大きいのはロケットスタート・出ムチ○の先行（+6）、大まくり（+5）、自由自在・ロングスパート（+3〜4）。
- 気性・根性の「スタミナを戻す」能力（折り合い上手・ど根性）は、勝率より平均着順に効く（+0.6）。
- 大逃げは勝率 +1 だが、平均着順が 8.9 → 5.3 と大きく上がる（離して逃げて掲示板に残る形）。手書きの 11 頭だけなので、今回は変えていない。
- ハイペース○・スローペース○は、その流れのレースが2割ほどなので、ふつうの番組では ±1 ポイントの内。

## 脚質ごとの数の釣り合い（持ち主の決定 2026-10-17）
- 先行は位置取りの自由が利くので、特殊能力は少なめのままでよい。
- 逃げと追込は位置取りがピーキー（ハナを取れないと崩れる・前が詰まると届かない）。この2つに、位置取りを助ける能力とくせになる弱み（番手×）を足した（上の表の「新」）。
- 測り方（`node tools/skills_bench.js perstyle`）：史実馬を全部 `H.fromHistoric` で馬にし、脚質ごとに1頭あたりの強みと弱みを数える（発動するものと持っている特性。脚質自在・固有の能力は数えない）。

|---|---|---|---|
| 逃げ | 817 | 2.77 → **3.03** | 0.35 → 0.45 |
| 先行 | 3,097 | 2.27 → 2.35 | 0.17 → 0.17 |

- 平均ペースの脚質の釣り合い（`tests/run.js` の「sim: ペース」。頭数合わせの馬も新しい能力を持つ）：前 逃げ 8.2・先行 7.3・差し 7.3・追込 7.9 → 今 8.3・7.4・7.4・7.4。後方待機○をたたき台の ＋0.05 にすると追込が 6.8 まで上がって釣り合いが崩れたので、＋0.025 にした（追走○・外回し○も ×0.93・×0.94 → ×0.95・×0.96）。

## racesim.js で変えたこと（2026-10-17。Godot の C++ 版を追いつかせるとき）
- `S.create`：`HS.Skills.setup(sim)` のあとに、各馬へ `HS.Skills.flags(s)`（`s.tsuiso`・`s.sotoM`・`s.sabaki`）。
- `S.skillAdj`：外枠○（`ctx.frame >= 7` で ＋1.2）・道悪○（`race.ground` が重・不良で ＋2）。
- `S.step` の各馬の脚の使い方（砂かぶり×のすぐ後）：追走○（追い出す前・直線の前・すぐ前 4m 以内で進路の差 0.8 未満に馬 → `costMul *= S.TSUISO`）、外回し○（追い出していて、直線の前で、コーナーの中で直線の手前 700m 以内〔高低差の無いコースは直線の手前 350m 以内〕。自分で乗る馬は進路 1.5 より外 → `costMul *= S.SOTO`）。どちらも初めて効いたときに `S.fire`。
- AI の馬の「前が壁になった」：くじは前と同じに引き、長さを外回し○は 0（言わない）、馬群さばきは ×0.4。
- 自分で乗る馬のコーナーの遠回り（`dx *= 1 − 0.005 × (進路 − 0.5)`）は、外回し○なら掛けない。
- 自分で乗る馬の横の動き：馬群さばきなら速さ `S.LANE.v × 1.6`、止められる幅 `dx 1.4`・`gap 0.55`。
- ペースのチェックポイント：`sim.check.lead`＝通った先頭の馬の番号（幻惑逃げ）。
- `js/core/skills.js`：`K.step` で `sk.banteFor`（直線の前・距離の2割より先で3番手より後ろの秒。2番手以内で 0）・`sk.wallFor`（直線ですぐ前 2.6m・進路の差 0.85 未満に馬がいた秒）・`x.wall` を数える。`cont` の能力は `K.step` で調べない。`K.apply` の `foeE`（後ろの馬〔`foe` があればその脚質〕のスタミナ）。固有の能力は `K.of` の先頭（持てる数とは別）。
