# ホースシミュレーション

ブラウザで遊べる競馬シミュレーションゲーム。架空の馬の能力値と、レースの条件（芝／ダート・距離・馬場）からレースを計算し、馬券を当てて所持金を増やします。

## 遊び方
1. `index.html` をブラウザで開く（サーバーは要りません）。
2. 出馬表を見て、単勝（1 着）・複勝（3 着以内。7 頭以下なら 2 着以内）に賭ける。馬名を押すと能力が見られます。
3. 「出走！」でレースを観戦。速さは ×1／×2／×4、「結果へ」で飛ばせます。
4. 結果と払い戻しを見て、次のレースへ。進み具合はブラウザに自動で保存されます。
