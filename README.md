# ターフの系譜

ブラウザで遊べる競馬シミュレーションゲーム。実在の名馬が実在のレースを走る時代に、馬主として史実馬を買い、生産者として配合を重ね、自分の血統で歴史を塗り替えていく。

## 遊び方
- `index.html` をブラウザで開くだけで遊べる（インストール・ビルド不要。スマホでも遊べる）。
- GitHub Pages で公開する場合：リポジトリの Settings → Pages → Branch を `main`・`/ (root)` にする。

## できること
- **史実の世界**：1960〜2025年の好きな年から始められる。その年に生きている実在の馬（1955〜2024年生、JRA の重賞の勝ち馬と海外の大レースの勝ち馬など約7300頭）が、年代どおりの名前のレース（JRA の重賞・地方の交流 G1・海外の大レース93競走）を走る。
- **馬主として**：デビュー前の史実馬を市場で買える。買った馬で史実の勝ち鞍を取るのも、取り逃すのもプレイヤーしだい。
- **生産者として**：実在の種牡馬（年代ごとの種付け料）と繁殖牝馬を配合。5代血統表のクロス（インブリード）・ニックス・系統で仔の素質が変わる。史実の名牝に史実どおりの種牡馬をつければ、あの名馬が自分の牧場に生まれる。違う相手をつければ歴史が変わる。
- **騎手として**：新人騎手としてデビューし、毎週の騎乗依頼を受けて実在のレースに乗る。抑える・追う（馬の拍子に合わせる）・ムチ・進路を、スマホのタッチかゲームパッドで操作する。勝ち星と評判が上がると強い馬・大きいレース・史実の名馬の依頼が来る。リーディングと見習いの減量もある。
- **育成**（馬主・生産者の遊び方）：調教メニュー（坂路・ウッド・併せ馬・プール…）、調教タイム、調教師のコメント、調子と疲れ、故障。おまかせもできる。
- **能力**：芝とダートで別のスピード・スタミナ、根性・気性・坂と、道悪・健康・距離適性（1000〜4000m）・脚質と脚の切れ（1〜8）・成長型・特殊能力（大舞台・大逃げ・ロングスパートなど21種）。有名な馬は解説も読める。
- **レース映像**：横から追う中継風の映像（毛色・勝負服・ゼッケン）、ハロン棒、ミニマップ、順位、実況、確定の掲示板。
- **記録**：年代記（G1 の勝ち馬と史実の勝ち馬の比較）、年度表彰、自分の成績。
- **セーブ**：毎週自動で端末に保存。書き出し・読み込みで別の端末へ移せる。

- 検証：`node tests/run.js`
