# ホースシミュレーション

ブラウザで遊べる競馬シミュレーションゲーム。牧場主として馬を配合・生産し、育てて、レースに出して勝たせます。育成・調教とレース観戦はダビスタ風、セリ・血統の系統・配合理論はウイニングポスト風を目指しています（種牡馬・血統・重賞・騎手は実在の名前、生まれる仔・ライバル・調教師・馬主は架空です）。

## 遊び方
1. `index.html` をブラウザで開く（サーバーは要りません）。スマホなどで 1 ファイルにまとめた版が欲しいときは `node tools/bundle.mjs` で `dist/horse-simulation.html` を作れます。
2. **厩舎**：毎週、馬ごとに調教（坂路・ウッド・併せ馬・プール・ゲート練習・休ませる）か、出走するレースを選んで「次の週へ」。疲れがたまると故障しやすく、調子も落ちます。
3. **レース**：自分の馬は黄色く光ります。賞金で牧場の資金が増えます。勝つとクラスが上がり（新馬→未勝利→1勝→2勝→3勝→オープン）、重賞・G1 に挑めます。
4. **牧場**：2〜4 月に繁殖牝馬へ種付け。種牡馬ごとに系統・ニックス・インブリード・アウトブリードの評価（◎○▲△）が出ます。仔は翌年 3 月に生まれ、2 歳から入厩できます。
5. **セリ**：毎年 7 月に 1 歳馬が買えます。値段と素質は一致しないので、血統と見立てから掘り出し物を探します。
6. **騎手・調教師**：厩舎の画面で選べます。一流騎手はクラスの低い馬には乗ってくれません。
7. **ライバル**：4 組のライバル馬主の馬が、重賞やあなたのレースに出てきます。年が明けると年度代表馬などの表彰があります。
8. **海外遠征**：重賞を勝った馬は、凱旋門賞などの海外 G1（遠征費 2,000 万円）に挑めます。
9. **引退**：牝馬は繁殖牝馬に、G1 を勝つか重賞を 2 勝した牡馬は自分の牧場の種牡馬（種付け無料）になります。

進み具合はブラウザに自動で保存されます。
